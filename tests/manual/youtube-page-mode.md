# YouTube 網頁模式、YouTube 選單、工具列全螢幕文字：手動驗收步驟

對應規格：`doc/specs/youtube-page-mode.md`（R66–R68）。單元測試見 `tests/unit/links.test.ts`（`youtubePageUrl`）。

## 驗收用的影片

- 可以嵌入的影片：`https://www.youtube.com/watch?v=iG9CE55wbtY`（TED）、`https://www.youtube.com/watch?v=aqz-KE-bpKQ`
- 搜尋結果頁：`https://www.youtube.com/results?search_query=TED+talk`

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R66 AC1 | 播到 2:00，「YouTube ▾」→「看這部影片的網頁（留言、推薦）」 | 顯示 YouTube 網頁，從 2:00 附近接著播；往下捲有留言區；廣告阻擋關閉；沒有「只顯示影片」 |
| R66 AC2、AC7 | 「YouTube ▾」→「回到播放器」 | 從網頁上的時間接著播；畫質、字幕不變；歷史沒有新增 |
| R66 AC3 | 網頁模式時點推薦影片（或換到另一部影片），再回到播放器 | 播放那部影片；歷史多一筆（已在歷史中時移到最上面） |
| R66 AC4 | 播放器暫停在 3:00 時切到網頁 | 網頁停在 3:00 附近，不自動播放 |
| R66 AC5 | 從搜尋結果點開的影片，看兩種模式的選單；按「回到剛才的 YouTube 頁面」 | 兩種模式都有這一項；回到原本的搜尋結果與捲動位置 |
| R66 AC6 | 網頁模式時關閉再開啟 | 這一格是播放器，停在網頁上的影片與時間 |
| R66 AC8 | 看操作區 | 沒有獨立的「← 回到 YouTube」；Backspace、滑鼠上一頁鍵仍可回去 |
| R67 AC1–AC4 | 格子按「全螢幕」；工具列按「離開全螢幕」；工具列全螢幕後再開關格子的全螢幕；F11、Esc | 工具列的文字和視窗狀態一致 |
| R68 | 安裝後看 MultiView.exe 的內容 → 詳細資料 | 版本 0.5.2 |
