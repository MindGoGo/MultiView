網頁來源手動驗收測試頁

啟動：在專案根目錄執行 node tests/manual/web-pages/server.mjs（需要 Node 18 以上），再把下列網址貼到程式的空白格。 步驟和預期結果見 tests/manual/web-page-source.md。

  • multi.html：大小不同的影片，加上被隱藏、太小、透明、在可視範圍外的影片（R13 AC3）
  • frame-parent.html：主要影片在跨網域的子框架裡（R13 AC3-1）
  • frame-same.html：主要影片在同網域的子框架裡（R13 AC3-1）
  • swap.html：播放 3 秒後換成另一個影片（R13 AC3-2）
  • remove.html：播放 3 秒後移除影片（R13 AC3-3）
  • novideo.html：沒有影片，有連結、輸入框、可捲動（R13 AC4、R14）
  • autoplay.html：網站自己會一直自動播放（R15 AC5、AC7）
  • drm.html：影片觸發加密媒體事件（R16 AC5）
  • /missing：回應 404（R16 AC2）；/slow：35 秒後才回應（R16 AC6）
  • broken-image.html：有一張 404 的圖片（R16 AC7）
  • ads.html（用 mv.localtest.me 開啟；不要用 ads. 開頭的網域，會整個被清單擋下）：請求 EasyList 中的廣告網址、隱藏廣告元素（R17 AC1）
  • cookie.html：設定、讀取 cookie（R18 AC2、AC3）
  • vod.html：網頁中的一般影片，可以跳轉（R19 AC7）；bunny-10s.mp4：10 秒的 mp4（R19）
