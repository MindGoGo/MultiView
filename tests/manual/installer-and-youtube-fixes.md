# 安裝版、YouTube 連結、暫停畫面黑線：手動驗收步驟

對應規格：`doc/specs/installer-and-youtube-fixes.md`（R44–R47）。單元測試見 `tests/unit/links.test.ts`。

## 驗收用的影片

- TED（720p，背景是均勻的藍色，容易看出橫線）：`https://www.youtube.com/watch?v=iG9CE55wbtY`
- 有 1080p 的影片：`https://www.youtube.com/watch?v=aqz-KE-bpKQ`

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R44 AC1 | `npm run dist` | 產生 `release/MultiView-Setup-0.3.2.exe`，沒有新的 `*-portable.exe` |
| R44 AC2 | 沒有安裝過時，雙擊安裝檔 | 不詢問系統管理員權限；安裝完成後程式自動開啟；桌面和「開始」功能表有 MultiView |
| R44 AC3 | 關閉程式，從桌面捷徑開啟 | 2 秒內出現畫面並載入格子 |
| R44 AC4 | 先用 0.3.1 單一 exe 設定好格子和清單，再開啟安裝版 | 版型、格子、清單都和原本一樣 |
| R44 AC5 | Windows「設定 → 應用程式」解除安裝 MultiView，再重新安裝 | 程式和捷徑移除；重新安裝後設定還在 |
| R45 AC1 | TED 影片按「直接操作」，暫停後點右下角「更多影片」裡的一部影片 | 這一格換成那部影片並開始播放；歷史最上面多一筆，網址是 `watch?v=` 加影片代碼 |
| R45 AC2 | 影片播完後點推薦影片 | 同 AC1 |
| R45 AC3 | 先把音量設 30、亮度 80%，再做 AC1 | 換影片後仍是音量 30、亮度 80% |
| R45 AC4 | 「直接操作」時點左上角的影片標題 | 系統瀏覽器開啟這部影片；這一格不變 |
| R45 AC5 | 「直接操作」時點頻道頭像、YouTube 標誌 | 系統瀏覽器開啟對應的頁面；這一格不變 |
| R45 AC6 | 整頁模式的網頁裡點會開新視窗的連結 | 沒有反應（和以前一樣） |
| R46 AC1–AC2 | `1` 版型選 1080p、`2×2` 選 720p，暫停後把滑鼠移到畫面上，讓標題和「更多影片」出現 | 正中央沒有深色橫線 |
| R46 AC3 | AC2 的情況下播放 15 秒 | YouTube 回報 hd720 |
| R47 | 安裝後看 MultiView.exe 的內容 → 詳細資料 | 版本 0.3.2 |
