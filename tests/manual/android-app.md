# Android 版：手動驗收步驟

對應規格：`doc/specs/android-app.md`（R145–R159）。單元測試在 `android/core/src/test/`，可以在本機跑（`cd android && ./gradlew :core:test`），GitHub Actions 也會執行。

安裝方式見 `doc/features/android-app.md`。測試裝置：POCO F6 Pro（HyperOS 3，Android 16）。

## 步驟 1：建置與安裝流程（R145，`android-v0.0.1`）

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R145 AC1 | 推送改到 `android/` 的 commit，看 GitHub 的 Actions 頁面 | 「Android」workflow 的「測試與編譯」成功，Artifacts 有 `MultiView-Android-debug` |
| R145 AC2 | 推送版本號還沒發佈過的提交（0.0.1），看 Actions | 「判斷要不要發佈」顯示「還沒有發佈：測試通過後自動發佈」；「產生簽章的 APK 並發佈」成功；Releases 出現「MultiView Android 0.0.1」與標籤 `android-v0.0.1`，附 `MultiView-Android-0.0.1.apk`，沒有標成最新版本 |
| R145 AC2 | 再推送一個沒有改版本號的提交 | 只跑「測試與編譯」，「產生簽章的 APK 並發佈」被略過 |
| R145 AC2 | 在手機下載 APK 安裝後開啟 | 看得到圖示（四個彩色格子），開啟後黑底顯示「MultiView」與「MultiView Android 0.0.1」，文字沒有被瀏海或導覽列擋住 |
| R145 AC3 | 版本號升到 0.0.2 並推送（自動發佈）後下載安裝 | 直接覆蓋安裝（沒有「與現有套件衝突」的錯誤），開啟顯示新的版本號（資料保留要等有設定可存的版本再驗一次） |

## 步驟 2：技術驗證（R146、R147，`android-v0.0.2`）

打開 App 是測試畫面。上方的按鈕：「原生播放器」「YouTube 內嵌」切換種類，「2×2」「3×3」切換格數，「網址」可以換成自己的網址（一行一個），「重新載入」重建所有格子。每格左上角顯示狀態，下方有喇叭（靜音）與音量滑桿。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R145 AC3 | 不移除 0.0.1，直接安裝 0.0.2 | 覆蓋安裝成功，上方顯示「MultiView Android 0.0.2」 |
| R146 AC1 | 「原生播放器」「2×2」，播放 10 分鐘 | 4 格都在播放、都聽得到聲音，不中斷（預設網址是測試用的影片；有直播的 m3u8 可以用「網址」換上） |
| R146 | 第 1 格靜音、第 2 格音量調到 30% | 只有這兩格的聲音改變 |
| R146 AC2 | 「3×3」播放幾分鐘 | 記錄是否卡頓、手機會不會變燙；每格左上角的「掉格」數字是否一直增加 |
| R147 AC1 | 「YouTube 內嵌」「2×2」 | 4 格 YouTube 都在格子裡播放（不跳成全螢幕） |
| R147 AC2 | 同上，聽聲音 | 記錄：4 格是否同時有聲音（iOS 是只有 1 格）；調整某一格的音量是否只影響那一格；狀態裡的「被暫停 N 次」（0.0.3 起） |
| R147 | 第 1–3 格按喇叭靜音，只留第 4 格有聲音，再按「全部播放」 | 記錄：靜音的格子會不會繼續播放（不被暫停） |
| — | 切到其他 App 再回來 | 切出去時全部暫停；回來後按「全部播放」可以繼續 |

## 步驟 4：核心功能第一版（R149–R153、R155，`android-v0.0.5`）

背景播放與子母畫面（R154）還沒做：切到其他 App 時全部暫停，回來時恢復。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R145 AC3 | 直接安裝 0.0.5 覆蓋 0.0.4 | 覆蓋安裝成功；打開是空白的格子（手機直向是上下兩格） |
| R150 | 複製一個 YouTube 網址，在空白格按藍色的「貼上」 | 先顯示彈跳的小生物與「解析中…」，幾秒後開始播放；左上角有小喇叭 |
| R150 | 在另一個空白格點「輸入網址…」，貼上 m3u8 或另一個 YouTube 網址，按「播放」 | 開始播放；因為第 1 格有聲音，這一格是靜音的 |
| R150 AC1 | 在 YouTube App 或 Chrome 按分享，選 MultiView | 有空格時放進空格並提示「已放進第 N 格」；沒有空格時問要取代哪一格 |
| R150 | 輸入不是網址的文字 | 顯示「不支援的網址」，格子不變 |
| R151、R152 | 點一下第 2 格 | 只有第 2 格有聲音；出現下方的操作列與上方的工具列；影片中央出現暫停鈕 |
| R151 | 再點一下第 2 格 | 操作列與工具列收起 |
| R151 | 點一下後不操作 | 3 秒後自動收起；打開音量滑桿或「⋯」選單時不會自動收起 |
| R152 | 工具列顯示時，按另一格左上角的喇叭 | 兩格同時有聲音（兩格都是 yt-dlp 或 m3u8 時）；喇叭旁邊有「yt-dlp」標示，沒有蓋住喇叭 |
| R152 | 操作列的音量（格子窄時在「⋯」裡）調到 30% | 只有這一格變小聲 |
| R153 | 操作列的播放／暫停；工具列的全部暫停、全部播放、全部靜音 | 行為正確；暫停的格子中央一直顯示播放鈕 |
| R153 | 拖曳操作列上方的進度條；雙擊影片右邊、左邊 1/3 | 跳到那個位置；快轉、倒轉 10 秒並顯示「+10 秒」「−10 秒」。直播不作用 |
| R153 | 亮度調到 50%；工具列的總亮度調到 80% | 這一格變暗；全部變暗（兩個相乘） |
| R153 | 畫質選 360p（「⋯」→ 畫質） | 過一會兒畫面變模糊；選「自動」恢復 |
| R149、R153 | 按全螢幕按鈕（或兩指張開） | 這一格占滿畫面，手機直向時自動轉成橫向；其他格暫停。再按一次（或兩指捏合）回到分割畫面、轉回直向、其他格繼續播 |
| R149 | 拖曳兩格之間的分隔線；雙擊分隔線 | 兩格的大小跟著改變；雙擊回到一半一半 |
| R149 | 長按影片（約 0.5 秒）後拖到另一格放開 | 兩格互換，影片不重新載入 |
| R149 | 工具列的旋轉按鈕；長按旋轉按鈕 | 轉成橫向（關了自動旋轉也可以），橫向時兩格左右排列；長按後回到跟著裝置旋轉 |
| R149 | 看畫面邊緣 | 影片畫到螢幕邊緣，沒有狀態列；操作列的按鈕沒有被瀏海或下方的手勢列擋住、都按得到 |
| R151 | 操作列的星號、更換網址、移除 | 提示「已加入最愛」；更換網址的小視窗有清除與貼上；移除後變回空白格 |
| R155 | 播放一部一般影片到 1 分鐘以上，滑掉 App 再打開 | 版型、格子都還原，都是暫停的；按播放後從上次的位置繼續 |
| R152 | 播放中用另一個 App 播音樂（或接電話） | MultiView 全部暫停；電話結束後恢復播放 |
| R152 | 播放中拔掉耳機（或關掉藍牙耳機） | 全部暫停 |
| — | 貼上一般網站的網址（例如新聞網站） | 目前以整頁顯示網頁，可以直接操作；下緣的小把手叫出操作列（影片模式與廣告阻擋之後才有） |
