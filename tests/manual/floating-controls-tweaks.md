# 浮動按鈕的調整（桌面版）：手動驗收步驟

對應規格：`doc/specs/floating-controls-tweaks.md`（R171）。單元測試見 `tests/unit/cell-click.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R171 AC1 | 滑鼠移到格子上，再移到左上的聲音按鈕 | 右邊展開音量滑桿與數值；拖曳可以改音量；移開 0.3 秒後收起 |
| R171 AC1 | 點聲音按鈕；打開齒輪選單 | 靜音／開聲音；齒輪選單沒有「音量」 |
| R171 AC1 | 拖完滑桿後按 ← → | 仍是倒轉、快轉，不是改音量 |
| R171 AC2 | 整頁模式的網頁格子：移到「⋯」叫出按鈕，從左下慢慢移到右上的齒輪 | 按鈕不消失，齒輪可以按；移出格子後收回 |
| R171 AC3 | 從影片格子按住「移動」拖到整頁模式的網頁格子 | 網頁格子出現藍色覆蓋；放開後交換 |
| R171 AC4 | 2×2，開兩格的聲音 | 左上角是小音波，播放時跳動、暫停時停住；版型 1 時不顯示 |
| R171 AC5 | 設定 → yt-dlp | 「已是最新版」標籤正常 |
| R171 AC6 | 在影片上按右鍵；按左鍵 | 游標位置出現齒輪選單；左鍵只聽這一格 |
| R171 AC6 | 設定 → 滑鼠操作：左鍵改「播放／暫停」，重新開啟程式 | 左鍵暫停、播放；設定還在 |
| 0.9.3 AC7 | 設定 → 滑鼠操作 | 正常顯示；切換後重新開啟程式，設定還在 |
| 0.9.3 AC8 | 設定 → YouTube 小視窗 → 打開「開啟 App 時打開小視窗」，版型 1，重新開啟程式 | 小視窗打開；設定仍是打開 |
| 0.9.3 AC9 | 按齒輪 → 再按一次齒輪；齒輪 → 亮度 → 再按齒輪；YouTube ▾ 按兩次 | 每次第二下都關閉 |
| 版本 | 設定 → 關於；GitHub Releases | 0.9.3；Actions 自動發佈 `desktop-v0.9.3` |
