# 記住觀看進度、重開後的播放問題：手動驗收步驟

對應規格：`doc/specs/resume-and-play-fixes.md`（R53–R56）。單元測試見 `tests/unit/resume.test.ts`。

## 驗收用的來源

- YouTube：`https://www.youtube.com/watch?v=iG9CE55wbtY`（TED，20 分鐘）
- mp4：`https://media.w3.org/2010/05/sintel/trailer.mp4`（W3C 測試影片，52 秒）
- m3u8 點播：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`
- 網頁來源（YouTube 網頁播放）：`https://www.youtube.com/watch?v=kJQP7kiw5Fk`
- 本機測試網頁（`node tests/manual/web-pages/server.mjs`）：
  - `http://127.0.0.1:8701/nolength.html`：播放前不提供長度
  - `http://127.0.0.1:8701/blocked.html`：只能用網站自己的按鈕播放

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R53 AC1 | 重開程式後，還沒播放的 YouTube 點進度條 30% | 從那裡開始播放，有畫面，按鈕「❚❚」 |
| R53 AC2–AC3 | 按暫停，再點進度條；再按播放鈕 | 維持暫停；按鈕和狀態一致 |
| R54 AC1–AC2 | 重開後 nolength.html 的格子滑鼠移上去，按中央播放鈕 | 有中央鈕和左下鈕；按下後播放，進度條出現 |
| R54 AC3 | blocked.html 按中央播放鈕 | 5 秒後出現「無法直接播放，請按「直接操作」後按網站的播放鈕」，再 5 秒消失 |
| R55 AC1–AC3 | 四種來源各看到某個位置，按工具列的關閉鈕，再開啟 | 暫停在上次的位置；按播放接著看 |
| R55 AC5 | 影片播完後關閉再開啟 | 從頭開始 |
| R55 AC6–AC7 | 換位後關閉再開啟；更換網址 | 進度跟著影片；新網址從頭開始 |
| R55 AC9 | 看到某個位置後立刻關閉 | 重開後誤差 1 秒內 |
| R56 | 安裝後看 MultiView.exe 的內容 → 詳細資料 | 版本 0.4.2 |
