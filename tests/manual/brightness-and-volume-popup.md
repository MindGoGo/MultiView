# 每格亮度、總亮度、音量彈出滑桿：手動驗收步驟

對應規格：`doc/specs/brightness-and-volume-popup.md`（R40–R43）。單元測試見 `tests/unit/brightness.test.ts`。

## 驗收用的來源

- YouTube：`https://www.youtube.com/watch?v=jfKfPfyJRdk`
- m3u8：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`
- 網頁來源：任一有影片的新聞頁（影片模式），以及沒有影片的網頁（整頁模式）

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R40 AC1–AC3 | 某一格按「☀」，拖到 50%、150%，再按「重設」 | 拖曳時那一格跟著變暗／變亮，其他格和操作按鈕不變；重設後回到 100%，「☀」不再亮起 |
| R40 AC4 | YouTube、m3u8、網頁（影片模式、整頁模式）各調一次 | 都能調整 |
| R40 AC5 | 設成 60% 後關閉再開啟程式；和另一格換位 | 仍是 60%；亮度跟著影片移動 |
| R40 AC6 | 播放中拖曳亮度滑桿 | 影片持續播放，沒有重新載入 |
| R40 AC7 | 用沒有亮度欄位的舊設定檔啟動 | 每格都是 100% |
| R41 AC1–AC2 | 工具列「☀」拖到 50%；再把某一格設 120%、總亮度 80% | 四格都變暗；那一格實際 96%，其他格 80% |
| R41 AC3 | 關閉再開啟程式 | 總亮度保留 |
| R41 AC4 | 打開總亮度選單，滑鼠移到畫面下方 | 工具列不隱藏；關閉選單後才隱藏 |
| R42 AC1–AC3 | 操作區按「🔉」，拖到 30，再按「重設」 | 沒有常駐滑桿；按鈕顯示「🔉 30」，只有這一格變小聲；重設後回到 100 |
| R42 AC4 | 切換成 `3×3`，視窗縮到最小，滑鼠移到每一格（包含最上面一列和網頁來源的格子） | 所有操作按鈕都在格子裡、看得到、按得到 |
| R43 | `npm run dist`，看 exe 的內容 → 詳細資料 | `MultiView-0.3.1-portable.exe`，版本 0.3.1 |
