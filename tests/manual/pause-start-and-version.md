# 切到網頁時立即維持暫停、設定顯示版本號：手動驗收步驟

對應規格：`doc/specs/pause-start-and-version.md`（R75–R77）。單元測試見 `tests/unit/app-info.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R75 AC1–AC2 | YouTube 播放器暫停在 3:00，「YouTube ▾」→「回到網頁」；在網頁裡按播放 | 網頁停在 3:00 附近、幾乎不播出；按播放後照常播放 |
| R75 AC3 | 網頁模式暫停中切換廣告阻擋 | 同 AC1 |
| R76 | 打開「⚙ 設定」 | 最下方顯示灰色的「MultiView 版本 0.5.5」，點了沒有反應 |
| R77 | 安裝後看版本 | 0.5.5 |

## 2026-10-14 驗收紀錄

| 需求 | 結果 | 說明 |
|---|---|---|
| R75 AC1–AC2 | ✅ | 播放器暫停在 181.82 秒；網頁從 181 秒（網址的開始時間只能是整數秒）開始，停在 181.10 秒，實際只播了約 0.1 秒，5 秒後仍然暫停；在網頁裡按播放後照常播放 |
| R75 AC3 | ✅（程式判斷） | 切換廣告阻擋走同一個機制 |
| R76 | ✅ | 設定選單顯示「MultiView 版本 0.5.4」（改版本號前測試）且不能點 |
| R77 | ✅ | 安裝後版本 0.5.5 |
