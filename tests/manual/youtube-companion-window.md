# YouTube 小視窗（推薦、留言、聊天室、搜尋）：手動驗收步驟

對應規格：`doc/specs/youtube-companion-window.md`（R78–R83）。單元測試見 `tests/unit/companion.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R78 AC1 | 第 2 格（YouTube）按「YouTube ▾」→「留言」 | 小視窗開啟在「留言」分頁，上方顯示「第 2 格：影片名稱」 |
| R78 AC2 | 小視窗開著時，第 3 格按「YouTube ▾」→「推薦影片」 | 同一個小視窗切到「推薦」，顯示第 3 格的影片 |
| R78 AC3 | 第 3 格「更換網址」成其他 YouTube 影片 | 推薦自動換成新影片的推薦 |
| R78 AC4 | 移除第 3 格 | 推薦顯示「這一格沒有 YouTube 影片」 |
| R78 AC5 | 移動、調整小視窗 → 關閉 MultiView 再開啟 → 按工具列「YouTube 小視窗」 | 關閉時小視窗一起關、重開不自動開啟；按下後在上次的位置與大小、上次的分頁開啟 |
| R78 其他 | 留言捲動一段 → 切到推薦 → 切回留言；主視窗置頂、全螢幕 | 留言停在原本的位置；小視窗一直在主視窗上面 |
| R79 AC1 | 「推薦」分頁 | 只有推薦影片清單，沒有影片畫面也沒有聲音 |
| R79 AC2 | 點一部推薦影片 | 連結的格子播放那部影片；推薦換成新影片的推薦 |
| R80 AC1 | 「留言」分頁捲到底 | 載入更多留言 |
| R80 AC2 | 點留言裡的「3:15」 | 連結的格子跳到 3:15，留言網頁不換頁 |
| R81 AC1 | 連結的格子是正在直播的影片 →「聊天室」 | 顯示即時訊息並持續更新 |
| R81 AC2 | 一般影片 →「聊天室」 | 顯示「這部影片沒有聊天室（只有直播有）」 |
| R82 AC1 | 「搜尋」分頁 | 手機版排版，可以搜尋 |
| R82 AC2 | 有空格時點一部影片 | 放進第一個空格並播放；搜尋結果與捲動位置不變 |
| R82 AC3 | 版型「1」時點影片 | 取代那一格 |
| R82 AC4 | `2×2` 四格都有影片時點影片 | 主視窗切到最前面並跳出選擇要取代的格子 |
| R82 AC5 | 切到推薦再切回搜尋 | 搜尋結果和捲動位置不變 |
| R83 | 安裝後看「⚙ 設定」的版本 | 0.6.0 |

## 2026-11-01 驗收紀錄

以開發版、獨立的測試資料夾執行，透過開發工具（CDP）操作，畫面以實際螢幕截圖確認。
