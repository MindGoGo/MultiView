# 設定視窗、工具列改版、音量放大、讀取動畫：手動驗收步驟

對應規格：`doc/specs/ui-refresh-and-volume-boost.md`（R96–R101）。單元測試見 `tests/unit/ui-refresh.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R96 AC1 | 按工具列的齒輪 | 置中的設定視窗、背景變暗；左側「YouTube 播放」「yt-dlp」「關於」，預設「YouTube 播放」；影片繼續播放 |
| R96 AC2 | 直播的播放方式切到 yt-dlp；關閉再打開 | 立刻生效；仍是 yt-dlp |
| R96 AC3 | 切換「無法嵌入時自動改用網頁播放」 | 立刻生效 |
| R96 AC4 | 有新版時到「yt-dlp」按「更新到 <版本>」 | 「正在更新…」→ 已是最新版，工具列提示 |
| R96 AC5 | 「關於」 | MultiView 版本 0.7.1 |
| R96 AC6 | Esc、✕、點背景；開著時按 Space、M | 都會關閉；快捷鍵不作用 |
| R96 AC7 | 切到「yt-dlp」後關閉再打開；重開程式 | 顯示「yt-dlp」；重開後「YouTube 播放」 |
| R96 AC8 | 視窗最小尺寸打開設定 | 完整顯示、可以捲動 |
| R97 AC1–AC3 | 看工具列、滑鼠移上去、按各按鈕 | 圖示分段按鈕、名稱提示、功能不變、作用中是強調色 |
| R97 AC4 | 視窗最小寬度 | 按鈕都看得到、按得到 |
| R97 AC5 | 按總亮度 | 顯示百分比、出現滑桿 |
| R98 AC1、AC2 | yt-dlp、m3u8 的格子音量拉到 200 | 範圍 0–200，超過 100 的部分是橘色；聲音明顯變大、沒有破音 |
| R98 AC3 | 內嵌、網頁、mp4 網址的格子 | 範圍 0–100 |
| R98 AC4 | AC1 的格子改成內嵌，再改回 | 顯示 100、最大 100；改回後 200 |
| R98 AC5、AC6 | 150 時重開；按靜音再取消 | 仍是 150；靜音沒有聲音、取消後回到 150 |
| R99 AC1–AC3 | 解析、載入、斷線 | 中央彈跳的小生物＋文字；開始播放後消失 |
| R99 AC4 | 讀取中按移除、更換網址 | 可以按 |
| R99 AC5 | `3×3` | 小生物縮小、不超出格子 |
| R99 AC6 | Windows 開啟「減少動畫」 | 仍然彈跳 |
| R100 AC1 | yt-dlp 一般影片 1080p 播兩分鐘 | 往後緩衝約 60 秒 |
| R100 AC2 | `fg1H4WCdkNI` 1080p 從 3:50 播到 4:30 | 時間連續 |
| R100 AC3 | 倒轉 5 秒 | 立即播放 |
| R101 | `npm run dist`、安裝 | `MultiView-Setup-0.7.1.exe`，「關於」顯示 0.7.1 |

## 2026-11-06 驗收紀錄

以 build 後的開發版、獨立的測試資料夾執行，透過開發工具（CDP）讀取畫面、操作按鈕、截圖；最小尺寸以 CDP 模擬 480×270。這台電腦的 Windows 開著「減少動畫」。

| 需求 | 結果 | 說明 |
|---|---|---|
| R96 AC1 | ✅ | 截圖確認：置中、背景變暗、三個分類、預設「YouTube 播放」；播放方式是兩段選擇按鈕，自動網頁播放是開關 |
| R96 AC4 | ✅（部分） | 「yt-dlp」分類顯示「2026.10.26 已是最新版」、按鈕「檢查更新」停用；有新版時的按鈕以單元測試驗證，更新流程沿用 R93（0.7.0 已實測） |
| R96 AC6 | ✅ | Esc 關閉；開著時送出 M（全部靜音）→ 有聲音的格子仍有聲音（修正：原本直接送給 window 的按鍵會穿過，改成程式本身也檢查設定視窗是否開著）；關閉後 M 才生效 |
| R96 AC8 | ✅ | 480×270：設定視窗在視窗內（16,16–464,254），內容可以捲動，分類收窄 |
| R96 AC2、AC3、AC5、AC7 | ⏳ | 未逐項操作（切換方式沿用 R88、R49 的處理） |
| R97 AC1–AC3 | ✅ | 截圖確認版型五個圖示（目前版型反白）、播放／暫停／靜音一組、右側圖示、─ ✕ 靠右 |
| R97 AC4 | ✅ | 修正後 480 像素寬時 16 個按鈕都在視窗內（修正前全螢幕、設定、最小化、關閉被擠出去） |
| R98 AC1 | ✅（部分） | yt-dlp 格子滑桿最大 200，拉到 200 後按鈕顯示 200、超過 100 的部分是橘色，播放持續、沒有錯誤。**聲音變大、沒有破音需要使用者用耳朵確認** |
| R98 AC3–AC7 | ✅（單元測試） | 能不能放大的判斷、實際音量、保存範圍以單元測試驗證 |
| R99 AC1 | ✅ | 解析中出現小生物與「解析中…」；開始播放後消失 |
| R99 AC6 | ✅ | 這台電腦開著「減少動畫」，小生物仍然彈跳（依使用者要求修改規格後） |
| R99 AC2–AC5 | ⏳ | 未逐項操作；2×2 時小生物寬約 50 像素 |
| R100 AC1、AC3 | ✅ | 1080p 一般影片穩定播放時往後緩衝 61–67 秒（一個片段約 7 秒）、往前保留 30–38 秒；倒轉 5 秒立即播放 |
| R100 AC2 | ⏳ | 原本的問題無法重現，需要使用者再觀察 |
