# 自訂版型：手動驗收步驟

對應規格：`doc/specs/custom-layouts.md`（R170）。單元測試見 `tests/unit/custom-layouts.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R170 AC1 | 版型 2×2，按工具列的鉛筆「編輯版型」 | 工具列多「自訂 1」並選取，提示「已建立「自訂 1」」；畫面仍是 2×2，每格有編號與「左右切」「上下切」「刪除這格」；鉛筆變成「完成」「刪除這個版型」 |
| R170 AC2 | 版型 1 → 編輯 → 按「上下切」，再在第 2 格按「上下切」→ 拖曳兩條分隔線 → 完成 → 關掉程式再開 | 上中下 3 格；「自訂 N」仍在，選取後格子與比例相同 |
| R170 AC3 | 左右切後在右邊那格上下切 | 1 左、2 右上、3 右下；按 2 只聽右上；1～3 的快捷鍵、單格全螢幕、拖曳換格都正常 |
| R170 AC4 | 第 2 格有影片，在第 1 格按「左右切」 | 影片沒有重新載入，留在原本那格（變成第 3 格） |
| R170 AC5 | 刪除有影片的格子 → 切到 3×3 | 格子消失、空間給旁邊的格子，提示有來源暫時隱藏；3×3 時影片出現 |
| R170 AC6 | 一直切同一格；切到 9 格；刪到剩 1 格 | 太小時切開的按鈕停用（滑鼠移上去「這一格太小，不能再切」）；9 格時「最多 9 格」；剩 1 格時刪除停用 |
| R170 AC7 | 建立 5 個自訂版型後，選固定版型按「編輯版型」 | 提示「自訂版型最多 5 個，請先刪除一個」 |
| R170 AC8 | 編輯自訂版型 →「刪除這個版型」→ 刪除 | 先跳出確認；刪除後換回 2×2，工具列少了那個版型 |
| R170 其他 | 編輯中按 Esc | 離開編輯（等於「完成」） |
