# 中央播放鈕、YouTube 字幕、畫質選單：手動驗收步驟

對應規格：`doc/specs/captions-and-quality-menu.md`（R30–R33）。單元測試見 `tests/unit/captions-quality.test.ts`。

## 驗收用的影片

- 有多種字幕的 YouTube 影片：`https://www.youtube.com/watch?v=iG9CE55wbtY`（TED，64 種字幕）
- 沒有字幕的 YouTube 影片：`https://www.youtube.com/watch?v=aqz-KE-bpKQ`
- 多種畫質的 m3u8：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R30 AC1–AC3 | 滑鼠移到播放中的格子；按中央鈕；點中央鈕以外的地方 | 出現半透明「❚❚」，靜止 2 秒消失；按下只暫停這一格；點其他地方切換聲音 |
| R30 AC4–AC6 | 整頁模式的格子；視窗縮到最小並切換成 `3×3`；按「直接操作」 | 都沒有中央鈕；最小格子用進度條旁的播放鈕 |
| R31 AC1–AC3 | TED 影片播放後按「CC」，選「中文（台灣）」，再選「關閉」 | 列出語言；3 秒內出現中文字幕，CC 變成啟用；關閉後字幕消失 |
| R31 AC4 | 選日文後關閉再開啟程式，按播放；和另一格換位 | 播放後自動出現日文字幕；CC 設定跟著影片移動 |
| R31 AC5 | 沒有字幕的影片播放後按「CC」 | 灰色的「這部影片沒有字幕」 |
| R31 AC7 | 程式開啟後還沒播放的 YouTube 格子按「CC」 | 灰色的「播放後才能選擇字幕」 |
| R32 AC1 | m3u8 按畫質按鈕，選 720p | 選單列出自動和 1080p～184p；15 秒內解析度 1280×720 |
| R32 AC2 | `3×3` 的 YouTube 選 720p；`1` 版型選 480p | 回報 hd720；YouTube 詳細統計資料的「最佳」解析度是 480p |
| R32 AC3–AC4 | 選回自動；關閉後重新開啟；換位 | 回到自動；選擇保留並跟著影片移動 |
| R33 | `npm run dist`，看 exe 的內容 → 詳細資料 | `MultiView-0.3.0-portable.exe`，版本 0.3.0 |
