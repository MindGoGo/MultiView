# 介面微調與浮在影片上的操作按鈕（桌面版）：手動驗收步驟

對應規格：`doc/specs/floating-controls.md`（R165、R166）。單元測試見 `tests/unit/r165-desktop.test.ts`、`tests/unit/floating-controls.test.ts`、`tests/unit/badge-and-headers.test.ts`、`tests/unit/companion.test.ts`。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R165 AC1 | 設定 → YouTube 小視窗 → 打開「開啟 App 時打開小視窗」，版型 `1`，關閉再開啟程式 | 小視窗直接打開，連結第 1 格 |
| R165 AC1 | 同上，改成版型 `2x2` 後重新開啟；或把設定關閉後重新開啟 | 不打開 |
| R165 AC2 | 一格用 yt-dlp、一格用內嵌播放器，滑鼠移上去 | yt-dlp 的格子左上角聲音按鈕右邊有綠點；內嵌播放器沒有標示；停在聲音按鈕上，提示說明播放方式 |
| R165 | 看中間的播放鈕 | 比之前小一點（52px） |
| R165 AC3 | 從 YouTube ▾ 打開小視窗 | 上方只有影片名稱 |
| R166 AC1 | 滑鼠移到格子上 | 沒有整塊的底；左上聲音、中間播放、右上 YouTube ▾ 與齒輪、左下時間、右下移動與全螢幕、最下面細進度條；上下有淡淡的漸層 |
| R166 AC1 | 點影片上按鈕以外的地方 | 照常切換這一格的聲音 |
| R166 AC2 | 齒輪 → 音量、亮度 | 齒輪下方出現滑桿，可以調 |
| R166 AC2 | 齒輪 → 畫質、語音、字幕 | 齒輪下方出現選單，可以選 |
| R166 AC2 | 齒輪 → 直接操作、廣告阻擋、顯示整個網頁、改用網頁播放、加入最愛、更換網址、移除 | 各自作用，和 0.8.4 的按鈕相同 |
| R166 AC2 | 齒輪選單開著時再按齒輪 | 關閉 |
| R166 AC3 | 滑鼠移到細進度條上、拖曳 | 變粗、顯示預覽縮圖；放開後跳轉，拖曳中按鈕不隱藏 |
| R166 AC4 | 整頁模式的網頁格子：滑鼠移到右下「⋯」 | 出現同樣的按鈕；按鈕以外可以直接點網頁；上一頁、下一頁可以用 |
| R166 AC5 | 可回放的 YouTube 直播（yt-dlp）往回拖 | 膠囊顯示 `-m:ss`；按一下回到「直播」 |
| R166 AC6 | 最上排的格子，滑鼠移到齒輪上 | 工具列不蓋住齒輪 |
| R166 AC7 | `3×3`、視窗最小 | 按鈕縮小，沒有時間膠囊，都按得到 |
| R166 | 滑鼠靜止 2 秒；開著選單時靜止 | 按鈕隱藏；選單開著時不隱藏 |
| R166（R161） | yt-dlp 播放有業配標記的影片，滑鼠移上去 | 細進度條上有色塊，滑鼠移上去一起變粗；跳過提示出現時在右上按鈕下面 |
| 版本 | 設定 → 關於；GitHub Releases | 0.9.1；Actions 自動發佈 `desktop-v0.9.1` |

## 2026-11-24 開發時的檢查

以 build 後的畫面在無頭 Chromium 執行（`window.multiview` 用假的介面、本機 mp4），截圖確認 `2x2` 與 `3x3`（800×500）的按鈕位置、齒輪選單、音量滑桿與最上排避開工具列。實際 Electron 程式、YouTube、整頁模式的網頁尚未實測。
