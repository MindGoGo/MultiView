# 支援一般影片網頁：手動驗收步驟

對應規格：`doc/specs/web-page-source.md`（R12–R18）。單元測試涵蓋的部分見 `tests/unit/web-*.test.ts`、`tests/unit/adblock.test.ts`，這份文件只列需要實際開啟程式的驗收條件。

## 準備

1. 啟動本機測試頁（需要 Node 18 以上；在專案根目錄）：
   ```
   node tests/manual/web-pages/server.mjs
   ```
   會開兩個網址：`http://127.0.0.1:8701/`（網域 A）和 `http://localhost:8702/`（網域 B，模擬跨網域子框架）。
2. 啟動程式：`npm run dev`，或執行打包後的 exe。
3. 測試頁的網址都列在 `http://127.0.0.1:8701/`。
4. 廣告阻擋的測試頁要用 `http://mv.localtest.me:8701/ads.html` 開啟（`localtest.me` 會解析到本機）。不能用 IP 位址或 localhost，因為廣告清單的通用隱藏規則不適用；也不能用 `ads.` 開頭的網域，因為清單會擋下整個網域。

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R13 AC1 | 貼上正在直播的 Twitch 頻道網址（例如 `https://www.twitch.tv/<頻道>`） | 10 秒內格子只顯示直播畫面 |
| R13 AC2 | 貼上 `https://www3.nhk.or.jp/nhkworld/en/live/` | 10 秒內格子只顯示直播畫面。第一次開啟會出現 cookie 同意提示：先切成整頁模式按掉，再按「只顯示影片」 |
| R13 AC3 | `multi.html` | 顯示綠色的「BIG 主要影片」 |
| R13 AC3-1 | `frame-parent.html`（跨網域子框架）、`frame-same.html`（同網域子框架） | 都只顯示藍色的「IFRAME 主要影片」 |
| R13 AC3-2 | `swap.html` | 3 秒後，2 秒內改成顯示「正片 B」 |
| R13 AC3-3 | `remove.html` | 3 秒後變成黑色畫面；再過 15 秒切換成整頁模式，並顯示「找不到影片…」提示 5 秒 |
| R13 AC4 | `novideo.html` | 約 15 秒後切換成整頁模式並顯示提示 |
| R13 AC5 | 放 4 個來源後拖曳分隔線、換位、切換版型 | 網頁不重新載入（畫面上的數字持續增加，不會歸零） |
| R13 AC7 | `3×3` 版型放入 Twitch 頻道頁 | 找得到影片並填滿格子；切成整頁模式時是窄版排版 |
| R14 AC1、AC3 | `novideo.html` 進入整頁模式後，點連結、在輸入框打字、捲動；再點「開新視窗的連結」 | 可以操作；一般連結在同一格換頁，開新視窗的連結沒有反應；關閉程式後設定檔仍然是原本的網址 |
| R14 AC2 | 整頁模式下按「只顯示影片」：(a) `novideo.html` 先按頁面上的「顯示影片」再按 (b) 直接按 | (a) 切回影片模式 (b) 留在整頁模式，顯示「找不到影片」3 秒 |
| R14 AC4 | 整頁模式的輸入框中按 Space、M、數字鍵 | 只輸入文字，聲音和播放狀態不變 |
| R14 AC5 | 接著點另一個影片模式的格子，按數字鍵 | 聲音獨占給對應的格子 |
| R14 AC6 | 整頁模式的輸入框中按 F11，再按 Esc | F11 切換全螢幕；Esc 不離開全螢幕 |
| R14 AC7 | 視窗縮到最小（480×270）並切換成 `3×3` | 網頁來源的操作按鈕只顯示圖示，全部看得到、按得到 |
| R15 AC1–AC4、AC6 | 放兩個 `multi.html` 和一個 YouTube；點擊、調音量、全部播放／暫停、切換版型讓網頁來源隱藏 | 和第一版的影片來源規則相同 |
| R15 AC5 | 放 `autoplay.html` 後關閉程式再開啟 | 開啟後維持暫停；按 Space 才播放 |
| R15 AC7 | `autoplay.html` 播放中切成整頁模式，按網站自己的「播放／暫停」按鈕暫停，再按「只顯示影片」 | 維持暫停 |
| R16 AC1、AC2、AC6 | `https://no-such-host.invalid`、`/missing`、`/slow` | 顯示「無法載入網頁」和「重試」；`/slow` 約 30 秒後才顯示 |
| R16 AC3 | 在錯誤狀態按「重試」 | 重新載入同一個網址 |
| R16 AC4 | 網頁程序當掉（可以用開發者工具的 `Page.crash`） | 顯示「無法載入網頁」，其他格繼續播放 |
| R16 AC5 | `drm.html` | 顯示「這個影片有版權保護，無法播放」，沒有「重試」 |
| R16 AC7 | `broken-image.html` | 正常播放，不顯示錯誤 |
| R17 AC1 | `http://mv.localtest.me:8701/ads.html`，切成整頁模式看結果 | 廣告網址「被擋下」、一般網址「已載入」、廣告區塊「被隱藏」 |
| R17 AC2 | 在另一格放同一個網址，按「廣告阻擋：開」關閉 | 該格重新載入，三項都變成沒有被擋；第一格不受影響 |
| R17 AC3 | 關閉程式再開啟 | 第二格仍然是「廣告阻擋：關」 |
| R17 AC5 | 拔掉網路線後開啟程式，放入本機測試頁 | 廣告阻擋照常運作，不顯示錯誤 |
| R18 AC1 | 整頁模式登入 Twitch，關閉程式再開啟 | 仍然是登入狀態 |
| R18 AC2、AC3 | 兩格放 `cookie.html`，在第一格按「設定一天有效的 cookie」，第二格重新載入；再關閉程式後開啟 | 第二格讀得到；重新開啟後也讀得到 |

## 2026-10-08 驗收紀錄

開發時用本機的開發版程式（`electron .`，獨立的設定資料夾）搭配 Chrome DevTools Protocol 操作和截圖驗證。滑鼠點擊和一般按鍵是由 DevTools Protocol 送進畫面；F11、Esc 是用 Windows SendKeys 送出的真實按鍵（DevTools Protocol 送的按鍵不會經過主程序的攔截）。

| 需求 | 結果 | 說明 |
|---|---|---|
| R13 AC1 | ✅ | `twitch.tv/godjj`（2×2）、`twitch.tv/krapycoco`（3×3）都在 10 秒內填滿格子 |
| R13 AC2 | ✅ | NHK World 填滿格子（按掉 cookie 提示之後） |
| R13 AC3、AC3-1、AC3-2、AC3-3、AC4、AC5、AC7 | ✅ | 依上表步驟，截圖確認 |
| R14 AC1–AC7 | ✅ | AC6 用 SendKeys 確認；AC7 量測 160×90 格子中 7 個操作元件都在格子內、點得到 |
| R15 AC1–AC7 | ✅ | 透過讀取影片的 paused / volume / muted 和網頁的靜音狀態確認 |
| R16 AC1–AC7 | ✅ | AC4 用 `Page.crash`；AC6 在 28 秒時仍在載入、32 秒時顯示錯誤 |
| R17 AC1–AC3 | ✅ | |
| R17 AC4 | ✅ | YouTube 來源在另一個網站資料區，不經過廣告阻擋；內嵌 YouTube 框架不阻擋由單元測試確認 |
| R17 AC5 | ⏳ | 沒有實際拔網路測試；清單從程式內的檔案讀取（單元測試確認不需要網路） |
| R18 AC1 | ⏳ | 需要 Twitch 帳號，未測 |
| R18 AC2–AC4 | ✅ | AC4：主畫面（YouTube 使用的資料區）讀不到網頁來源設定的 cookie |
