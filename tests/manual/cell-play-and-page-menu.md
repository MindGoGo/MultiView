# 播放／暫停按鈕、右鍵選單與上下頁：手動驗收步驟

對應規格：`doc/specs/cell-play-and-page-menu.md`（R26–R29）。單元測試見 `tests/unit/page-menu.test.ts`。

## 準備

1. `node tests/manual/web-pages/server.mjs`
2. `npm run dev` 或執行 `MultiView-0.2.1-portable.exe`
3. 放入 `http://127.0.0.1:8701/novideo.html`，按「顯示整個網頁」切成整頁模式

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R26 AC1–AC3 | 四格播放，按其中一格進度條左邊的「❚❚」，再按「▶」；直播、網頁影片也各試一次 | 只有那一格暫停／播放，聲音不變 |
| R26 AC4 | mp4 播完後按「▶」 | 從頭播放 |
| R26 AC6 | 視窗縮到最小、`3×3` | 按鈕仍然顯示並可以按 |
| R26 AC7 | `autoplay.html` 整頁模式，按網站自己的暫停 | 1 秒內按鈕變成「▶」 |
| R27 AC1 | 選取網頁上的標題文字，按右鍵 →「複製」，到記事本貼上 | 貼上那段文字 |
| R27 AC2 | 在網頁的輸入框按右鍵 →「貼上」；再試「全選」「剪下」 | 貼入剪貼簿的文字；全選、剪下照常作用 |
| R27 AC3 | 沒有選取文字時，在空白處按右鍵 | 剪下、複製、貼上是灰色 |
| R27 AC4 | 在「同一格換頁到 multi.html」連結上按右鍵 →「複製連結網址」，到記事本貼上 | `http://127.0.0.1:8701/multi.html` |
| R27 AC5 | 按右鍵 →「重新整理」 | 重新載入，維持整頁模式 |
| R27 AC6 | 影片模式的格子按右鍵 | 不出現選單 |
| R28 AC1–AC2 | 剛載入時看「←」「→」；點連結換頁；按「←」「→」 | 剛載入都是灰色；換頁後「←」可以按；上下頁正確 |
| R28 AC3 | 游標在整頁模式的網頁上按滑鼠的上一頁／下一頁側鍵；游標在影片模式的格子上按 | 前者換頁；後者沒有變化 |
| R28 AC4、AC5 | 換頁後關閉再開啟；換頁後切換廣告阻擋 | 都載入當初貼上的網址，「←」「→」是灰色 |
| R29 | `npm run dist`，看 exe 的檔名和內容 → 詳細資料 | `MultiView-0.2.1-portable.exe`，版本 0.2.1 |
