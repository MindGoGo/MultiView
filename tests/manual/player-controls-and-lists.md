# 進度條、單格全螢幕、清單與畫質：手動驗收步驟

對應規格：`doc/specs/player-controls-and-lists.md`（R19–R25）。單元測試見 `tests/unit/progress.test.ts`、`solo.test.ts`、`lists.test.ts`、`lists-store.test.ts`、`quality.test.ts`；這份文件只列需要實際開啟程式的驗收條件。

## 準備

1. 本機測試頁：`node tests/manual/web-pages/server.mjs`（`bunny-10s.mp4` 支援 Range，可以跳轉；`vod.html` 是網頁中的一般影片）。
2. 啟動程式：`npm run dev`，或執行打包後的 exe。
3. 驗收用的影片：
   - mp4：`http://127.0.0.1:8701/bunny-10s.mp4`
   - m3u8 點播（多種畫質）：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`
   - YouTube 一般影片（有 1080p）：`https://www.youtube.com/watch?v=aqz-KE-bpKQ`
   - YouTube 可回放的直播：`https://www.youtube.com/watch?v=LuKwFajn37U`（DW News）
   - 網頁中的一般影片：`http://127.0.0.1:8701/vod.html`；網頁中的直播（不能回放）：`http://127.0.0.1:8701/multi.html`

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R19 AC1–AC4 | 放 mp4、m3u8 點播、YouTube 一般影片，滑鼠移到格子上；點進度條中間、拖曳進度條 | 顯示「目前時間／總長度」；點擊後跳轉並維持播放／暫停；拖曳中只顯示時間，放開才跳 |
| R19 AC5 | 放 DW 直播，往回點進度條，再按「回到直播」 | 顯示 `-h:mm:ss`；按下後變成「● LIVE」並停用 |
| R19 AC6 | 放 `multi.html`（網頁中的直播） | 只顯示「● LIVE」 |
| R19 AC7 | 放 `vod.html`，點進度條 80% | 網頁中的影片跳到約 8 秒 |
| R19 AC9 | 視窗縮到最小並切換成 `3×3` | 進度條在格子最下面、點得到，不顯示時間 |
| R19 AC10、AC11 | 點靜音格子的進度條；mp4 播完後點進度條中間 | 聲音不變；跳轉後維持暫停 |
| R20 AC1–AC3、AC9 | `2×2` 四格播放、第 3 格先暫停、第 5 格有隱藏來源；按第 2 格的「全螢幕」，再按 Esc | 只看得到第 2 格，其他暫停；離開後只有原本在播放的恢復；過程中沒有「暫時隱藏」提示 |
| R20 AC4 | 先按 F11，再進入單格全螢幕，按「離開全螢幕」 | 回到分割畫面，視窗維持全螢幕 |
| R20 AC5–AC7 | 單格全螢幕時按 Space、數字鍵、`3×3`、「移除」 | Space 只切換放大的那一格；數字鍵沒有作用；按 `3×3` 先回到分割畫面再切換；移除後回到分割畫面 |
| R20 AC10 | 放大整頁模式的網頁來源，焦點在網頁輸入框，按 Esc，再按 F11 | Esc 留在單格全螢幕；F11 離開 |
| R21 AC1–AC5 | 打開「清單」；點一下某一筆（有空格／沒有空格）；拖到有影片的格子；拖到面板上放開 | 依規格放入、提示、更換（保留聲音和音量）、不變 |
| R21 AC6–AC9 | 編輯：改成 `ftp://x`、清空名稱、改成另一筆的網址；刪除；在編輯框按 Space、M、數字 | 「不支援的網址」；名稱變成網址；「清單中已經有這個網址」；刪除成功；只輸入文字 |
| R21 AC10、AC11 | 關閉後重新開啟；把 `%APPDATA%\MultiView\lists.json` 改成 `{ broken` 後重新開啟 | 清單還在；清單是空的、壞掉的檔案改名成 `lists.json.bak` |
| R22 AC1–AC6 | 格子按 ☆／★；另一格放同一個網址；面板「新增」（名稱空白、重複網址）；刪除最愛 | 依規格 |
| R23 AC1–AC7 | 貼上網址、重播同一個網址、改名後重播、無法載入的網址、重新開啟程式、全部清除（取消／清除） | 依規格 |
| R24 AC1 | `3×3` 的 YouTube 格子按「畫質：自動」切成「高」 | 播放器回報的畫質在 30 秒內變成 1080p；實際畫面在已經緩衝的片段播完後才變清楚 |
| R24 AC2 | m3u8 格子切換「高／自動」 | 高：1920×1080；自動（3×3）：512×288 |
| R24 AC3–AC4 | 看 mp4、網頁格子的按鈕；重新開啟程式；換位 | 沒有畫質按鈕；設定保留並跟著影片移動 |
| R25 | `npm run dist`，看 exe 的檔名和內容 → 詳細資料 | `MultiView-0.2.0-portable.exe`，版本 0.2.0 |
