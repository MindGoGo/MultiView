對應規格：`doc/specs/ios-app.md`（R119–R144）。單元測試在 `ios/MultiViewCore/Tests/`，由 GitHub Actions 執行（沒有 Mac，不能在本機跑）。

安裝方式見 `doc/features/ios-app.md`。

## SponsorBlock：跳過業配（R161，`ios-v0.0.35`）

準備：設定 → YouTube 的播放方式 →「一般影片」選 yt-dlp。找一部有業配標記的熱門影片：科技類 YouTuber（例如 Linus Tech Tips、MKBHD）最近的影片大多有業配；可以先在電腦的瀏覽器裝 SponsorBlock 擴充功能，確認那部影片的進度條上有綠色色塊、記下業配的時間。（和 Android 版 `tests/manual/android-app.md` 的 K 組相同，多了子母畫面。）

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R161 | 設定 → SponsorBlock（跳過業配） | 「自動跳過片段」預設開啟；下面 8 個類別只勾了「業配」；有資料來源（SponsorBlock，CC BY-NC-SA 4.0）的說明 |
| R161 AC4 | 貼上那部影片，等它開始播放，點一下格子 | 進度條上業配的位置有綠色色塊（和瀏覽器擴充功能的位置相同） |
| R161 AC4 | 按住進度條拖過綠色色塊 | 預覽提示多一行「業配」；離開色塊後消失 |
| R161 AC1 | 拖到業配開始前幾秒放開，等它播進業配 | 自動跳到業配結束，右上角出現「● 已跳過業配　取消」，約 5 秒後消失 |
| R161 AC1 | 工具列顯示時（點一下格子），最上面一列的格子發生跳過 | 提示在工具列下面，不被擋住 |
| R161 AC2 | 再拖回業配開始前幾秒，播進業配 | 不再跳過（同一段跳過一次後，倒回去看不再跳） |
| R161 AC2 | 換另一部有業配的影片，播進業配後馬上按「取消」 | 跳回業配開頭繼續播放，整段業配播完都不會再被跳 |
| R161 AC3 | 第三部影片：直接把進度條拖到業配中間放開；雙擊右邊快轉到業配裡也試一次 | 從那裡繼續播放，不會被跳走 |
| R161 AC6 | 播放有業配的影片（只有這一格有聲音），在業配開始前幾秒按電源鍵鎖定螢幕 | 聽得出來業配被跳過（聲音跳到業配之後）；鎖定畫面的進度條也跳過去；解鎖回來位置在業配之後 |
| R161 AC6 | 鎖定螢幕時用鎖定畫面的播放／暫停，再播到下一段業配（如果有） | 同樣跳過 |
| R161 AC7 | 播放有業配的影片（只有這一格有聲音），在業配開始前幾秒從畫面底部往上滑回到主畫面 | 自動進入子母畫面繼續播放，播到業配時子母畫面的畫面跳到業配之後 |
| R161 AC7 | 用操作列的「⋯」→「子母畫面」手動開子母畫面，回到主畫面播到業配 | 同樣跳過 |
| R161 AC8 | `1×2`：兩格各放一部有業配的影片（或同一部），同時播放 | 各自跳過、各自出現提示；在一格按「取消」不影響另一格 |
| R161 AC5 | 設定 → 勾「開場」「片尾」 | 回到格子，進度條多了青色（開場）、深藍色（片尾）的色塊（影片有標記的話），播到時也會跳過，提示「已跳過開場」 |
| R161 AC5 | 設定 → 關閉「自動跳過片段」 | 色塊馬上消失，播到業配不跳 |
| R161 AC5 | 從 App 切換器滑掉 App 再開 → 設定 | 剛才的設定（關閉／勾選的類別）保留。測完改回開啟、只勾業配 |
| R161 | 用行動數據（關 Wi-Fi）播一部有業配的新影片 | 一樣有色塊、會跳過 |
| R161 AC9 | 開飛航模式後再關、或在網路很差時播一部新影片 | 影片照常播放，沒有錯誤訊息（只是沒有色塊） |
| R161 AC9 | 同一部影片用內嵌播放器（設定改成內嵌）、直播、網頁格子 | 沒有色塊、不跳過 |

如果鎖定螢幕或子母畫面時**沒有**跳過，請回報是哪一種情況（鎖定螢幕、自動子母畫面、手動子母畫面），以及回到 App 後位置是不是在業配裡：規格 R161 寫的是定時觀察器加片段開頭的觀察器兩種都會觸發，沒有跳過表示兩種都沒執行，要改做法。

## 只有一格時的顯示、上下排的小視窗、在小視窗裡看（R162，`ios-v0.0.36`）

在 iPhone 上測。準備：放兩部 YouTube 影片（一格有聲音），工具列的旋轉按鈕沒有固定方向。（和 Android 版 `tests/manual/android-app.md` 的 L 組相同；iOS 沒有返回鍵，改用「上一頁」按鈕與滑動手勢。）

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R162 AC1 | 版型 `2`，等工具列消失 | 有聲音的格子左上角有小喇叭 |
| R162 AC1 | 切到版型 `1`，等工具列消失；再切回 `2`、兩指張開進入全螢幕，等工具列消失 | 兩種情況左上角都沒有小喇叭；點一下叫出工具列時左上角的靜音按鈕照常出現 |
| R162 AC2 | 直向、版型 `1`，播放中打開「YouTube 小視窗」 | 影片在上面（占滿寬度、16:9，從動態島下面開始），小視窗在下面；影片繼續播放、沒有重新載入；工具列 3 秒後自動隱藏 |
| R162 AC2 | 在下面的小視窗切到「留言」「推薦」，點一部推薦影片 | 上面那格換成那部影片 |
| R162 AC2 | 轉成橫向 | 小視窗回到原本的位置（占滿寬度、蓋在影片上） |
| R162 AC2 | 轉回直向，關掉小視窗 | 影片回到占滿畫面 |
| R162 AC3 | 版型 `2`、直向，兩指張開進入全螢幕（轉成橫向），點一下叫出工具列，按「YouTube 小視窗」 | 轉成直向，上面影片、下面小視窗 |
| R162 AC3 | 按小視窗的關閉 | 轉回橫向的全螢幕；再兩指捏合離開全螢幕，回到直向的分割畫面 |
| R162 AC3 | 全螢幕中再打開小視窗（轉成直向），不關小視窗，兩指捏合離開全螢幕 | 回到直向的分割畫面，小視窗還開著 |
| R162 AC3 | 版型 `1`、直向，先打開小視窗（上下排），再兩指張開進入全螢幕 | 不轉成橫向，維持上下排 |
| R162 AC3 | 用旋轉按鈕固定成橫向，進入全螢幕，打開小視窗，再關掉 | 打開時轉成直向、上下排；關掉時轉回橫向 |
| R162 AC4 | 小視窗 → 搜尋分頁，按關閉左邊的格子圖示 | 圖示變成藍色的播放圖示，上方提示「點影片：在小視窗裡看」 |
| R162 AC4 | 搜尋並點一部影片 | 在小視窗裡打開影片頁，格子不變；約 3 秒後小視窗上方的標題與分頁隱藏，只剩一條小把手 |
| R162 AC4 | 點小把手 | 標題與分頁出現，左邊有「上一頁」，右邊有「放進格子」；3 秒沒有操作再隱藏 |
| R162 AC6 | 按「上一頁」；在網頁上從左邊緣往右滑也試一次 | 小視窗的網頁回上一頁；回到第一頁時「上一頁」按鈕不見 |
| R162 AC4 | 再點一部影片，叫出標題，按「放進格子」 | 影片放進空格（沒有空格時詢問要取代哪一格）；小視窗裡的影片暫停 |
| R162 AC5 | 有一格在播放時，在小視窗裡播放一部影片（有聲音） | 播放中的格子暫停，只聽得到小視窗的聲音 |
| R162 AC5 | 搜尋結果裡自動播放的靜音預覽（如果有） | 格子不暫停 |
| R162 AC5 | 關掉小視窗 | 小視窗的聲音停止，剛才暫停的格子恢復播放、有聲音 |
| R162 AC5 | 再打開小視窗播放影片（格子暫停），切到「留言」分頁 | 小視窗的聲音停止，格子恢復播放 |
| R162 AC5 | 回到搜尋分頁播放影片（格子暫停），點格子叫出操作列、按格子的播放 | 小視窗的影片暫停，格子播放 |
| R162 AC5 | 格子分別用 yt-dlp（原生播放器）、內嵌播放器各測一次上面的暫停與恢復 | 兩種都會暫停、恢復；恢復後原生播放器的格子可以多格同時出聲（和之前一樣） |
| R162 AC4 | 從 App 切換器滑掉 App 再開，打開小視窗 | 還是「在這裡看」；按圖示改回格子圖示（提示「點影片：放進格子」），點影片又會放進格子 |
| R162 AC7 | 推薦、留言分頁點影片；聊天室 | 和之前一樣（換掉連結的格子；影片頁不播放） |

如果在小視窗裡播放時格子**沒有**暫停、或關掉小視窗後格子**沒有**恢復（或恢復了但沒有聲音），請回報格子的播放方式（yt-dlp、內嵌、網頁）：規格 R162 的「WKWebView 播放時對 `AVAudioSession` 與格子的影響」是推測，要依實測調整。
