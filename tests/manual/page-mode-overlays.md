# 整頁模式時工具列與操作列不擋網頁：手動驗收步驟

對應規格：`doc/specs/page-mode-overlays.md`（R116–R118）。單元測試見 `tests/unit/pointer-zones.test.ts`。

測試網頁：`node tests/manual/web-pages/server.mjs` 後，放入 `http://127.0.0.1:8701/page-top-bar.html`（頂端有搜尋欄，底部有按鈕區，沒有影片；15 秒後自動切成整頁模式）。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R116 AC1 | 滑鼠移到距離上緣 10–40 像素（包括水平中間），點搜尋欄 | 工具列不出現，可以輸入 |
| R116 AC2 | 滑鼠移到上緣 6 像素內停留，再往下移到工具列按鈕 | 0.3 秒後出現，維持顯示，可以按 |
| R116 AC3 | 滑鼠快速掠過上緣 | 不出現 |
| R116 AC4、AC5 | 右邊放影片模式的格子，滑鼠移到它上方最上面 40 像素 | 立即出現；左邊仍依 AC1 |
| R116 AC6 | 工具列顯示時按住中間空白處 | 可以拖曳視窗 |
| R117 AC1 | 滑鼠移到整頁模式的格子 | 右下角只有「⋯」，網頁底部可以點 |
| R117 AC2 | 滑鼠移到「⋯」 | 展開操作列，按鈕可以按 |
| R117 AC3 | 滑鼠離開操作列 | 0.3 秒後收回 |
| R117 AC4 | 開著音量滑桿或選單，滑鼠離開操作列 | 不收回 |
| R117 AC5 | 看左上角 | 收起時沒有小標示，展開時有 |
| R117 AC6 | 影片模式的格子 | 沒有小把手 |
| R117 AC7 | `3×3`、視窗最小 | 小把手在格子內，按得到 |
| R118 | `npm run dist`、安裝 | `MultiView-Setup-0.8.3.exe`，「關於」顯示 0.8.3 |

## 2026-11-08 驗收紀錄

以 build 後的開發版、獨立的測試資料夾執行。經使用者同意移動真實游標（只移動、不點擊，結束時放回原位），並暫時把測試視窗設成置頂；以開發工具（CDP）讀取工具列、格子狀態與網頁收到的滑鼠位置。

| 需求 | 結果 | 說明 |
|---|---|---|
| R116 AC1 | ✅ | y=20 工具列不出現；網頁在左側與水平中間都收到滑鼠移動（`{x:634,y:20}`），拖曳區沒有攔截。實際輸入文字未測（約定不點擊） |
| R116 AC2 | ✅ | y=2 停留 600 毫秒後出現；移到 y=30 維持顯示。按工具列按鈕未測（約定不點擊） |
| R116 AC3 | ✅ | y=2 停留 100 毫秒後離開，不出現 |
| R116 AC4、AC5 | ✅ | 同一個視窗：右側影片模式的格子 y=20 在 200 毫秒內出現，左側整頁模式依 AC1 |
| R116 AC6 | ✅（部分） | 工具列顯示時拖曳區是 `drag`，隱藏時是 `none`；實際拖曳未測（約定不點擊） |
| R117 AC1 | ✅ | 滑鼠在格子上：只有小把手，沒有操作列 |
| R117 AC2 | ✅ | 滑鼠移到小把手：展開操作列；按鈕的點擊未測（約定不點擊） |
| R117 AC3 | ✅ | 移到操作列上維持展開；離開後收回小把手 |
| R117 AC5 | ✅ | 收起時沒有小標示，展開時有 |
| R117 AC4、AC6 | ✅（單元測試） | |
| R117 AC7 | ⏳ | 未手動測 |
