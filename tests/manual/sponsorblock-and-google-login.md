# SponsorBlock 與用 Edge 登入 Google：手動驗收步驟

對應規格：`doc/specs/sponsorblock-and-google-login.md`（R161、R168、R169）。單元測試見 `tests/unit/sponsor-block.test.ts`、`tests/unit/google-login.test.ts`。

先在設定 →「YouTube 播放」把「一般影片的播放方式」設成 yt-dlp。找一部有業配標記的影片：在瀏覽器裝 SponsorBlock 擴充功能時進度條上有綠色色塊的影片（例如科技類 YouTuber 的影片）。

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R161 AC1 | 播放有業配的影片，等到業配開始 | 自動跳到業配結束，右上角「● 已跳過業配　取消」，5 秒後消失 |
| R161 AC2 | 按「取消」；之後倒回去重看業配 | 跳回業配開頭繼續播放，不再被跳過 |
| R161 AC3 | 拖曳進度條到業配中間；再拖到業配前面 | 從業配中間繼續播放，不會被跳走；從前面播進業配時照樣跳過 |
| R161 AC4 | 游標移到進度條 | 業配的位置有綠色色塊；游標在色塊上時提示多一行「● 業配」 |
| R161 AC5 | 設定關閉「自動跳過片段」；再開啟並勾「開場」；重開程式 | 關閉時色塊消失、不跳；勾開場後開場也有青色色塊、會跳；設定保留 |
| R161 AC7 | 兩格播同一部影片，其中一格按「取消」 | 兩格各自跳過、各自的提示；取消只影響那一格 |
| R161 AC8 | 拔掉網路（影片已經緩衝）或封鎖 sponsor.ajay.app 後播放 | 影片照常播放，沒有色塊、沒有錯誤訊息 |
| R161 AC9 | 內嵌播放器、網頁模式、直播 | 沒有色塊、不跳過 |
| R161 其他 | 工具列顯示時，最上面一列的格子跳過業配 | 提示在工具列下面，沒有被蓋住 |
| R168 AC1 | 開啟 YouTube 小視窗，按右上的「登入」 | 開啟新的 Edge 視窗，是 Google 的登入頁；小視窗顯示登入說明，按鈕是「登入中…」 |
| R168 AC2 | 在 Edge 用個人帳號登入（含兩步驟驗證），登入後關掉 Edge 視窗；再用公司帳號試一次 | 不出現「可能不安全」；關掉後小視窗顯示「正在讀取登入狀態…」，幾秒後小視窗提示「已登入 Google」，按鈕是「紀錄」「登出」，網頁右上角是自己的大頭貼 |
| R168 AC3 | 按「紀錄」，點一部影片 | 搜尋分頁顯示自己的觀看紀錄；影片放進格子 |
| R168 AC4 | 關閉 MultiView 再開啟，打開小視窗 | 仍然是登入的（隔幾天再看一次，記錄會不會被登出） |
| R168 AC5 | 按「登入」，Edge 開啟後沒登入就關掉；再試一次，改按小視窗的「取消登入」 | 第一次提示「沒有偵測到登入…」；第二次提示「已取消登入」；按鈕都回到「登入」 |
| R168 AC6 | 按「登出」→ 確認視窗按「取消」；再按「登出」→「登出」 | 按取消時仍然是登入的；確認後網頁換成沒有登入的樣子，按鈕回到「登入」 |
| R168 AC7 | 登入或取消後，打開 `%TEMP%`；開啟平常用的 Edge | 沒有 `multiview-login-` 開頭的資料夾；平常的 Edge 分頁、帳號不變 |
| R168 風險 | 如果 Edge 顯示「這個瀏覽器或應用程式可能不安全」或「無法登入」 | 記錄畫面與文字（代表 Google 擋了開著偵錯連線的瀏覽器，要換做法） |
| R168 瀏覽器 | 設定 → YouTube 播放 → Google 登入，選 Chrome（或 Brave）→ 小視窗按「登入」 | 開啟的是 Chrome（或 Brave），說明文字也是那個瀏覽器的名稱；登入完成後自動關閉 |
| R169 AC1 | 複製 YouTube 網址 → 空白格子按「貼上並開啟」 | 開始播放 |
| R169 AC2 | 在網址輸入框（格子、清單面板）按右鍵 →「貼上」 | 網址貼進輸入框；剪下、複製、全選照常 |
| R169 AC3 | 剪貼簿是空的時按「貼上並開啟」 | 顯示「剪貼簿裡沒有網址」 |
| R162 AC1 | 版型 `1`；版型 `2×2` 下按單格全螢幕；回到 `2×2` | 前兩種情況有聲音的格子左上角沒有小喇叭；回到 `2×2` 後照常顯示 |
