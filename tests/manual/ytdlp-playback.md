# YouTube 可選用 yt-dlp 播放：手動驗收步驟

對應規格：`doc/specs/ytdlp-playback.md`（R88–R94）。單元測試見 `tests/unit/ytdlp.test.ts`。

測試前準備：用獨立的測試資料夾（環境變數 `MULTIVIEW_USER_DATA`），不動到正式的設定。舊版 yt-dlp 從 GitHub 的 releases 下載（例如 2026.10.21）。

### 實測時發現並修正

- 主程序交給畫面的設定少了播放方式，畫面一開啟就錯誤（空白畫面）→ 已修正。
- 剛解析出來的一般影片網址，前幾秒 YouTube 會回 403（用 curl 實測：立刻 403、3 秒後 206）。播放器因此失敗，每次重試都重新解析又拿到新網址，最後退回內嵌 → 主程序先試讀網址，可以讀了才交給畫面（最多 10 秒）。
- 直播的影像、聲音是分開的 HLS 軌道，原本計畫的 `-f "best[protocol^=m3u8]"` 找不到格式 → 不指定格式，從格式清單取主清單（主清單裡有聲音軌，hls.js 會自己組合）。
- 直播的主清單沒有回傳 `Access-Control-Allow-Origin`，確認需要補（第 8 節）。
- 一般影片用主清單播放時，選畫質要等已緩衝的片段（實測可達 190 秒以上）播完才換，不符合 R32 AC1（15 秒內）→ 使用者選畫質時清掉緩衝立刻換。實測：緩衝 193 秒時選 144p，2.6 秒換好，播放位置不變、繼續播放。
