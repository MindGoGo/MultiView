# 回到 YouTube 頁面、沒有空格時選擇要取代的格子：手動驗收步驟

對應規格：`doc/specs/youtube-back-to-page.md`（R63–R65）。單元測試見 `tests/unit/back-to-page.test.ts`。

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R63 AC1–AC2 | 格子貼上 `https://www.youtube.com/results?search_query=TED+talk`，捲到第 10 部並點它；按「← 回到 YouTube」 | 播放那部影片、有回去按鈕、背景頁面沒有聲音；回去後停在原本的捲動位置 |
| R63 AC3 | 點影片後，滑鼠在這一格上按滑鼠「上一頁」側鍵；再試一次「直接操作」時游標在播放器裡按 | 都回到搜尋結果 |
| R63 AC4 | 點影片後按 Backspace；網址輸入框有焦點時按 Backspace | 回到搜尋結果；輸入框只刪字 |
| R63 AC5 | 影片播放時音量調到 30，回去 | 頁面的音量是 30 |
| R63 AC6、AC8 | 影片播放時「更換網址」；貼上網址開啟的影片 | 沒有回去按鈕 |
| R63 AC7 | 點影片後關閉再開啟，按「← 回到 YouTube」 | 重新載入搜尋結果頁 |
| R63 AC9 | 點影片後和另一格換位，按「← 回到 YouTube」 | 在新的位置回到搜尋結果 |
| R64 AC1 | 版型「1」有影片，清單按「開啟 YouTube」 | 直接取代，沒有提示 |
| R64 AC2 | 單格全螢幕時點一下最愛 | 取代放大的那一格，仍是單格全螢幕 |
| R64 AC3–AC5 | `2×2` 四格都有影片，按「開啟 YouTube」或點歷史；選第 2 格；再開一次按 Esc | 出現選擇框（編號 1～4 與影片名稱）；第 2 格被取代；Esc 取消 |
| R64 AC6 | 有空格時點一下 | 放進第一個空格 |
| R64 AC7 | 視窗縮到 600px 寬時按「開啟 YouTube」 | 選擇框蓋在清單面板上面，可以選 |
| R65 | 安裝後看 MultiView.exe 的內容 → 詳細資料 | 版本 0.5.1 |

## 實作時的發現

- 最初的做法是讓 YouTube 網頁換到影片頁後再退回，但 YouTube 退回時會出現迷你播放器、捲動位置歸零；改成在網頁裡攔下影片連結的點擊，網頁不換頁。
- 背景的頁面原本用整個畫面的大小，YouTube 因此重新排版、捲動位置跑掉；改成維持原本那一格的大小。
