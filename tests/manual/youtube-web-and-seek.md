# YouTube 網頁播放、進度條預覽、快轉倒轉：手動驗收步驟

對應規格：`doc/specs/youtube-web-and-seek.md`（R48–R52）。單元測試見 `tests/unit/youtube-web.test.ts`、`tests/unit/storyboard.test.ts`、`tests/unit/seek-skip.test.ts`。

## 驗收用的來源

- 禁止嵌入的 YouTube 影片：`https://www.youtube.com/watch?v=kJQP7kiw5Fk`、`https://www.youtube.com/watch?v=JGwWNGJdvx8`
- 可以嵌入的 YouTube 影片：`https://www.youtube.com/watch?v=iG9CE55wbtY`（TED，20 分鐘）
- mp4：`https://test-videos.co.uk/vids/bigbuckbunny/mp4/h264/360/Big_Buck_Bunny_360_10s_1MB.mp4`（10 秒）
- m3u8 點播：`https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8`（10 分 34 秒）

## 驗收步驟

| 需求 | 步驟 | 預期結果 |
|---|---|---|
| R48 AC1–AC2 | 空白格貼上禁止嵌入的影片，按「改用 YouTube 網頁播放」 | 先顯示錯誤和按鈕；按下後只顯示影片並開始播放，廣告阻擋是關閉的 |
| R48 AC3 | 關閉再開啟程式；和另一格換位 | 仍是網頁播放；跟著移動 |
| R48 AC4 | 拖曳進度條、播放／暫停、調音量和亮度 | 都有作用 |
| R48 AC6 | 「更換網址」成可以嵌入的影片 | 用一般的嵌入播放 |
| R48 AC7 | 看歷史清單 | 多一筆，網址是原本的 YouTube 網址，名稱沒有「 - YouTube」 |
| R49 AC1–AC5 | 工具列「⚙ 設定」勾選「YouTube 無法嵌入時自動改用網頁播放」，貼上禁止嵌入的影片；重開程式；取消勾選再貼一次 | 勾選後直接改用網頁播放；重開後仍勾選；取消後顯示錯誤和按鈕；選單開著時工具列不隱藏 |
| R50 AC1 | mp4 進度條正中央 | `0:05`，上方有那個位置的畫面 |
| R50 AC2 | YouTube 進度條左右移動 | 縮圖跟著換 |
| R50 AC3 | m3u8 進度條 | 只有時間 |
| R50 AC4–AC5 | 滑鼠移到最左、最右；拖曳進度條 | 提示在格子內；拖曳時跟著游標，放開並離開後消失 |
| R50 AC6 | mp4 播放中看預覽 | 播放不中斷 |
| R51 AC1–AC5 | 滑鼠在格子上按 →、←；暫停中按；在開頭、結尾附近按；按住 → | 前後 5 秒；維持暫停；不超出範圍；連續跳轉 |
| R51 AC6 | 按「⏪」「⏩」；`3×3` 視窗最小 | 和方向鍵相同；最小格子沒有這兩個按鈕，其他按鈕都按得到 |
| R51 AC7–AC8 | 網址輸入框有焦點時按 →；滑鼠移出視窗按 → | 影片都不跳轉 |
| R51 AC2、AC10 | 單格全螢幕時滑鼠移出畫面按 →；滑鼠停著不動、操作區隱藏後按 → | 都會跳轉；操作區重新顯示 |
| R51 AC9 | YouTube、m3u8、網頁來源各按一次 → | 都會跳轉 |
| R52 | 安裝後看 MultiView.exe 的內容 → 詳細資料 | 版本 0.4.0 |
