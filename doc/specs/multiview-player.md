# 多畫面直播播放器 規格

- 功能代號：`multiview-player`
- Jira：無
- 狀態：已複查（待使用者確認修正）
- 最後更新：2026-10-08

## 1. 背景與目標

使用者需要在同一個畫面同時看多個直播（例如新聞台、賽事、監看畫面）。用瀏覽器開多個分頁或視窗時，畫面被網址列、推薦影片、留言等占掉，也很難管理哪一路有聲音。本產品是一個 Windows 桌面程式，視窗內只有影片，用固定版型分割畫面、可以拖曳調整比例，並集中控制播放與聲音。

## 2. 範圍

**包含（第一版）：**
- Windows 桌面程式（Electron），供使用者個人使用
- 影片來源：YouTube 影片與直播、直接的 mp4 / m3u8 連結
- 5 種固定版型、可拖曳的分隔線、拖曳換位
- 聲音：點擊切換單一聲音，也可以同時開多格聲音，每格可以各自調整音量
- 全部播放、全部暫停、全部靜音、快捷鍵
- 關閉後保留設定，下次開啟時還原

**不包含（之後再評估）：**
- 任意網頁中的影片（例如新聞台官網），規劃在第二版
- Twitch 和其他平台
- YouTube Shorts、播放清單（網址中的 `list=` 會被忽略，只播放 `v=` 指定的影片）
- 進度條和拖曳跳轉（mp4 也沒有）
- 「跳回直播進度」按鈕
- macOS / Linux
- 程式碼簽章、自動更新、安裝程式
- 多格之間的播放進度同步
- 完全自由的浮動小視窗版面（C 方案）
- 帳號、雲端同步、錄影

## 3. 共用定義

- **格位（slot）：** 程式固定有 9 個格位，編號 1–9，每個格位最多放一個來源。來源最多 9 個。移除來源時，該格位變成空白，其他來源**不會往前遞補**。
- **格子編號：** 版型中的第 N 格顯示第 N 個格位。編號順序為由左到右、由上到下；`1+3` 版型的大畫面是第 1 格，右側由上到下是第 2–4 格。
- **顯示中的來源：** 格位編號小於或等於目前版型格數的來源；其餘稱為「隱藏的來源」。
- **點擊攔截層：** 每一格的影片上方覆蓋一層透明的攔截層。滑鼠點擊和移動都由程式處理，不會傳到 YouTube 播放器，因此點擊影片不會觸發 YouTube 的暫停，鍵盤焦點也會留在程式上。

## 4. 需求清單

### R1：無邊框的主視窗
- 描述：程式只有一個主視窗，沒有系統標題列和邊框，內容區全部用來顯示影片。可以拖曳全域工具列（見 R3）的空白處來移動視窗，拖曳視窗邊緣可以調整大小。最小視窗尺寸為 480×270px。工具列右側有「最小化」和「關閉」按鈕。
- 驗收條件：
  - AC1：開啟程式 → 不做任何操作 → 視窗中只看得到影片格，看不到標題列、選單列或工具列。
  - AC2：工具列顯示時 → 按下「置頂」 → 切換到其他程式時，主視窗仍然保持在最上層；再按一次就取消置頂。
  - AC3：按下 F11 → 視窗切換成全螢幕；再按 F11 或 Esc → 回到原本的大小和位置。
  - AC4：移動視窗或改變大小後關閉程式 → 重新開啟 → 視窗回到上次的位置和大小。如果上次的位置已經不在任何螢幕範圍內（例如拔掉了第二台螢幕），就改成在主螢幕置中。如果關閉時是全螢幕，重新開啟時用進入全螢幕前的大小和位置。
  - AC5：把視窗縮小到 480×270px → 無法再縮得更小。
  - AC6：按工具列的「最小化」 → 視窗縮到工作列；按「關閉」 → 儲存設定後結束程式。

### R2：在格子中加入影片來源
- 描述：空白格的中央顯示網址輸入框和提示文字「貼上 YouTube、mp4 或 m3u8 網址」。支援以下格式：
  - YouTube：`youtube.com/watch?v=<id>`、`youtu.be/<id>`、`youtube.com/live/<id>`、`youtube.com/embed/<id>`。網域可以是 `www.`、`m.` 或不加子網域；`http` 和 `https` 都可以；其他 query 參數會被忽略。
  - 直接連結：`http(s)` 網址，路徑以 `.mp4` 或 `.m3u8` 結尾（不分大小寫，可以帶 query string）。
  - 同一個網址可以放在多格。
- 驗收條件：
  - AC1：在網路正常的情況下，在空白格貼上 YouTube 直播網址並按 Enter → 該格在 5 秒內開始播放。
  - AC2：貼上 m3u8 直播網址 → 該格開始播放。
  - AC3：貼上 mp4 網址 → 該格開始播放，播完後停在最後一個畫面，不會自動重播。
  - AC4：貼上不支援的網址（例如 `https://example.com`、YouTube Shorts）或非網址的文字 → 輸入框下方顯示「不支援的網址」，格子維持空白，其他格不受影響。
  - AC5：輸入框是空的或只有空白字元時按 Enter → 不做任何事。
  - AC6：YouTube 影片禁止內嵌、已刪除或設為私人 → 格子顯示「此影片無法在外部播放」，並提供「更換網址」按鈕。
  - AC7：m3u8 / mp4 載入失敗，或播放中斷線且自動重試 3 次仍然失敗 → 格子顯示「無法載入影片」和「重試」按鈕；按「重試」會重新載入同一個網址。
  - AC8：對已經在播放的格子選擇「更換網址」並輸入新網址 → 舊影片停止，改為播放新影片；靜音狀態和音量維持不變。
  - AC9：對格子選擇「移除」 → 該格恢復成空白狀態，其他來源的位置不變。

### R3：畫面只顯示影片
- 描述：
  - YouTube 使用官方內嵌播放器，隱藏控制列，並把相關影片限制在同一個頻道。YouTube 標誌、廣告，以及 YouTube 在暫停或片尾時顯示的同頻道推薦屬於平台限制，不做遮蓋。
  - 格子之間只有 2px 的分隔線，沒有標題或外框。
  - 每一格的操作按鈕（喇叭、音量、移動、更換網址、移除、直接操作播放器）只在滑鼠停在該格上時顯示。滑鼠靜止 2 秒或移出該格後就隱藏。
  - 全域工具列（版型、全部播放 / 暫停 / 靜音、置頂、最小化、關閉）只在滑鼠移到視窗頂端 40px 以內時顯示，移開後 1 秒隱藏。
  - 「直接操作播放器」：暫時拿掉該格的點擊攔截層，讓使用者可以直接點擊 YouTube 播放器（例如略過廣告）。滑鼠移出該格後，攔截層自動恢復。
- 驗收條件：
  - AC1：滑鼠在視窗外 → 畫面中只有影片和分隔線。
  - AC2：滑鼠移到某一格 → 只有這一格出現操作按鈕；滑鼠靜止 2 秒後按鈕消失，移動滑鼠又會出現。
  - AC3：滑鼠移到視窗頂端 → 出現全域工具列；移開 1 秒後消失。
  - AC4：YouTube 格子播放中 → 看不到 YouTube 的控制列（播放鍵、進度條、音量）。
  - AC5：在 YouTube 格子按「直接操作播放器」後點擊影片 → 點擊會傳到 YouTube 播放器；滑鼠移出該格後再點擊 → 回到 R7 的獨占聲音行為。

### R4：固定版型
- 描述：提供 5 種版型，從全域工具列切換：`1`（單一畫面）、`2`（左右兩格）、`2×2`、`3×3`、`1+3`（左邊一格大畫面，右邊三格直向排列）。格子編號依「共用定義」。
- 驗收條件：
  - AC1：第一次開啟程式 → 預設版型是 `2×2`，四格都是空白。
  - AC2：`2×2` 已經放了 4 個來源，切換成 `3×3` → 原本的 4 個來源出現在第 1–4 格，而且不重新載入（直播不會中斷）；第 5–9 格是空白。
  - AC3：`3×3` 的第 1–6 格有來源，切換成 `2×2` → 第 1–4 格繼續顯示；第 5、6 格的來源變成隱藏的來源，會暫停並隱藏，但不刪除。切回 `3×3` 時，它們重新出現在第 5、6 格，維持暫停。
  - AC4：切換後如果有隱藏的來源 → 工具列顯示提示「有 N 個來源暫時隱藏」，3 秒後自動消失。
  - AC5：在 `2×2` 中移除第 2 格的來源，且第 5 格有隱藏的來源 → 第 2 格變成空白，隱藏的來源不會遞補上來。

### R5：拖曳分隔線調整比例
- 描述：各版型的分隔線如下，每條分隔線都可以拖曳：
  - `2`：1 條直線
  - `2×2`：1 條貫穿的直線 + 1 條貫穿的橫線
  - `3×3`：2 條貫穿的直線 + 2 條貫穿的橫線
  - `1+3`：1 條直線（大畫面和右欄之間）+ 右欄內 2 條橫線
  - `1`：沒有分隔線

  比例會分開記在每一種版型裡。
- 驗收條件：
  - AC1：在 `2` 版型拖曳中間的分隔線 → 左右兩格即時改變寬度，影片維持原本的長寬比，多出的空間顯示黑色。
  - AC2：拖曳到讓任一格的寬度小於 max(160px, 視窗寬度的 10%)，或高度小於 max(90px, 視窗高度的 10%) → 分隔線停在極限位置，不能再拖。
  - AC3：雙擊分隔線 → 只有這條分隔線恢復成預設位置（均分）。
  - AC4：在 `2×2` 調整比例後切換到 `3×3`，再切回 `2×2` → 恢復剛才調整過的比例。
  - AC5：拖曳過程中影片持續播放，不重新載入。
  - AC6：調整視窗大小 → 各格維持相同的比例。

### R6：拖曳換位
- 描述：按住某一格的「移動」把手，拖到另一格後放開，兩個格位的內容就互換（包括靜音狀態和音量）。`1` 版型不顯示「移動」把手。
- 驗收條件：
  - AC1：在 `1+3` 版型把第 4 格拖到第 1 格 → 兩個來源互換位置，兩者都繼續播放，不重新載入。
  - AC2：把有來源的格子拖到空白格 → 來源移到空白格，原本的格子變成空白。
  - AC3：拖曳中放開在原本的格子或視窗外 → 不發生任何變化。

### R7：聲音控制
- 描述：每個來源都有自己的靜音狀態和音量（0–100，預設 100）。
  - **獨占聲音：** 點擊有來源的格子的影片區域 → 這一格取消靜音，其他所有來源都靜音。點擊空白格或錯誤狀態的格子不會影響聲音。
  - **多格聲音：** 點擊格子的喇叭按鈕 → 只切換這一格的靜音狀態，不影響其他格子。
  - **音量：** 每一格有自己的音量滑桿。
  - **聲音圖示：** 取消靜音而且音量大於 0 的格子，左上角會一直顯示一個小喇叭圖示，不需要把滑鼠移上去。
- 驗收條件：
  - AC1：加入新來源時，如果沒有任何顯示中的來源是有聲音的 → 新來源有聲音；否則新來源靜音。
  - AC2：格子 1、2 都有聲音，點擊格子 3 的影片區域 → 只有格子 3 有聲音。
  - AC3：只有格子 1 有聲音，點擊格子 2 的喇叭按鈕 → 格子 1 和 2 都有聲音。
  - AC4：調整格子 2 的音量 → 只有格子 2 的音量改變。
  - AC5：取消靜音且音量大於 0 的格子顯示喇叭圖示；靜音或音量為 0 的格子不顯示。

### R8：全部播放、全部暫停、全部靜音
- 描述：全域工具列有「全部播放」「全部暫停」「全部靜音」三個按鈕，作用在所有顯示中、而且不是錯誤狀態的來源。
- 驗收條件：
  - AC1：4 格都在播放 → 按「全部暫停」 → 4 格都暫停。
  - AC2：其中 2 格暫停 → 按「全部播放」 → 4 格都在播放。
  - AC3：按「全部靜音」 → 所有來源靜音，但各格的音量設定不變；之後點擊任一格 → 依 R7 的規則恢復聲音，音量維持原本的設定。
  - AC4：隱藏的來源不受這三個按鈕影響，維持暫停。
  - AC5：沒有任何顯示中的來源時 → 三個按鈕都顯示為停用。

### R9：快捷鍵
- 描述：主視窗在前景、而且焦點不在網址輸入框時：

| 按鍵 | 動作 |
|---|---|
| Space | 只要有任何顯示中的來源在播放就全部暫停，否則全部播放 |
| M | 全部靜音 |
| 1–9 | 把聲音獨占給第 N 格（等同 R7 的點擊影片）；第 N 格不在目前版型中、是空白或錯誤狀態就不動作 |
| F11 | 切換全螢幕 |
| Esc | 離開全螢幕；如果正在輸入網址，就取消輸入並清空輸入框 |

- 驗收條件：
  - AC1：上表的每個按鍵都能觸發對應的動作。
  - AC2：在網址輸入框中按 Space 或數字鍵 → 只輸入文字，不觸發快捷鍵。
  - AC3：剛點擊過某一格的影片之後 → 快捷鍵仍然有效（焦點沒有被 YouTube 播放器拿走）。

### R10：保存與還原
- 描述：以下設定會自動存到 `%APPDATA%\<程式名稱>\settings.json`，下次開啟時還原：
  - 視窗的位置、大小、置頂狀態
  - 目前的版型
  - 每種版型的分隔線比例
  - 9 個格位的來源（網址、靜音狀態、音量），包括隱藏的來源
- 驗收條件：
  - AC1：設定好 `2×2` 的四個來源和聲音後關閉程式 → 重新開啟 → 版型、來源、聲音狀態都和關閉前一樣，所有來源載入後維持暫停；按「全部播放」或 Space 才開始播放。
  - AC2：設定檔損毀或格式錯誤 → 程式照樣能開啟，使用預設值（R4 AC1），並把壞掉的設定檔改名成 `settings.json.bak` 保留。
  - AC3：設定變更後，最晚 1 秒內就寫入檔案（程式當掉時最多遺失最後 1 秒的變更）。

## 7. 非功能需求

- **平台：** Windows 10 / 11，64 位元。
- **效能：** 在 `2×2` 版型連續播放 4 路 YouTube 1080p 直播 30 分鐘，程式不當掉，畫面也不凍結。實際畫質交給 YouTube 自動調整。（這項只能手動驗收。）
- **合規：** 不遮蓋 YouTube 的標誌和廣告，不繞過禁止內嵌的限制。
- **技術選型：** Electron + Vite + React + TypeScript；m3u8 使用 hls.js；單元測試使用 Vitest。
- **已知技術風險（實作時處理，不影響需求）：**
  - YouTube 內嵌播放器需要頁面有正常的來源網址；用 `file://` 載入可能出現錯誤 153。頁面要改用自訂協定或本機 http 提供。
  - 很多 m3u8 伺服器沒有開放跨來源存取（CORS），需要在主程序替這些回應補上 CORS 標頭。

## 8. 預計影響的檔案

新專案，預計結構如下：
- `electron/main.ts`：主視窗、置頂、全螢幕、最小視窗、視窗位置還原、快捷鍵攔截（R1、R9、R10）
- `electron/store.ts`：設定檔的讀寫和損毀處理（R10）
- `src/lib/source.ts`：網址解析與分類（R2）
- `src/lib/layout.ts`：版型定義、格子編號、分隔線比例計算、最小尺寸限制（R4、R5）
- `src/lib/slots.ts`：格位、換位、隱藏判斷（R4、R6）
- `src/lib/audio.ts`：聲音狀態規則（R7、R8）
- `src/components/Grid.tsx`、`Cell.tsx`、`Toolbar.tsx`、`Divider.tsx`（R3–R8）
- `src/players/YouTubePlayer.tsx`、`HlsPlayer.tsx`、`Mp4Player.tsx`（R2、R3）
- `src/hooks/useShortcuts.ts`（R9）
- `tests/unit/`：source、layout、slots、audio、store 的單元測試
