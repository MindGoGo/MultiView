# 自訂版型（自己切格子） 規格

- 功能代號：`custom-layouts`
- 狀態：**草稿，待使用者確認**（2026-11-18）
- 前置規格：[multiview-player](multiview-player.md) 的 R4（版型）、R5（分隔線）、R20（單格全螢幕）；拖曳換格、1～9 快捷鍵、YouTube 小視窗的「第 N 格」。
- 需求編號：R167（R161–R166 已使用）。預計版本 0.9.0。

## 1. 背景與目標

現在只有固定的 5 種版型（1、2、2×2、3×3、1+3）。螢幕是直的時，想要上中下 3 格這類排法做不到（使用者要求，2026-11-18）。

目標：使用者可以自己把格子「左右切」或「上下切」，做出任何不重疊、不留空的排法，存成自訂版型，和固定版型一樣在工具列切換。

## 2. 範圍

**包含**：自訂版型的建立、編輯（切開、刪除格子、拖曳分隔線）、儲存、切換、刪除。

**不包含**：
- 完全自由擺放（格子重疊、任意位置）
- 自訂版型的名稱（固定叫「自訂 1」「自訂 2」…）、匯出匯入、復原（Ctrl+Z）
- 手機版（手機版讀到自訂版型時用預設版型，見 R167 的「相容」）
- 改變固定版型本身

## 3. 共用定義

- **切割樹**：自訂版型的結構。每個節點是「一格」，或是「左右排列」「上下排列」的一組子節點（2 個以上，各有比例，比例總和為 1）。上中下 3 格是一個「上下排列」、底下 3 格。
- **格子編號**：從樹的最上層開始，先左後右、先上後下依序編號（深度優先）。例如「左邊 1 格、右邊上下 2 格」是 1 = 左、2 = 右上、3 = 右下；2×2 是 1 左上、2 右上、3 左下、4 右下，和現在的固定版型一樣。
- **最小格子**：沿用 R5，寬至少 max(160px, 10%)、高至少 max(90px, 10%)。

## 4. 需求

### R167：自訂版型

- 描述：
  - **工具列**：版型按鈕後面依序列出自訂版型（圖示是它的縮圖），最後是「編輯版型」按鈕（鉛筆圖示）。最多 5 個自訂版型。
  - **編輯版型**：
    - 按「編輯版型」→ 進入編輯模式：
      - 目前是自訂版型時，編輯它。
      - 目前是固定版型時，先把它複製成一個新的自訂版型（「自訂 N」），再編輯；已經有 5 個時提示「自訂版型最多 5 個，請先刪除一個」，不進入。
    - 編輯模式中，每一格中間顯示格子編號與三個按鈕：「左右切」「上下切」「刪除這格」。影片照常播放，格子的其他操作暫時不出現。
    - **左右切／上下切**：把這一格平分成兩格，新的空白格在右邊（或下面）。如果這一格原本就在同方向的排列裡（例如上中下的中間那格按「上下切」），就在同一層多加一格，這一格和新格平分它原本的大小。
      - 切開後兩格不能小於最小格子，否則按鈕停用（滑鼠移上去提示「這一格太小，不能再切」）。
      - 總共 9 格時兩個按鈕都停用（提示「最多 9 格」）。
    - **刪除這格**：這一格拿掉，它的空間交給同一層相鄰的格子（優先前一格，沒有時給後一格）；同一層只剩一格時，那一格往上併入上一層。只剩 1 格時停用。
      - 這一格有影片時，影片不刪除：移到最後面、變成「暫時隱藏」的來源（和切換成較少格的版型相同，工具列提示「有 N 個來源暫時隱藏」）。
    - **影片跟著格子走**：切開、刪除後格子編號會變，但每一格裡的影片留在原本的那一格（例如在第 1 格右邊切出新格，原本的第 2 格變成第 3 格，影片跟著到第 3 格）。
    - 分隔線照常可以拖曳（編輯模式內外都可以），雙擊回到平分。
    - 工具列在編輯模式中保持顯示，「編輯版型」變成「完成」；旁邊多「刪除這個版型」。按「完成」或 Esc 離開編輯模式。
    - **刪除這個版型**：先確認「要刪除『自訂 N』嗎？」，刪除後換回 2×2（隱藏的影片規則同切換版型）。
  - **切換版型**：和固定版型相同（影片依格子編號放，多出來的暫時隱藏，R4）。拖曳換格、單格全螢幕、1～9 快捷鍵、YouTube 小視窗的「第 N 格」都用上面的格子編號。
  - **儲存**：`settings.json` 多 `customLayouts`：`[{ "id": "c1", "tree": <切割樹> }]`；`layout` 是自訂版型時存 `"custom:c1"`。比例存在切割樹裡（拖曳分隔線就更新）。讀到不合法的樹（格數 0 或超過 9、比例不對、子節點少於 2…）時丟掉那個自訂版型；`layout` 指向不存在的自訂版型時用 2×2。
  - **相容**：手機版讀到 `custom:…` 的 `layout` 時用預設版型、忽略 `customLayouts`（手機版現有的行為，不用改）。舊版桌面版讀到時也是用預設版型。
- 驗收條件：
  - AC1：在 2×2 按「編輯版型」→ 工具列多一個「自訂 1」並選取它，畫面仍是 2×2，每格出現編號與三個按鈕。
  - AC2：（直螢幕的例子）版型 1 → 編輯 → 按「上下切」兩次 → 上中下 3 格平分；拖曳兩條分隔線調整大小；按「完成」→ 關掉程式再開，「自訂 1」仍在，選取後是同樣的 3 格與比例。
  - AC3：左右切後在右邊那格上下切 →「左 1、右上 2、右下 3」；按 2 只聽右上那格，1～3 的快捷鍵、單格全螢幕、拖曳換格都正常。
  - AC4：有影片的第 2 格旁邊切出新格 → 影片沒有重新載入，留在原本那格（編號變成第 3 格）。
  - AC5：刪除有影片的格子 → 格子消失、空間給相鄰的格子，影片變成暫時隱藏，工具列提示；切回較多格的版型時影片出現。
  - AC6：格子太小時切開的按鈕停用；9 格時切開的按鈕停用；只剩 1 格時刪除停用。
  - AC7：已有 5 個自訂版型時，在固定版型按「編輯版型」→ 提示最多 5 個，不建立新的。
  - AC8：刪除自訂版型（確認後）→ 換回 2×2，工具列少了那個版型。
  - AC9：設定檔的 `customLayouts` 有不合法的樹 → 開啟時略過它，其他照常。
  - AC10：單元測試：切割樹的格子位置與編號、切開（新增一層或同一層多一格）、刪除（交給相鄰格、只剩一格時併入上一層）、最小格子與 9 格的限制、影片跟著格子走、分隔線拖曳、設定檔讀寫與不合法的樹。

## 5. 做法（預計）

- `src/lib/layoutTree.ts`：切割樹的型別與純函式（格子位置、分隔線、切開、刪除、影片重新排列、驗證）；固定版型轉成切割樹（複製成自訂版型時用）。
- `src/lib/layout.ts`：版型可以是固定或自訂；`cellRects`、`dividers`、`cellCount` 依版型種類算。
- `Grid.tsx`、`Divider.tsx`：分隔線改用切割樹的分隔線（每條分隔線知道自己屬於哪一組）。
- `Toolbar.tsx`、`icons.tsx`：自訂版型的按鈕與縮圖、「編輯版型」「完成」「刪除這個版型」。
- `Cell.tsx`：編輯模式的編號與按鈕。
- `App.tsx`：編輯模式、切開與刪除時重新排列影片、儲存。
- `src/lib/settings.ts`：`customLayouts`、`custom:` 的 `layout`。
