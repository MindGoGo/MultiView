# 浮動按鈕的調整（桌面版）規格

- 功能代號：`floating-controls-tweaks`
- 狀態：已確認、已實作。R171：0.9.2，0.9.3 修正，使用者實測正常（2026-11-25）。R172：0.9.4，待實測
- 前置規格：[floating-controls](floating-controls.md)（R165、R166）
- 需求編號：R171、R172（只有桌面版）。R165–R167 和手機共用，R168–R170 是桌面版原本的登入、貼上網址、自訂版型。

## 1. 背景

使用者實測 0.9.1 後提出（2026-11-25）：

1. 音量收在齒輪裡，左上的聲音按鈕只能靜音。想合併：滑鼠移到聲音按鈕上出現音量滑桿，點一下照原本靜音／開聲音。
2. 整頁模式的網頁格子：滑鼠在左下叫出按鈕後往上移去按齒輪，按鈕就消失了。
3. 整頁模式的網頁格子：從別格按「移動」拖過來時，沒有藍色的覆蓋，換不了位置。
4. 左上角「有聲音」的 🔊 換成音波圖示。使用者看過三個候選（白色、粉紫漸層、白色會跳動）後選「白色會跳動」，並要求稍微小一點。
5. 設定 → yt-dlp 版本旁的「已是最新版」標籤跑版（多了一塊圓形背景）。
6. 在影片上按右鍵打開齒輪選單；使用者希望做成設定：左鍵、右鍵各自選「開啟選單／只聽這一格／播放／暫停」。

## 2. R171：浮動按鈕的調整

- 描述：
  - **音量滑桿**（`src/components/Cell.tsx`、`src/styles.css` 的 `.vol-group`）：
    - 浮動按鈕顯示時，滑鼠移到左上的聲音按鈕上 → 右邊展開音量滑桿與數值，按鈕和滑桿連成一個半透明膠囊（像 YouTube）。滑鼠離開 0.3 秒後收起；拖曳中不收起，滑桿展開時浮動按鈕不隱藏。
    - 點聲音按鈕照原本靜音／開聲音。音量 0 或靜音時圖示是靜音。
    - 範圍照 R98（可放大的來源到 200，超過 100 的一段是橘色）。雙擊滑桿回到預設音量。滑桿不留下鍵盤焦點，←／→ 仍是快轉、倒轉（R51）。
    - 格子寬度不到 360px 時滑桿短一點、不顯示數值。
    - 齒輪選單拿掉「音量」。
  - **整頁模式按鈕消失**：原因是游標從浮動按鈕移到網頁上時，格子收到 `mouseleave`，被當成離開格子而收回小把手。整頁模式改成只用主程序回報的游標位置判斷離開格子（R14 原本就用它判斷移入）。
  - **整頁模式的格子換位**：原因是找游標下的格子用 `document.elementsFromPoint`，整頁模式的格子 `pointer-events: none`，找不到。改成比對每一格的位置（`cellIndexAt`）。
  - **有聲音的圖示**：🔊 改成五條白色圓角直條的音波（15×12px，放在 20px 高的半透明底上），格子播放時上下跳動，暫停時停住；系統設定「減少動態效果」時不跳動。只有一格時不顯示照舊（R162 桌面版）。
  - **設定的標籤跑版**：R166 的浮動按鈕用了 `.chip` 類別，和設定視窗 yt-dlp 版本旁的 `chip` 標籤撞名（標籤被套上 40px 圓形）。浮動按鈕改名 `.fab`、`.fab-row`、`.cell-corner.fabs`。
  - **左右鍵的效果**（`src/lib/cellClick.ts`、`src/components/SettingsDialog.tsx`）：
    - 設定新增分類「滑鼠操作」，兩列「在影片上按左鍵」「在影片上按右鍵」，各自三選一：開啟選單、只聽這一格、播放／暫停。預設左鍵只聽這一格（和原本相同）、右鍵開啟選單。
    - 「開啟選單」在游標位置打開齒輪選單（從游標往右；游標在視窗下半部時往上），選單裡的亮度、畫質等也在那裡打開。
    - 「播放／暫停」和中間的播放鈕相同（還找不到影片時不作用）。「只聽這一格」照 R7（空白格、錯誤的格子不影響聲音）。
    - 只在影片上按鈕以外的地方作用。整頁模式、「直接操作」時滑鼠直接給網頁或播放器，不作用；整頁模式的右鍵仍是網頁的選單（R27）。
    - 設定檔：`settings.json` 最上層的 `cellClick`：`{"left": "solo", "right": "menu"}`，值是 `menu`、`solo`、`play`。桌面版自己的欄位；沒有這個欄位或不認得的值用預設值。手機版沒有滑鼠，不讀這個欄位。
- 驗收條件：
  - AC1：滑鼠移到聲音按鈕 → 右邊出現音量滑桿；拖曳改音量；點按鈕靜音／開聲音；齒輪選單沒有音量。
  - AC2：整頁模式的網頁格子：從「⋯」叫出按鈕，從左下移到右上的齒輪 → 按鈕不消失，可以按。
  - AC3：從影片格子按「移動」拖到整頁模式的網頁格子 → 出現藍色覆蓋，放開後交換位置。
  - AC4：多格時有聲音的格子左上角是小音波，播放時跳動、暫停時停住。
  - AC5：設定 → yt-dlp 的「已是最新版」標籤正常。
  - AC6：預設設定：在影片上按右鍵 → 游標位置出現齒輪選單；左鍵 → 只聽這一格。設定改成左鍵「播放／暫停」→ 左鍵暫停、播放；重新開啟程式後設定還在。

### 0.9.3 修正（使用者實測 0.9.2）
- **「滑鼠操作」設定頁整個畫面變黑**：主程序交給畫面的設定（`settings:getView`）是逐一列出欄位，漏了 `cellClick`，畫面讀到 `undefined` 就當掉。同一個原因也讓 R165 的 `companionOnLaunch` 每次開啟都是關閉（之後又被存成關閉），「開啟 App 時打開小視窗」實際上沒有作用。改成 `viewSettingsOf`：交給畫面除了 `version`、`window`、`companion` 以外的全部欄位，不再逐一列出（單元測試檢查欄位和 `normalizeView` 相同）。
- **齒輪再按一下關不掉**：選單、滑桿在 `pointerdown`（捕捉階段）判斷點在外面就關閉，畫面在按鈕的事件之前就更新，按鈕以為選單是關的又把它打開。改成：選單、滑桿有 `toggleKey`，按這一格的齒輪或 YouTube ▾（`data-popup-toggle` 相同）時不當作點在外面，交給按鈕自己開關。
- 驗收條件：
  - AC7：設定 → 滑鼠操作 → 正常顯示，可以切換；重新開啟程式後設定還在。
  - AC8：「開啟 App 時打開小視窗」打開後重新開啟程式（版型 1）→ 小視窗打開，設定仍是打開。
  - AC9：按齒輪打開選單，再按一次齒輪 → 關閉；從齒輪打開亮度滑桿後按齒輪 → 關閉。YouTube ▾ 相同。

## 3. R172：按住格子換位、滑桿支援滾輪與鍵盤

- 背景：使用者實測 0.9.3 正常後提出（2026-11-25）：換位要先按「移動」按鈕才能拖，想按住格子就能拖；音量、亮度等滑桿想用滑鼠滾輪和鍵盤調整。
- 描述：
  - **按住格子換位**（`src/components/Cell.tsx`）：
    - 在影片上（按鈕以外的地方）按住左鍵、移動超過 6px 就開始換位，和按住「移動」按鈕拖曳相同（藍色覆蓋、放開交換、放在原本的格子或視窗外不做事，R6）。拖曳中游標是抓取的樣子。
    - 移動不到 6px 就放開，照原本算點一下（左鍵的效果照 R171 的設定）；拖曳後放開不算點一下。
    - 只有一格、空白格不能拖。整頁模式、「直接操作」時滑鼠給網頁或播放器，仍用「移動」按鈕。「移動」按鈕保留。
  - **滑桿的滾輪與鍵盤**（`src/lib/sliderInput.ts`）：
    - 適用：左上聲音按鈕旁的音量滑桿（R171）、齒輪選單的亮度滑桿、工具列的總亮度滑桿（`SliderPopup`）。
    - 滾輪：滑鼠在滑桿（音量是聲音按鈕或滑桿）上，往上捲加、往下捲減，一格調 5。觸控板的小幅捲動累積到一格（100px）才調整，換方向重新累積。在聲音按鈕上捲動時滑桿一起展開。
    - 鍵盤：滑桿開著時（音量是滑鼠在聲音按鈕或滑桿上），↑ → 加 5、↓ ← 減 5，PageUp／PageDown 一次 25，Home／End 到最小／最大。這時 ← → 不當作快轉、倒轉（R51），放開滑桿後恢復。
    - 範圍照原本（音量 0–100，可放大的來源到 200；亮度 20–150%）。
- 驗收條件：
  - AC1：在影片上按住拖到別的格子 → 藍色覆蓋，放開後交換；只是點一下 → 不換位，照左鍵的設定作用。
  - AC2：滑鼠在聲音按鈕上滾動滾輪 → 音量一格 5 增減；按 ↑ ↓ → 音量增減；移開後 ← → 恢復快轉、倒轉。
  - AC3：齒輪 → 亮度：滾輪與方向鍵可以調；工具列的總亮度相同。

## 4. 對前置規格的影響

| 前置需求 | 變更 |
|---|---|
| R7（點影片獨占聲音） | 左鍵的預設照舊；可以在設定改成其他效果（R171） |
| R42、R166（音量在齒輪選單的滑桿） | 改成滑鼠移到左上的聲音按鈕時展開 |
| R117、R166（整頁模式的浮動按鈕） | 修正游標移到網頁上時按鈕收回 |
| R6（拖曳換位） | 修正拖到整頁模式的格子；在影片上按住拖曳也能換位（R172） |
| R40–R42、R98（亮度、音量滑桿） | 可以用滾輪和鍵盤調整（R172） |
| R51（← → 快轉、倒轉） | 滑桿開著時 ← → 調整數值（R172） |
