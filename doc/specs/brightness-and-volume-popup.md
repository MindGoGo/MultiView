- 功能代號：`brightness-and-volume-popup`
- Jira：無
- 狀態：已確認、已複查、已實作
- 最後更新：2026-10-09
- 前置規格：[multiview-player](multiview-player.md)（R1–R11）、[web-page-source](web-page-source.md)（R12–R18）、[player-controls-and-lists](player-controls-and-lists.md)（R19–R25）、[cell-play-and-page-menu](cell-play-and-page-menu.md)（R26–R29）、[captions-and-quality-menu](captions-and-quality-menu.md)（R30–R33）。本規格的需求編號從 R40 開始；R34–R39 保留給之後的本機播放與下載功能。

## 1. 背景與目標

不同直播的畫面亮度差很多，晚上看時有的格子太亮、有的太暗，只能調整整個螢幕的亮度。這次讓每一格可以各自調整亮度，並在工具列提供一次調整全部格子的總亮度。同時把操作區的音量滑桿改成按鈕＋彈出滑桿，讓操作區更精簡。

## 2. 範圍

**包含：**
- 每格的亮度（R40）
- 工具列的總亮度（R41）
- 音量滑桿改成按鈕＋彈出滑桿（R42）
- 版本號更新並打包（R43）

**不包含：**
- 對比、飽和度、色溫等其他畫面調整
- 調整螢幕的實際背光亮度（只是把畫面的顏色調暗或調亮）
- 用鍵盤或滑鼠滾輪調整亮度、音量

## 3. 共用定義

- **實際亮度：** 格子亮度 × 總亮度。例如總亮度 80%、格子亮度 120%，實際亮度是 96%。範圍是 4%–225%，不另外設上限。
- **滑桿選單：** R40–R42 的彈出視窗，內容是一條滑桿、目前的百分比和「重設」按鈕。拖曳滑桿時立即生效；按 Esc、點選單外面就關閉（和 R31、R32 的格子選單相同的關閉方式）。格子的滑桿選單開著時，操作區不會自動隱藏。格子裡的滑桿選單出現在按鈕上方，工具列的滑桿選單出現在按鈕下方，都限制在視窗範圍內。

## 4. 需求清單

### R40：每格的亮度
- 描述：
  - 有來源的格子，操作按鈕多一個「☀」按鈕，按下後出現滑桿選單：範圍 20%–150%，每格 5%，預設 100%；「重設」回到 100%。
  - 亮度只作用在影片畫面（包括 YouTube、mp4、m3u8、網頁來源的整個網頁），不影響格子上的操作按鈕、進度條、中央播放鈕、聲音圖示和網址輸入框。例外：網頁來源的提示文字（例如「找不到影片…」）畫在網頁那一層，會一起變暗或變亮。
  - 單格全螢幕、錯誤狀態的格子也可以調整。
  - 亮度不是 100% 時，「☀」按鈕顯示為啟用狀態（和其他已開啟的按鈕相同的強調樣式）。
  - 每格的亮度跟著來源：拖曳換位時一起移動，保存在設定檔；更換網址時保留。舊的設定檔沒有這個欄位時視為 100%。
  - 調整亮度不重新載入影片、不影響播放和聲音。
- 驗收條件：
  - AC1：按某一格的「☀」，把滑桿拖到 50% → 拖曳過程中那一格的畫面跟著變暗，其他格不變；操作按鈕的亮度不變。
  - AC2：拖到 150% → 那一格的畫面變亮。
  - AC3：按「重設」→ 回到 100%，「☀」不再是啟用狀態。
  - AC4：YouTube、m3u8、網頁來源（影片模式和整頁模式）的格子都能調整。
  - AC5：設成 60% 後關閉程式再開啟 → 仍然是 60%；和另一格換位 → 亮度跟著影片移動。
  - AC6：調整過程中影片持續播放，沒有重新載入。
  - AC7：舊的設定檔 → 讀取後每格都是 100%。

### R41：工具列的總亮度
- 描述：
  - 全域工具列多一個「☀ 100%」按鈕（顯示目前的總亮度），按下後出現滑桿選單：範圍 20%–150%，每格 5%，預設 100%；「重設」回到 100%。
  - 每格畫面的實際亮度是「格子亮度 × 總亮度」。
  - 滑桿選單開著時，工具列不會自動隱藏。
  - 總亮度保存在設定檔；舊的設定檔視為 100%。
- 驗收條件：
  - AC1：四格亮度都是 100%，總亮度拖到 50% → 四格都變暗。
  - AC2：其中一格亮度 120%、總亮度 80% → 那一格的實際亮度是 96%，其他格是 80%。
  - AC3：關閉程式再開啟 → 總亮度保留。
  - AC4：滑桿選單開著時，滑鼠離開視窗頂端，工具列仍然顯示。

### R42：音量改成按鈕＋彈出滑桿
- 描述：
  - 操作區的音量滑桿（第一版 R7）改成一個顯示目前音量的按鈕（例如「🔉 70」，格子窄時只顯示「🔉」），按下後出現滑桿選單：範圍 0–100，每格 1；「重設」回到 100。
  - 喇叭按鈕（切換靜音）維持不變。
  - 音量的規則和第一版 R7 相同：只影響這一格、跟著來源保存和換位。
- 驗收條件：
  - AC1：操作區沒有常駐的音量滑桿，改成音量按鈕。
  - AC2：按音量按鈕，把滑桿拖到 30 → 這一格的音量變成 30，按鈕顯示「🔉 30」；其他格不變。
  - AC3：按「重設」→ 音量回到 100。
  - AC4：`3×3` 且視窗縮到最小 → 所有操作按鈕都看得到、按得到（第二版 R14 AC7）。

### R43：版本號

- 驗收條件：
  - AC1：`npm run dist` → 產生 `release/MultiView-0.3.1-portable.exe`，檔案內容的版本是 0.3.1。

## 8. 非功能需求

- **效能：** 亮度以顯示卡處理的畫面濾鏡實作，九格同時調整時播放不卡頓（手動驗收）。
- **技術風險：** 網頁來源的 `<webview>`、YouTube 的 iframe 套用 CSS 濾鏡後要能正常顯示；做不到時要停下來回報。
- **測試：** 亮度、音量的數值範圍與設定檔相容、實際亮度的計算寫成單元測試；畫面效果以截圖手動驗收。
- **實作結果：** `<webview>`、YouTube 的 iframe、m3u8 的影片套用 CSS `brightness()` 濾鏡都正常顯示，調整時不重新載入。多了「☀」按鈕後，`3×3` 最小格子的按鈕排成四列，最上面一列格子會超出視窗上緣；把窄格子的按鈕左右間距從 6px 縮成 4px 後排回三列（R42 AC4）。
