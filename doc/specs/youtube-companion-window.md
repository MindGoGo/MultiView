- 功能代號：`youtube-companion-window`
- Jira：無

- 前置規格：[youtube-browse-and-subscriptions](youtube-browse-and-subscriptions.md)（R57–R62）、[youtube-back-to-page](youtube-back-to-page.md)（R63–R65）、[youtube-page-mode](youtube-page-mode.md)（R66–R68）、[youtube-menu-tweaks](youtube-menu-tweaks.md)（R69–R72）、[youtube-adblock-fix](youtube-adblock-fix.md)（R73–R74）、[pause-start-and-version](pause-start-and-version.md)（R75–R77）。本規格的需求編號從 R78 開始。

## 1. 背景與目標

看 YouTube 時想同時看推薦影片、留言、直播聊天室，或另外搜尋影片，現在只能把格子切到網頁模式，會擋住影片（2026-11-01 使用者需求）。

目標：一個獨立的「YouTube 小視窗」，上方分頁切換「推薦」「留言」「聊天室」「搜尋」，影片照常在格子裡播放。

## 2. 範圍

**包含：**
- YouTube 小視窗與分頁（R78）
- 推薦影片（R79）
- 留言（R80）
- 聊天室（R81）
- 手機版搜尋（R82）
- 版本號更新並打包（R83）

**不包含：**
- 留言、聊天室發言、按讚、訂閱（不能登入）
- 同時開多個小視窗
- 非 YouTube 的格子

## 3. 共用定義

- **YouTube 小視窗：** 和 MultiView 主視窗分開的獨立視窗，可以拖曳、調整大小、放到其他螢幕。
- **連結的格子：** 推薦、留言、聊天室顯示哪一格的內容。從某一格的「YouTube ▾」開啟時就是那一格；之後在另一格的選單開啟時換成那一格。連結的是格子的位置：拖曳換位後，顯示換到這個位置的影片。
- **格子目前的影片：** 連結的格子正在播放的 YouTube 影片：一般播放的影片，或 YouTube 網頁模式「網頁上目前的影片」（第十四版 R66）。
- **放入格子的規則：** 和清單面板「點一下」相同（第十三版 R64）：有空格放進第一個空格；單格顯示直接取代；其他情況跳出選擇要取代的格子。

## 4. 需求清單

### R78：YouTube 小視窗
- 描述：
  - 開啟方式：
    - 一般 YouTube 播放與網頁模式的格子，「YouTube ▾」選單多三項：「推薦影片」「留言」「聊天室」→ 開啟小視窗並切到對應的分頁，連結的格子是這一格。
    - 工具列多一個「YouTube 小視窗」按鈕 → 開啟小視窗（已開啟時切到最前面），顯示上次的分頁；第一次開啟時是「搜尋」。
  - 小視窗上方：分頁「推薦」「留言」「聊天室」「搜尋」，以及推薦、留言、聊天室分頁顯示的「第 N 格：影片名稱」。
  - 只有一個小視窗；已經開著時，再次開啟就切換分頁、更新連結的格子，並切到最前面。
  - 連結的格子換了影片（更換網址、從清單放入、在網頁模式換影片、回到剛才的 YouTube 頁面後再點影片），推薦、留言、聊天室自動換成新的影片。
  - 連結的格子沒有 YouTube 影片（空格、移除、換成其他網站）時，推薦、留言、聊天室顯示「這一格沒有 YouTube 影片」。
  - 小視窗的位置與大小保存在設定檔；關閉 MultiView 時一起關閉；重開 MultiView 時不自動開啟。
  - 小視窗附屬於主視窗：永遠在主視窗上面（主視窗置頂、全螢幕時也看得到），主視窗最小化時一起縮小；可以拖到其他螢幕。
  - 切換分頁時，各分頁的網頁保留（不重新載入），回來時停在原本的位置。推薦和留言是同一部影片的網頁，共用一個網頁、只切換顯示的區域。
  - 小視窗裡的網頁都套用廣告阻擋（第十六版 R73）。
- 驗收條件：
  - AC1：在第 2 格（YouTube）按「YouTube ▾」→「留言」→ 小視窗開啟在「留言」分頁，標題顯示「第 2 格：影片名稱」。
  - AC2：小視窗開著時在第 3 格按「YouTube ▾」→「推薦影片」→ 同一個小視窗切到「推薦」，顯示第 3 格的影片。
  - AC3：第 3 格更換成其他 YouTube 影片 → 推薦自動換成新影片的推薦。
  - AC4：移除第 3 格 → 推薦顯示「這一格沒有 YouTube 影片」。
  - AC5：移動、調整小視窗後關閉 MultiView 再開啟，按工具列的「YouTube 小視窗」→ 在上次的位置與大小開啟。

### R79：推薦影片
- 描述：
  - 「推薦」分頁顯示格子目前影片在 YouTube 網頁上的推薦影片清單（只顯示推薦區，不顯示影片本身；網頁裡的影片不播放、沒有聲音：網頁一開始播放就暫停，播放器整個隱藏）。
  - 點推薦影片時網頁不換頁（在網頁裡攔下影片連結，和第十三版 R63 相同），交給連結的格子播放。
  - 點推薦影片 → 連結的格子換成那部影片（和「更換網址」相同）。
- 驗收條件：
  - AC1：推薦分頁只看得到推薦影片清單，沒有影片畫面也沒有聲音。
  - AC2：點一部推薦影片 → 連結的格子播放那部影片；推薦分頁接著顯示新影片的推薦。

### R80：留言
- 描述：
  - 「留言」分頁顯示格子目前影片的留言區（只顯示留言區；網頁裡的影片不播放、沒有聲音），可以捲動、展開回覆、切換排序。
  - 留言裡的時間連結（例如「3:15」）→ 連結的格子跳到那個時間（同一部影片帶時間的連結）；留言裡其他影片的連結 → 連結的格子換成那部影片。
  - 影片關閉留言時，顯示 YouTube 自己的「留言功能已關閉」。
- 驗收條件：
  - AC1：留言分頁顯示留言，可以往下捲動載入更多。
  - AC2：點留言裡的「3:15」→ 連結的格子跳到 3:15。

### R81：聊天室
- 描述：
  - 「聊天室」分頁顯示格子目前影片的 YouTube 聊天室（YouTube 的彈出式聊天室）。只支援正在直播的影片（以播放器回報的「直播」判斷）；聊天重播不支援。
  - 不是直播的影片顯示「這部影片沒有聊天室（只有直播有）」。
- 驗收條件：
  - AC1：連結的格子是直播 → 聊天室分頁顯示即時訊息並持續更新。
  - AC2：一般影片 → 顯示「這部影片沒有聊天室（只有直播有）」。

### R82：手機版搜尋
- 描述：
  - 「搜尋」分頁以手機版 YouTube（m.youtube.com）的排版顯示，可以搜尋、瀏覽、看頻道。
  - 點影片 → 依「放入格子的規則」放進格子；網頁不換頁（停在原本的搜尋結果）。需要選擇要取代的格子時，主視窗切到最前面並跳出選擇框。
  - 搜尋分頁的內容和連結的格子無關；切換分頁時保留搜尋結果與捲動位置。
- 驗收條件：
  - AC1：搜尋分頁顯示手機版排版，可以搜尋。
  - AC2：有空格時點一部影片 → 放進第一個空格並播放；搜尋結果不變。
  - AC3：單格顯示時點影片 → 取代那一格。
  - AC4：`2×2` 四格都有影片時點影片 → 主視窗跳出選擇要取代的格子（第十三版 R64）。
  - AC5：切到推薦再切回搜尋 → 搜尋結果和捲動位置不變。

## 8. 非功能需求

- **安全：** 小視窗的網頁和網頁來源相同，在沙箱中執行，只載入程式的偵測程式；不開新視窗。
- **效能：** 推薦、留言分頁的網頁不播放影片（停止並靜音），避免多一路影片的網路與解碼。
- **技術風險：**
  - 「只顯示推薦區／留言區」依賴 YouTube 網頁的結構，YouTube 改版時可能失效；失效時顯示整個網頁（仍可使用）。
  - 手機版 YouTube 需要以手機的瀏覽器識別開啟；YouTube 可能要求同意 cookie 等。
- **測試：** 網址的組合（聊天室、手機版）、放入格子的規則寫成單元測試；畫面以手動驗收。
