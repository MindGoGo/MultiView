# 整頁模式時工具列與操作列不擋網頁 規格

- 功能代號：`page-mode-overlays`
- Jira：無
- 狀態：已確認、已複查、已實作
- 最後更新：2026-11-08
- 前置規格：[web-autoplay-and-cloudflare](web-autoplay-and-cloudflare.md)（R113–R115）。本規格的需求編號從 R116 開始。

## 1. 背景與目標

2026-11-08 使用者回報：整頁模式時，網頁上的按鈕或搜尋欄可能被程式的工具列擋住。

原因：滑鼠進到視窗最上面 40 像素，工具列就立刻出現（第一版 R3）；工具列也是 40 像素高，蓋在最上排格子上面。網站的搜尋欄和選單通常在頁面頂端，滑鼠一移過去，工具列就蓋住要點的東西。格子底部的操作列也有同樣的問題：滑鼠移到格子上就出現，蓋住網頁底部。

使用者選擇（2026-11-08）：整頁模式時縮小工具列的感應區；底部操作列也一起處理，平常收成小把手。

## 2. 範圍

**包含：**
- 整頁模式時工具列的感應區（R116）
- 整頁模式時操作列收成小把手（R117）
- 版本號（R118）

**不包含：**
- 影片模式、內嵌播放器、yt-dlp 播放、mp4、m3u8、空白格的工具列與操作列（行為不變）
- 「直接操作」（第一版 R3）：只是暫時操作，行為不變
- 提示文字、清單面板、設定視窗讓工具列保持顯示的規則（R97 以前的規則不變）

## 3. 共用定義

- **整頁模式的格子：** 網頁來源顯示整個網頁的格子（第二版 R14），包括 YouTube 網站頁面（R57）與 YouTube 網頁模式（R66）。
- **上緣感應區：** 視窗最上面 6 像素。

## 4. 需求清單

### R116：整頁模式時工具列的感應區
- 描述：
  - 滑鼠在整頁模式的格子上方時，要進到上緣感應區並停留 0.3 秒，工具列才出現。
  - 停留不到 0.3 秒就離開上緣感應區，工具列不出現。
  - 工具列出現後，滑鼠在最上面 40 像素內都維持顯示（才能移到工具列的按鈕上）；離開後和現在一樣 1 秒後隱藏。
  - 滑鼠在其他格子（影片模式、空白格等）上方時，規則和現在相同：進到最上面 40 像素立即出現。
  - 判斷依據是滑鼠水平位置下方的那一格，所以同一排的格子可以各自適用不同規則。
  - 工具列隱藏時，中間的拖曳視窗區域不作用。原本它隱藏時仍然會攔下滑鼠，蓋在網頁頂端的部分點不到。工具列顯示時照常可以拖曳視窗。
- 驗收條件：
  - AC1：最上排是整頁模式的格子，滑鼠移到距離視窗上緣 10–40 像素的位置（包括視窗水平中間）→ 工具列不出現，可以點網頁的搜尋欄。
  - AC2：滑鼠移到上緣 6 像素內，停留 0.3 秒 → 工具列出現；往下移到工具列按鈕上 → 維持顯示，可以按。
  - AC3：滑鼠快速掠過上緣（不到 0.3 秒）→ 工具列不出現。
  - AC4：滑鼠在影片模式的格子上方進到最上面 40 像素 → 工具列立即出現（和 0.8.2 相同）。
  - AC6：工具列顯示時，按住中間空白處 → 可以拖曳視窗。
  - AC5：2×2 左上是整頁模式、右上是影片模式 → 滑鼠在左上方時依 AC1，在右上方時依 AC4。

### R117：整頁模式時操作列收成小把手
- 描述：
  - 整頁模式的格子，滑鼠移到格子上時，右下角只出現一個小把手（約 32×20 像素，顯示「⋯」），不出現整條操作列。
  - 滑鼠移到小把手上 → 展開成原本的操作列。滑鼠留在操作列上時維持展開。
  - 滑鼠離開操作列 0.3 秒後收回小把手；操作列裡的選單、滑桿開著時不收回。
  - 播放方式的小標示（R109）在整頁模式只在操作列展開時顯示，平常不蓋住網頁左上角。
  - 滑鼠離開格子 → 小把手和操作列都隱藏（和現在相同）。
  - 切回影片模式 → 恢復原本的操作列。
  - 從影片模式按「顯示整個網頁」切到整頁模式 → 操作列立即收成小把手。
- 驗收條件：
  - AC1：滑鼠移到整頁模式的格子上 → 右下角只有小把手，網頁底部其他位置可以點。
  - AC2：滑鼠移到小把手上 → 展開操作列，所有按鈕可以按（「只顯示影片」「更換網址」等）。
  - AC3：滑鼠離開操作列 → 0.3 秒後收回小把手。
  - AC4：開著音量滑桿或選單，滑鼠離開操作列 → 不收回。
  - AC5：操作列收起時左上角沒有小標示；展開時有。
  - AC6：影片模式的格子 → 和 0.8.2 相同，沒有小把手。
  - AC7：`3×3` 且視窗最小 → 小把手在格子內，按得到。

### R118：版本號

- 驗收條件：
