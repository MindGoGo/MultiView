# YouTube 網頁播放、進度條預覽、快轉倒轉 規格

- 功能代號：`youtube-web-and-seek`
- Jira：無
- 狀態：已確認、已複查、已實作
- 最後更新：2026-10-10
- 前置規格：[multiview-player](multiview-player.md)（R1–R11）、[web-page-source](web-page-source.md)（R12–R18）、[player-controls-and-lists](player-controls-and-lists.md)（R19–R25）、[cell-play-and-page-menu](cell-play-and-page-menu.md)（R26–R29）、[captions-and-quality-menu](captions-and-quality-menu.md)（R30–R33）、[brightness-and-volume-popup](brightness-and-volume-popup.md)（R40–R43）、[installer-and-youtube-fixes](installer-and-youtube-fixes.md)（R44–R47）。本規格的需求編號從 R48 開始；R34–R39 仍保留給本機播放與下載功能。

## 1. 背景與目標

- 很多 YouTube 影片（音樂 MV、電視台節目等）的上傳者不允許嵌入，格子只能顯示「此影片無法在外部播放」，但這些影片在 YouTube 網站上可以正常觀看。
- 進度條只能看到目前位置，不知道滑鼠指到的地方是幾分幾秒，也看不到那個位置的畫面。
- 想往回看幾秒或略過一小段，只能拖曳進度條，不夠精確。

目標：禁止嵌入的 YouTube 影片可以改用 YouTube 網頁播放；進度條顯示滑鼠位置的時間與預覽縮圖；可以用鍵盤或按鈕快轉、倒轉 5 秒。

## 2. 範圍

**包含：**
- 禁止嵌入的 YouTube 影片改用網頁播放（R48）
- 工具列的設定選單與「自動改用網頁播放」（R49）
- 進度條的時間提示與預覽縮圖（R50）
- 快轉、倒轉 5 秒（R51）
- 版本號更新並打包（R52）

**不包含：**
- Netflix、Disney+ 等有 DRM 的付費串流（2026-10-10 討論：技術與授權限制，不做）
- m3u8、網頁來源的預覽縮圖（只顯示時間）
- 改用網頁播放的格子改回嵌入播放（禁止嵌入的影片本來就無法嵌入播放）
- 「直接操作」時焦點在 YouTube 播放器裡的方向鍵（YouTube 播放器的鍵盤操作已關閉，第一版設計）
- 自訂快轉秒數

## 3. 共用定義

- **禁止嵌入：** YouTube 播放器回報錯誤碼 101 或 150（上傳者不允許在其他網站播放）。
- **YouTube 網頁播放：** 這一格改用網頁來源（第二版 R12–R18）載入這部影片的 YouTube 網頁 `https://www.youtube.com/watch?v=<影片代碼>`，預設以影片模式只顯示影片畫面。之後的操作、限制都和其他網頁來源相同：有影片模式／整頁模式切換、廣告阻擋按鈕、進度條（偵測到影片時）；沒有畫質、字幕選單。
- **目前操作的格子：** 單格全螢幕時是放大的那一格；否則是滑鼠所在的那一格（滑鼠停著不動、操作區已經自動隱藏時也算）。都沒有時沒有目前操作的格子。

## 4. 需求清單

### R48：禁止嵌入的 YouTube 影片改用網頁播放
- 描述：
  - YouTube 格子遇到禁止嵌入時，錯誤訊息「此影片無法在外部播放」下方多一個「改用 YouTube 網頁播放」按鈕，按下後這一格改成 YouTube 網頁播放。
  - YouTube 的其他錯誤顯示不同的訊息，不顯示這個按鈕：
    - 錯誤碼 100：「找不到這部影片，可能已刪除或不公開」
    - 其他錯誤碼：「這部影片無法播放」
  - 注意：YouTube 嵌入播放器對不存在的影片代碼也回報 150（2026-10-10 實測），所以不存在的影片也會顯示「此影片無法在外部播放」和按鈕；按下後由 YouTube 網頁顯示影片無法播放。
  - 改用網頁播放時：
    - 影片模式時，YouTube 網頁的影片移到網頁最外層（離開影片模式時放回原位）：影片留在 YouTube 的播放器容器裡放大時，整個網頁畫不出來（全黑但有聲音）。畫質由 YouTube 自動決定。
    - 格子的網址維持原本的 YouTube 網址（清單、歷史、最愛都用這個網址）。
    - 廣告阻擋預設關閉；可以用原本的「廣告阻擋」按鈕開啟。
    - 音量、靜音、亮度保留。
    - 使用者放入的影片（貼上、從清單放入、更換網址）在網頁載入完成時記錄到歷史（第三版 R23）；名稱是網頁標題去掉結尾的「 - YouTube」。
  - 改用網頁播放的狀態跟著來源保存、換位一起移動；關閉程式再開啟仍然是網頁播放。
  - 在這一格「更換網址」成其他網址時，回到一般的判斷（新的 YouTube 網址先用嵌入播放）。
  - 年齡限制、需要登入的影片：可以切到整頁模式，在 YouTube 網頁登入（登入狀態和其他網頁來源共用）。
- 驗收條件：
  - AC1：放入禁止嵌入的影片 → 顯示「此影片無法在外部播放」和「改用 YouTube 網頁播放」。
  - AC2：按「改用 YouTube 網頁播放」→ 這一格載入 YouTube 網頁，以影片模式只顯示影片並開始播放；廣告阻擋是關閉的。
  - AC3：AC2 之後關閉再開啟程式 → 這一格仍是網頁播放；和另一格換位 → 跟著移動。
  - AC4：AC2 的格子可以拖曳進度條、播放／暫停、調音量和亮度。
  - AC5：放入不存在的影片代碼 → YouTube 回報禁止嵌入（150），顯示「此影片無法在外部播放」和按鈕；按下後 YouTube 網頁顯示影片無法播放。（原本要求顯示「找不到這部影片」，因 YouTube 的回報做不到，2026-10-10 修改）
  - AC6：AC2 的格子更換成可以嵌入的 YouTube 網址 → 用一般的嵌入播放。
  - AC7：在空白格貼上禁止嵌入的影片並改用網頁播放 → 網頁載入完成後歷史多一筆，網址是原本的 YouTube 網址。

### R49：設定選單與「自動改用網頁播放」
- 描述：
  - 工具列新增「⚙ 設定」按鈕，按下出現設定選單（和格子的選單相同的樣式與關閉方式：按 Esc 或點選單外面關閉）。選單開著時工具列不自動隱藏。
  - 選單裡有一個可勾選的項目「YouTube 無法嵌入時自動改用網頁播放」，預設不勾選。
  - 勾選時：YouTube 格子遇到禁止嵌入，直接改成 YouTube 網頁播放（不顯示錯誤訊息和按鈕）。
  - 勾選與否保存在設定檔，關閉程式再開啟仍然保留。舊的設定檔沒有這個設定時視為不勾選。
  - 只影響之後遇到的禁止嵌入（包括開啟程式時自動還原的格子）；已經在顯示錯誤訊息的格子不會自動改變。
- 驗收條件：
  - AC1：工具列有「⚙ 設定」，按下出現選單，有「YouTube 無法嵌入時自動改用網頁播放」，預設不勾選。
  - AC2：勾選後放入禁止嵌入的影片 → 不顯示錯誤，直接改成網頁播放並開始播放。
  - AC3：取消勾選後放入禁止嵌入的影片 → 顯示錯誤訊息和按鈕（R48 AC1）。
  - AC4：勾選後關閉再開啟程式 → 仍然勾選。
  - AC5：設定選單開著時，滑鼠離開視窗頂端，工具列仍然顯示。

### R50：進度條的時間提示與預覽縮圖
- 描述：
  - 滑鼠移到進度條上時，游標上方出現提示，顯示游標位置對應的時間：一般影片是 `m:ss`（一小時以上 `h:mm:ss`）；可回放的直播是距離直播最新位置的時間，例如 `-1:23`。拖曳進度條時也顯示，跟著游標移動。滑鼠離開進度條就消失。
  - YouTube（嵌入播放）和 mp4 的提示在時間上方多一張預覽縮圖，是游標位置附近的畫面：
    - YouTube 使用 YouTube 提供的預覽縮圖；取得失敗或沒有縮圖（例如直播）時只顯示時間。
    - mp4 跳到游標位置附近取得畫面；還沒取得時只顯示時間。
  - m3u8、網頁來源（包括 YouTube 網頁播放）只顯示時間。
  - 預覽縮圖寬 160px（依影片比例）；格子寬度放不下縮圖時只顯示時間。
  - 提示限制在格子範圍內，不會超出格子左右兩邊。
  - 沒有進度條的情況（沒有回放範圍的直播等）沒有提示。
  - 游標在進度條上時，操作區不因滑鼠靜止而自動隱藏（否則停下來看縮圖時提示會消失）；離開進度條後重新計算靜止時間。
- 驗收條件：
  - AC1：10 分鐘的 mp4，滑鼠移到進度條正中央 → 提示顯示 `5:00` 左右，上方有那個位置的畫面。
  - AC2：YouTube 影片 → 提示有預覽縮圖，滑鼠左右移動時縮圖跟著換。
  - AC3：m3u8 點播 → 只有時間。可回放的直播 → 顯示 `-m:ss`。
  - AC4：滑鼠移到進度條最左、最右邊 → 提示完整顯示在格子內。
  - AC5：拖曳進度條時提示跟著游標；放開、滑鼠離開進度條後消失。
  - AC6：mp4 播放中顯示預覽縮圖 → 播放不中斷、聲音不受影響。

### R51：快轉、倒轉 5 秒
- 描述：
  - 有目前操作的格子、而且它有進度條時，按鍵盤 → 快轉 5 秒，← 倒轉 5 秒。按住會連續快轉或倒轉（網頁來源有焦點時也一樣）。
  - 用方向鍵跳轉時，那一格的操作區顯示出來（和滑鼠移動時相同，2 秒後自動隱藏），可以看到跳轉後的時間。
  - 進度條的播放／暫停按鈕右邊多兩個按鈕「⏪」（倒轉 5 秒）、「⏩」（快轉 5 秒）。格子寬度小於 360px 時不顯示這兩個按鈕（鍵盤照常可用）。
  - 跳轉後維持原本的播放或暫停狀態（第三版 R19）。不會超出可跳轉的範圍：倒轉最多到開頭（直播為可回放範圍的開始），快轉最多到結尾（直播為最新位置）。
  - 沒有回放範圍的直播、沒有進度條的格子：方向鍵和按鈕都不動作（沒有按鈕）。
  - 焦點在文字輸入框（網址輸入框、清單的改名）時，方向鍵照原本的作用移動游標。
  - 整頁模式的網頁有焦點時，方向鍵交給網頁（捲動網頁）。
- 驗收條件：
  - AC1：滑鼠在一格 mp4 上，按 → → 進度往後 5 秒；按 ← → 往前 5 秒；其他格不變。
  - AC10：滑鼠停在格子上不動，操作區自動隱藏後按 → → 仍然快轉，操作區重新顯示。
  - AC2：單格全螢幕時，滑鼠不在畫面上也可以用方向鍵快轉、倒轉那一格。
  - AC3：暫停中按 → → 跳轉後仍然暫停。
  - AC4：在 0:03 按 ← → 跳到 0:00；在結尾前 2 秒按 → → 跳到結尾。
  - AC5：按住 → 2 秒 → 連續往後跳轉。
  - AC6：按「⏪」「⏩」→ 和方向鍵相同。`3×3` 視窗最小時 → 沒有這兩個按鈕，其他按鈕都看得到、按得到（R42 AC4）。
  - AC7：網址輸入框有焦點時按 ← → → 只移動輸入框的游標，影片不跳轉。
  - AC8：滑鼠不在任何格子上、也不是單格全螢幕時按 → → 沒有任何格子跳轉。
  - AC9：YouTube、m3u8 點播、可回放的直播、網頁來源（影片模式）都可以快轉、倒轉。

## 8. 非功能需求

- **效能：** mp4 的預覽縮圖只在滑鼠停在進度條上時取得，離開後釋放；不影響正在播放的影片。YouTube 預覽縮圖的資訊每部影片只取得一次。
- **實作結果：**
  - YouTube 網頁播放：YouTube 會不斷改寫影片元素的位置和大小，蓋掉影片模式的放大樣式；改成監看主要影片的 style，被改寫時立刻補回（所有網頁來源都適用）。
  - YouTube 網頁播放的黑畫面（2026-10-10 使用者回報 `yE7nLbXTZ6o`：開始約 1 秒有畫面，之後全黑但有聲音）：影片留在 YouTube 的 `#player-container` 裡放大時，整個網頁都畫不出來；關閉硬體解碼、關閉影片疊加層、改變縮放方式、拿掉外層的裁切與圓角、劇院模式都無效，把影片移到 `#player-container` 外面（例如 body）就正常。所以影片模式在 YouTube 網頁上把主要影片移到 body，離開影片模式時放回原位；YouTube 沒有把它搬回去（觀察 60 秒），被搬回時下一次檢查會再移出。初版以「不縮小排版」暫時避開（格子小時剛好沒觸發），找到原因後改回和其他網站一樣放大排版再縮小。
  - YouTube 網頁播完或使用者在整頁模式操作時，網頁可能自己換到下一部影片；格子的網址仍是原本的影片，重新開啟程式時回到原本的影片。
  - YouTube 預覽縮圖：從 `https://www.youtube.com/watch?v=<代碼>` 的 HTML 取出 `playerStoryboardSpecRenderer`，選寬度不超過 320px 的最大等級，以 160px 寬顯示。
  - mp4 預覽：另一個靜音、不播放的影片元素跳到游標位置，提示消失時釋放。
- **技術風險：**
  - YouTube 的預覽縮圖不是公開的介面，要從 YouTube 網頁取得縮圖資訊，YouTube 改版時可能失效；失效時只顯示時間（R50），不影響其他功能。
  - 網頁來源的影片偵測、影片模式能不能正常用在 YouTube 網頁上（例如 YouTube 網頁的廣告、同意畫面），實作時先驗證；做不到時停下來回報。
  - mp4 的預覽要另外連線讀取影片，有些網站可能限制同時連線。
- **測試：** 錯誤碼對應、跳轉目標的計算（範圍限制）、方向鍵對應、預覽縮圖資訊的解析、設定檔相容寫成單元測試；畫面以截圖手動驗收。
