# 格子播放／暫停按鈕、整頁模式右鍵選單與上下頁 規格

- 功能代號：`cell-play-and-page-menu`
- Jira：無
- 狀態：已確認、已複查
- 最後更新：2026-10-09
- 前置規格：[multiview-player](multiview-player.md)（R1–R11）、[web-page-source](web-page-source.md)（R12–R18）、[player-controls-and-lists](player-controls-and-lists.md)（R19–R25）。本規格的需求編號從 R26 接續，沿用前置規格的「共用定義」。

## 1. 背景與目標

目前要暫停某一格，只能用「全部暫停」或點進網站自己的按鈕；網頁來源的整頁模式雖然可以操作網頁，但沒有右鍵選單（不能複製、貼上），也不能回到上一頁。這次在每格的進度條旁加上播放／暫停按鈕，並讓整頁模式的網頁可以用右鍵選單和上下頁。

## 2. 範圍

**包含：**
- 每格的播放／暫停按鈕（R26）
- 整頁模式的右鍵選單：剪下、複製、貼上、全選、上一頁、下一頁、重新整理、複製連結網址（R27）
- 整頁模式的上一頁／下一頁：格子按鈕、右鍵選單、滑鼠側鍵（R28）
- 版本號更新為 0.2.1 並打包（R29）

**不包含：**
- 影片模式（包括「直接操作」）的右鍵選單
- 網頁的瀏覽紀錄保存：關閉程式後上一頁／下一頁的紀錄不保留，重新開啟時從當初貼上的網址開始
- 右鍵選單的其他項目（例如另存圖片、檢查元素、拼字檢查）
- 用鍵盤（例如 Alt + ←）上一頁

## 3. 需求清單

### R26：每格的播放／暫停按鈕
- 描述：
  - 有進度條或「● LIVE」標記的格子（R19），在那一列的最左邊多一個播放／暫停按鈕。
  - 播放中或緩衝中顯示「❚❚」，按下後暫停這一格；暫停或播完時顯示「▶」，按下後播放這一格（播完的影片從頭播放）。
  - 只影響這一格：不影響其他格的播放，也不影響聲音（不觸發 R7 的獨占聲音）。
  - 網頁來源依 R15 的播放意圖運作（按下等同這一格的播放／暫停）。
  - 按鈕在格子寬度小於 360px 時也顯示。
  - 圖示依實際播放狀態顯示（不是依最後一次按的按鈕），狀態改變後 1 秒內更新；例如在整頁模式按網站自己的暫停，按鈕也會變成「▶」。
- 驗收條件：
  - AC1：四格都在播放，按第 2 格的「❚❚」→ 只有第 2 格暫停，按鈕變成「▶」；其他格繼續播放，聲音狀態不變。
  - AC2：再按「▶」→ 第 2 格繼續播放，按鈕變成「❚❚」。
  - AC3：可回放的直播、不能回放的直播（只顯示「● LIVE」）、網頁來源的主要影片都有這個按鈕，而且都能暫停和播放。
  - AC4：mp4 播完後按「▶」→ 從頭播放。
  - AC5：錯誤狀態、網頁來源還沒找到主要影片時，沒有這個按鈕。
  - AC6：把格子縮到最小寬度 → 按鈕仍然顯示並可以按。
  - AC7：網頁來源在整頁模式按網站自己的暫停 → 1 秒內按鈕變成「▶」。

### R27：整頁模式的右鍵選單
- 描述：
  - 網頁來源在整頁模式時，在網頁上（包括網頁中的子框架）按右鍵，在游標位置出現右鍵選單；按 Esc 或點選單外面就關閉。影片模式（包括「直接操作」）不出現。
  - 「上一頁」「下一頁」「重新整理」作用在整個網頁，不是只有子框架。
  - 選單項目依序為：剪下、複製、貼上、全選｜上一頁、下一頁、重新整理｜複製連結網址（只有在連結上按右鍵時才有）。
  - 不能用的項目顯示為灰色：沒有選取文字時的剪下和複製、不在輸入框時的剪下和貼上、沒有上一頁或下一頁時。
  - 「重新整理」重新載入目前的網頁（不是當初貼上的網址），維持整頁模式。
  - 剪下、複製、複製連結網址使用系統剪貼簿，可以貼到其他程式；貼上可以貼入其他程式複製的文字。
- 驗收條件：
  - AC1：整頁模式選取網頁上的一段文字，按右鍵 → 「複製」可以按；按下後到記事本貼上，得到那段文字。
  - AC2：在網頁的輸入框按右鍵 → 「貼上」可以按；按下後貼入剪貼簿的文字。「剪下」「全選」也照常作用。
  - AC3：沒有選取文字時，在網頁空白處按右鍵 → 「剪下」「複製」「貼上」是灰色的。
  - AC4：在連結上按右鍵 → 有「複製連結網址」；按下後剪貼簿是那個連結的完整網址。
  - AC5：按「重新整理」→ 重新載入目前的網頁，維持整頁模式。
  - AC6：影片模式的格子按右鍵 → 不出現選單。

### R28：整頁模式的上一頁／下一頁
- 描述：
  - 網頁來源在整頁模式時，格子的操作按鈕多「←」（上一頁）和「→」（下一頁）；影片模式不顯示。沒有上一頁／下一頁時按鈕是灰色的。
  - 右鍵選單（R27）的「上一頁」「下一頁」作用相同。
  - 滑鼠的「上一頁／下一頁」側鍵：游標在整頁模式的網頁格子上時，作用在那一格；在其他地方不作用。
  - 換頁不影響設定檔保存的網址（仍然是當初貼上的網址，同第二版 R14 AC3），也不改變模式（維持整頁模式）。
  - 換頁時依第二版 R16 處理載入失敗。
  - 瀏覽紀錄從當初貼上的網址開始：程式內部先載入的空白頁（第二版 R17）不算一頁。重試、切換廣告阻擋、更換網址之後，紀錄重新開始。
- 驗收條件：
  - AC1：`novideo.html` 整頁模式，剛載入時「←」「→」都是灰色。
  - AC2：點連結換到另一頁 → 「←」可以按；按下後回到 `novideo.html`，「→」變成可以按；再按「→」回到另一頁。
  - AC3：在整頁模式的格子上按滑鼠的上一頁側鍵 → 回到上一頁；游標在影片模式的格子上按 → 沒有變化。
  - AC4：換頁後關閉程式再開啟 → 那一格載入的是當初貼上的網址。
  - AC5：在 AC2 的狀態下切換廣告阻擋 → 網頁重新載入當初貼上的網址，「←」「→」都是灰色。

## 7. 非功能需求

- **安全：** 右鍵選單由程式提供，網頁不能自己加項目；「複製連結網址」只寫入剪貼簿，不會開啟連結。
- **測試：** 右鍵選單項目的組成與灰色判斷、播放按鈕的圖示判斷寫成單元測試；剪貼簿、滑鼠側鍵、實際換頁以手動驗收。
