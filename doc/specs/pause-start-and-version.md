# 切到網頁時立即維持暫停、設定顯示版本號 規格

- 功能代號：`pause-start-and-version`
- Jira：無
- 狀態：已確認、已複查、已實作
- 最後更新：2026-10-14
- 前置規格：[youtube-web-and-seek](youtube-web-and-seek.md)（R48–R52）、[youtube-page-mode](youtube-page-mode.md)（R66–R68）、[youtube-menu-tweaks](youtube-menu-tweaks.md)（R69–R72）、[youtube-adblock-fix](youtube-adblock-fix.md)（R73–R74）。本規格的需求編號從 R75 開始。

## 1. 背景與目標

2026-10-14 使用者回報：

1. 暫停中的 YouTube 切到網頁模式（或在網頁模式切換廣告阻擋）時，網頁會先播放約 1 秒才暫停。原因：程式約每秒才確認一次網頁的播放狀態，YouTube 自動開始播放後最多 1 秒才被發現並暫停（第十四版 R66 AC4、第十五版 R70）。
2. 希望在工具列的設定選單看到目前的版本號。
3. 某些廣告很多的一般網站，切換「顯示整個網頁」「只顯示影片」後，滑鼠移到那一格不出現下方的操作區，無法移除。待使用者提供網址重現後另外補充需求（未決事項）。

另外，使用者回報開啟 YouTube 網頁的廣告阻擋後廣告反而變多，決定維持預設開啟、先觀察（2026-10-14）。

## 4. 需求清單

### R75：切到網頁時立即維持暫停
- 描述：
  - 需要「網頁剛載入、網站自己開始播放時暫停一次」的情況（暫停中切到 YouTube 網頁模式、網頁模式中切換廣告阻擋），網頁在偵測到影片開始播放的當下就暫停，不等程式下一次確認狀態。
  - 只處理網頁剛載入後第一次開始播放；之後使用者在網頁裡按播放照常播放（第二版 R15）。
  - 「第一次開始播放」包括 YouTube 的片頭廣告（廣告和影片用同一個播放元件）：暫停的是當下在播的內容，按播放後從那裡繼續。
  - 網頁裡有多個影片時，只處理程式判斷為主要影片的那一個（第二版 R13 的主要影片）。
- 驗收條件：
  - AC1：播放器暫停在 3:00 時切到網頁模式 → 網頁停在 3:00 附近，播放的時間不超過 0.3 秒（網頁網址的開始時間只能是整數秒，所以網頁從 3:00 的整數秒開始）。
  - AC2：AC1 的狀態下在網頁裡按播放 → 照常播放。
  - AC3：網頁模式暫停中切換廣告阻擋 → 重新載入後同 AC1。

### R76：設定選單顯示版本號
- 描述：工具列「⚙ 設定」選單的最下方多一行灰色、不能點的「MultiView 版本 x.y.z」，版本號和程式檔案的版本相同。
- 驗收條件：
  - AC1：打開「⚙ 設定」→ 最下方顯示「MultiView 版本 0.5.5」（以安裝後的版本為準），點了沒有反應。

### R77：版本號
- 描述：程式版本號從 0.5.4 更新為 0.5.5，並打包。
- 驗收條件：
  - AC1：`npm run dist` → 產生 `release/MultiView-Setup-0.5.5.exe`；安裝後程式的版本是 0.5.5。
