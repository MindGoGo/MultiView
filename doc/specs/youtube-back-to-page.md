## 1. 背景與目標

第十二版 R57：在格子裡的 YouTube 網站點了影片，這一格會換成那部影片的嵌入播放。但原本的 YouTube 頁面（例如搜尋結果）就不見了，看完影片沒辦法回去繼續找（2026-10-10 使用者回報）。

另外，沒有空格時從清單點一下放入（例如「開啟 YouTube」），只會提示「沒有空格，請拖到要更換的格子」，只有一格在顯示時還得先手動移除影片（2026-10-10 使用者回報）。

目標：從 YouTube 網站開啟的影片可以回到原本的頁面，停在原本的搜尋結果和捲動位置；沒有空格時可以直接選擇要取代的格子（只有一格時直接取代）。

## 2. 範圍

**包含：**
- 回到 YouTube 頁面（R63）
- 沒有空格時選擇要取代的格子（R64）
- 版本號更新並打包（R65）

**不包含：**
- 一般網頁來源、貼上網址開啟的影片：沒有「回到」（不是從 YouTube 網站開啟的）
- 多層的上一頁（只回到開啟影片的那一個 YouTube 頁面）
- 重開程式後還原捲動位置（只能重新載入那個頁面）

## 3. 共用定義

- **來源頁面：** 在格子裡的 YouTube 網站點影片時，這一格正在顯示的 YouTube 頁面（例如搜尋結果、頻道頁）。
- **目前操作的格子：** 單格全螢幕時是放大的那一格；否則是滑鼠所在的那一格（第九版 R51 共用定義）。
- **單格顯示：** 只有一格在顯示的情況：版型「1」，或單格全螢幕（第三版 R20）。

## 4. 需求清單

### R63：回到 YouTube 頁面
- 描述：
  - 在 YouTube 網站點了影片（第十二版 R57）時，這一格換成影片播放，來源頁面保留在背景：網頁不換頁（停在原本的頁面）、靜音、不顯示，維持那一格的大小。
  - 從 YouTube 網站開啟的影片，可以用以下方式回到來源頁面：
    - 操作區的「← 回到 YouTube」按鈕（格子寬度小於 360px 時只顯示「←」）。
    - 滑鼠在這一格上時，按滑鼠的「上一頁」側鍵（直接操作 YouTube 時游標在播放器裡，也要能作用）。
    - 這一格是目前操作的格子時，按鍵盤 Backspace（文字輸入框有焦點時不作用；「顯示整個網頁」的網頁有焦點時交給網頁）。
  - 回到來源頁面時：影片關閉，來源頁面恢復顯示和聲音，停在原本的頁面和捲動位置；音量、靜音、亮度和影片播放時相同（在影片播放時調整過的會沿用）。
  - 回到來源頁面後，再點其他影片，規則相同（可以再回來）。
  - 在影片播放時「更換網址」或從清單放入其他影片 → 不再能回到來源頁面（背景的頁面關閉）。移除這一格時也一起關閉。
  - 拖曳換位時，來源頁面跟著影片一起移動。
  - 重開程式後，從 YouTube 網站開啟的影片仍然有「← 回到 YouTube」：按下後重新載入來源頁面的網址（捲動位置回到最上面）。
  - 背景的來源頁面不計入格子的播放狀態，「全部播放」「全部暫停」不影響它；不記錄歷史、不保存觀看進度。
  - 回到來源頁面時，這一格的歷史和觀看進度依來源頁面的規則（YouTube 網站頁面不記錄歷史，第十二版 R57）。
- 驗收條件：
  - AC1：YouTube 首頁搜尋「TED talk」，捲動到第 10 部影片並點它 → 這一格播放那部影片，操作區有「← 回到 YouTube」；背景的頁面沒有聲音。
  - AC2：按「← 回到 YouTube」→ 回到搜尋結果，停在原本的捲動位置；影片關閉。
  - AC3：AC1 的狀態下，滑鼠在這一格上按滑鼠的「上一頁」側鍵 → 同 AC2。
  - AC4：AC1 的狀態下，滑鼠在這一格上按 Backspace → 同 AC2；網址輸入框有焦點時按 Backspace → 只刪除文字。
  - AC5：AC1 的狀態下把音量調到 30，回到來源頁面 → 來源頁面的音量是 30。
  - AC6：AC1 的狀態下「更換網址」成其他影片 → 沒有「← 回到 YouTube」。
  - AC7：AC1 的狀態下關閉再開啟程式 → 仍然有「← 回到 YouTube」，按下後載入搜尋結果頁。
  - AC8：貼上網址開啟的影片 → 沒有「← 回到 YouTube」；按 Backspace 或滑鼠上一頁鍵沒有作用。
  - AC9：AC1 的格子和另一格換位後按「← 回到 YouTube」→ 在新的位置回到搜尋結果。

### R64：沒有空格時選擇要取代的格子
- 描述：
  - 在清單面板「點一下」放入（最愛、歷史、訂閱的影片與頻道、「開啟 YouTube」，第三版 R21、第十二版 R57、R59）時：
    - 有顯示中的空格 → 和現在相同，放進第一個空格。
    - 單格顯示（版型「1」或單格全螢幕）、那一格有影片 → 直接取代那一格，不用選擇。單格全螢幕時維持單格全螢幕。
    - 其他沒有空格的情況 → 跳出「選擇要取代的格子」：每一個顯示中的格子蓋上一層半透明的選擇框，顯示格子編號（1～9，和數字鍵快捷鍵相同）和目前影片的名稱；點某一格就取代那一格；按「取消」、按 Esc 或點格子以外的地方就不做任何事。
  - 取代和在那一格「更換網址」相同（第一版 R2 AC8：音量、靜音、亮度保留）。
  - 選擇框出現時，清單面板維持開著，但選擇框蓋在清單面板上面，所有格子都可以點（視窗寬度不到 640px、面板佔滿整個寬度時也可以選）；選完或取消後回到清單面板。
  - 選擇框出現時，整頁模式的網頁、直接操作中的格子也一樣可以點選（選擇框蓋在網頁上面）。
  - 拖曳放入的行為不變（第三版 R21）。
  - 被取代的影片如果是從 YouTube 網站開啟的，背景的來源頁面一起關閉（R63）。
- 驗收條件：
  - AC1：版型「1」，格子正在播放影片，按「開啟 YouTube」→ 那一格換成 YouTube 首頁；音量、亮度維持原本的設定；沒有提示或選擇框。
  - AC2：`2×2` 單格全螢幕放大第 3 格，點一下最愛的一筆 → 第 3 格換成那一筆，仍是單格全螢幕；其他格不變。
  - AC3：`2×2` 四格都有影片，按「開啟 YouTube」→ 出現選擇框，四格各顯示編號和影片名稱；點第 2 格 → 第 2 格換成 YouTube 首頁，其他格不變。
  - AC4：AC3 的選擇框出現時按 Esc（或「取消」）→ 選擇框消失，格子都不變。
  - AC5：`2×2` 四格都有影片，點一下歷史的一筆 → 同 AC3 出現選擇框。
  - AC6：還有空格時點一下 → 和現在一樣放進第一個空格，不出現選擇框。
  - AC7：視窗縮到 600px 寬（清單面板佔滿整個寬度）、四格都有影片時點一下 → 選擇框蓋在面板上面，可以點選任何一格。

## 8. 非功能需求

- **效能：** 背景的來源頁面退回點影片前的頁面，不在背景播放影片；每一格最多保留一個來源頁面。
- **實作結果：**
  - 最初讓 YouTube 網頁換到影片頁後再退回上一頁，但 YouTube 退回時會留下迷你播放器、捲動位置歸零。改成在網頁裡（最上層框架、YouTube 自己的處理之前）攔下影片連結的點擊：網頁不換頁，交給程式播放；原本在換頁時才處理的方式保留作為備援。
  - 背景的頁面最初使用「隱藏的網頁」的樣式（整個畫面大小），YouTube 因此重新排版、捲動位置跑掉；改成維持原本那一格的大小、只是看不見。實測點影片前、背景時、回去後捲動位置都是 4180。
  - 背景的頁面和其他播放器放在同一層、依 id 排序，回到前景時 id 不變，網頁不會重新載入。
  - 滑鼠「上一頁」側鍵：在程式畫面上聽 `mouseup`（button 3）；另外加上視窗的 `app-command`（`browser-backward`）作為「直接操作」時的備援，但第四版 R28 已記錄 Chromium 不會把側鍵轉成 app-command，所以直接操作時可能收不到，需要真實滑鼠確認。
- **技術風險：**
  - YouTube 網站退回上一頁時能不能維持捲動位置，取決於 YouTube 自己；實作時驗證，做不到時記錄在未決事項。
  - 滑鼠側鍵在嵌入播放的 YouTube 格子上能不能收到，實作時驗證；收不到時改由主程序的視窗事件處理。
- **測試：** 設定檔相容、Backspace 的快捷鍵對應寫成單元測試；回到來源頁面以手動驗收（滑鼠側鍵需要真實滑鼠）。
