# 中央播放鈕、YouTube 字幕、畫質選單 規格

- 功能代號：`captions-and-quality-menu`
- Jira：無
- 狀態：已確認、已複查
- 最後更新：2026-10-09
- 前置規格：[multiview-player](multiview-player.md)（R1–R11）、[web-page-source](web-page-source.md)（R12–R18）、[player-controls-and-lists](player-controls-and-lists.md)（R19–R25）、[cell-play-and-page-menu](cell-play-and-page-menu.md)（R26–R29）。本規格的需求編號從 R30 接續。

## 1. 背景與目標

進度條旁的播放鈕（R26）太小，不好按；YouTube 影片常有字幕，但目前無法開啟；畫質只有「自動／高」兩種，無法選擇特定畫質。這次在畫面中央加上半透明的播放／暫停鈕、為 YouTube 格子加上字幕選單，並把畫質改成可以選擇影片實際提供的畫質。

## 2. 範圍

**包含：**
- 影片模式下，滑鼠停在格子上時，畫面中央的半透明播放／暫停鈕（R30）
- YouTube 格子的字幕選單：關閉或選擇影片提供的字幕語言（R31）
- 畫質選單：自動，或影片實際提供的畫質，取代 R24 的「自動／高」（R32）
- 版本號更新為 0.3.0 並打包（R33）

**不包含：**
- m3u8、mp4、網頁來源的字幕
- 字幕樣式（字型、大小、顏色）、自動翻譯成其他語言
- 整頁模式的中央播放鈕（會擋住網頁）
- mp4、網頁來源的畫質選擇（同 R24）

## 3. 共用定義

- **畫質名稱：** 以畫面高度表示，例如 360p、720p、1080p。YouTube 的畫質代碼對應：tiny＝144p、small＝240p、medium＝360p、large＝480p、hd720＝720p、hd1080＝1080p、hd1440＝1440p、hd2160＝2160p、highres＝4320p。
- **可用畫質：** 影片實際提供的畫質。YouTube 由播放器回報（不含 YouTube 的「auto」）；m3u8 由串流的畫質清單取得（同一高度只列一次）。
- **格子選單：** R31、R32 的選單。出現在按鈕上方，限制在視窗範圍內；項目太多放不下時可以捲動。同一時間只開一個選單；按 Esc、點選單外面或選了項目後就關閉。

## 4. 需求清單

### R30：中央的半透明播放／暫停鈕
- 描述：
  - 影片模式的格子在滑鼠停在格子上時，畫面正中央顯示一個半透明的圓形按鈕；顯示和隱藏的時機與操作按鈕相同（第一版 R3：滑鼠靜止 2 秒或移出格子後隱藏）。
  - 播放中或緩衝中顯示「❚❚」，暫停或播完時顯示「▶」，判斷方式和 R26 相同。按下只影響這一格，不影響聲音。
  - 按鈕直徑 64px。格子寬度小於 360px 時不顯示中央鈕：這時操作區（進度條和兩列按鈕）幾乎佔滿格子，中央鈕和操作按鈕會互相擋住（第二版 R14 AC7 要求操作按鈕都按得到），改用進度條左邊的播放鈕（R26）。
  - 只有按鈕本身的範圍會播放／暫停；點擊按鈕以外的影片區域，仍然依 R7 獨占聲音。
  - 和 R26 的按鈕相同：錯誤狀態、網頁來源還沒找到主要影片、還不知道進度時不顯示。整頁模式、「直接操作」（點擊要傳給 YouTube 播放器）、顯示網址輸入框時也不顯示。
- 驗收條件：
  - AC1：播放中的格子，滑鼠移到格子上 → 中央出現半透明的「❚❚」；滑鼠靜止 2 秒 → 消失。
  - AC2：按中央的「❚❚」→ 只有這一格暫停，按鈕變成「▶」；聲音狀態不變。再按 → 繼續播放。
  - AC3：點擊中央按鈕以外的影片區域 → 依 R7 獨占聲音，播放狀態不變。
  - AC4：整頁模式的格子 → 沒有中央按鈕。
  - AC5：`3×3` 且視窗縮到最小（格子寬度小於 360px）→ 沒有中央鈕；進度條左邊的播放鈕可以按。
  - AC6：按「直接操作」後 → 中央按鈕不顯示。

### R31：YouTube 字幕選單
- 描述：
  - YouTube 格子的操作按鈕多一個「CC」按鈕。按下後在按鈕附近出現選單，列出「關閉」和這部影片提供的字幕語言（語言名稱由 YouTube 提供，以繁體中文顯示；YouTube 自動產生的字幕在名稱後加「（自動產生）」）；目前的選擇前面打勾。點選單外面或再按一次「CC」就關閉選單。
  - 影片沒有字幕時，選單只有「關閉」和灰色的「這部影片沒有字幕」。
  - YouTube 在影片開始播放前不提供字幕清單：還沒播放過的影片（例如開啟程式時還原、維持暫停的影片），選單只有「關閉」和灰色的「播放後才能選擇字幕」；保存的字幕語言在開始播放後自動套用。
  - 選擇語言後 3 秒內在影片上顯示該語言的字幕；選「關閉」則隱藏字幕，包括上傳者設定為預設開啟的字幕。切換時不重新載入影片。
  - 開啟字幕時「CC」按鈕顯示為啟用狀態（和其他已開啟的按鈕相同的強調樣式）。
  - 每格記住自己的字幕語言，保存在設定檔，換位時跟著來源移動。重新開啟程式或更換成另一部影片時，如果新影片有同一種語言就自動開啟，沒有就關閉。舊的設定檔沒有這個欄位時視為關閉。
- 驗收條件：
  - AC1：有字幕的 YouTube 影片，按「CC」→ 選單列出「關閉」和影片提供的語言。
  - AC2：選擇其中一種語言 → 3 秒內影片上出現字幕，「CC」變成啟用狀態，影片沒有從頭播放。
  - AC3：再選「關閉」→ 字幕消失。
  - AC4：開啟字幕後關閉程式再開啟 → 字幕仍然開啟；和另一格換位 → 字幕設定跟著影片移動。
  - AC5：沒有字幕的影片 → 選單顯示灰色的「這部影片沒有字幕」。
  - AC6：mp4、m3u8、網頁來源的格子沒有「CC」按鈕。
  - AC7：開啟程式時還原、還沒播放的 YouTube 格子按「CC」→ 選單顯示灰色的「播放後才能選擇字幕」；開始播放後再按 → 列出字幕語言。

### R32：畫質選單
- 描述：
  - 取代 R24 的「畫質：自動／高」切換按鈕。YouTube 和 m3u8 格子的畫質按鈕顯示目前的選擇（例如「畫質：自動」「畫質：720p」），按下後出現選單：「自動」和可用畫質（由高到低），目前的選擇前面打勾。
  - 還不知道可用畫質時（影片還在載入），選單只有「自動」和目前的選擇。
  - **自動：** 同 R24 的自動。
  - **選擇特定畫質：**
    - m3u8：固定使用該畫質，不隨網路速度改變。
    - YouTube：播放器以該畫質的大小（例如 720p 為 1280×720）排版再縮放到格子，讓 YouTube 選擇該畫質；選擇比格子小的畫質時，畫面會放大顯示而比較模糊。YouTube 仍然可能依網路速度降低畫質，程式無法強制。
  - 切換時不重新載入影片。
  - 每格記住自己的選擇，保存在設定檔，換位時跟著來源移動。舊設定檔的「高」視為 1080p，沒有這個欄位時視為自動。
  - 保存的畫質在影片中沒有時：m3u8 改用低於它的最高可用畫質（都比它高就用最低的）；YouTube 照樣以該大小排版，由 YouTube 選擇。
- 驗收條件：
  - AC1：m3u8（有 288p、480p、720p、1080p 等多種畫質）按畫質按鈕 → 選單列出「自動」和這些畫質；選 720p → 15 秒內影片解析度變成 1280×720；按鈕顯示「畫質：720p」。
  - AC2：YouTube 影片（有 1080p）在 `3×3` 選 720p → 30 秒內播放器回報的畫質是 hd720；選 360p（`1` 版型的大格子）→ 30 秒內回報 medium。
  - AC3：選回「自動」→ 回到 R24 的自動行為。
  - AC4：設定後關閉程式再開啟 → 選擇保留；和另一格換位 → 設定跟著影片移動。
  - AC5：舊設定檔中的「高」→ 讀取後是 1080p；沒有欄位 → 自動。
  - AC6：mp4、網頁來源的格子沒有畫質按鈕。

## 7. 資料表變更

無。設定檔的來源多一個字幕欄位，畫質欄位可以是數字（舊檔相容，R31 AC4、R32 AC5）。

## 8. 非功能需求

- **技術風險（實作時處理，不影響需求）：**
  - YouTube IFrame API 的字幕控制（`loadModule('captions')`、`setOption('captions', 'track', …)`、`getOption('captions', 'tracklist')`）沒有正式文件；做不到時要停下來回報。
  - YouTube 的「選擇特定畫質」只能靠播放器大小，和 R24 相同。
- **測試：** 畫質名稱對應、可用畫質整理、m3u8 的畫質選擇、設定檔相容寫成單元測試；字幕與實際畫質以手動驗收。
