## 1. 背景與目標

看 YouTube 影片時想看留言、點其他推薦影片，現在的 YouTube 格子只有播放器，看不到 YouTube 網頁上的內容（2026-10-10 使用者需求）。

另外，從格子按「全螢幕」（單格全螢幕）時，格子顯示「離開全螢幕」，工具列卻仍是「全螢幕」，文字和實際狀態不一致（2026-10-10 使用者回報）。

從清單、訂閱或貼上網址開啟的 YouTube 影片沒有「回到 YouTube」（第十三版 R63 只有從 YouTube 網站開啟的影片才有），而「看影片的網頁」和「回到 YouTube」兩個功能放在一起會重複（2026-10-10 使用者回饋）。

目標：所有 YouTube 格子都可以切換到這部影片的 YouTube 網頁（整頁模式），看完再切回播放器，播放位置接續；和「回到 YouTube」合成一個「YouTube ▾」選單。

## 2. 範圍

**包含：**
- YouTube 影片切換到網頁模式、切回播放器，和「回到 YouTube」合成一個選單（R66）
- 工具列「全螢幕」按鈕的文字和實際狀態一致（R67）
- 版本號更新並打包（R68）

**不包含：**
- 留言、按讚、訂閱（不能登入，第十二版背景）
- 禁止嵌入、已經用 YouTube 網頁播放的格子（第九版 R48）：它們本來就有「顯示整個網頁」
- 重開程式後維持網頁模式（重開後一律是播放器）

## 3. 共用定義

- **YouTube 網頁模式：** YouTube 格子改用網頁來源的整頁模式，顯示目前影片的 YouTube 網頁（`watch?v=` 頁面，可以捲動看留言、推薦影片）。
- **網頁上目前的影片：** YouTube 網頁模式下，網頁正在顯示的那部影片（在網頁裡點了推薦影片後會改變）。

## 4. 需求清單

### R66：YouTube 影片切換到網頁模式，和「回到 YouTube」合成一個選單
- 描述：
  - YouTube 格子（嵌入播放與 YouTube 網頁模式）的操作區有一個「YouTube ▾」按鈕（格子寬度小於 360px 時只顯示「YT」），按下出現選單（和格子的畫質、字幕選單相同的樣式與關閉方式）：
    - 播放器時：「看這部影片的網頁（留言、推薦）」→ 切換到 YouTube 網頁模式。
    - 網頁模式時：「回到播放器」→ 換回嵌入播放。
    - 從 YouTube 網站開啟的影片（第十三版 R63）再多一項「回到剛才的 YouTube 頁面」→ 和 R63 相同（回到點影片前的頁面，停在原本的捲動位置）。
  - 第十三版 R63 原本獨立的「← 回到 YouTube」按鈕併入這個選單；Backspace、滑鼠「上一頁」側鍵維持回到剛才的 YouTube 頁面（R63）。
  - 切換到 YouTube 網頁模式時：
    - 從播放器目前的時間接著播；播放器原本暫停時，網頁也停在那個位置不播放（整頁模式不會阻止網站自己播放，第二版 R15，所以只在網頁剛載入、YouTube 自動開始播放時暫停一次；之後使用者在網頁裡按播放照常播放）。
    - 音量、靜音、亮度和播放器相同；廣告阻擋關閉（和第九版 R48 相同），可以用「廣告阻擋」按鈕開啟。
    - 網頁模式時沒有「只顯示影片」按鈕（由選單的「回到播放器」取代）。
    - 在網頁裡點推薦影片，像一般瀏覽器一樣在網頁裡換成那部影片（不換回播放器）。
  - 回到播放器時：
    - 播放「網頁上目前的影片」，從網頁上的時間接著播；網頁原本暫停時，播放器也停在那個位置。
    - 畫質、字幕的選擇維持切換前的設定。
    - 網頁上目前的影片禁止嵌入時，依第九版 R48、R49 的規則（顯示「改用 YouTube 網頁播放」，或自動改用網頁播放）；播放失敗不記錄歷史（第三版 R23 AC4）。
  - 其他：
    - 切換本身不記錄歷史（還是同一部影片）；在網頁裡換成其他影片後回到播放器，那部影片記錄到歷史。
    - 網頁模式時，格子上的 ☆ 和最愛、歷史的判斷用切換前的那部影片；回到播放器後才換成網頁上目前的影片。
    - 只有嵌入播放的 YouTube 格子有「YouTube ▾」；禁止嵌入改用網頁播放的格子（第九版 R48）、在格子裡逛 YouTube 網站的格子（第十二版 R57）沒有（它們本來就是網頁）。
    - 從 YouTube 網站開啟的影片，背景的來源頁面在網頁模式時仍然保留，「回到剛才的 YouTube 頁面」在兩種模式下都可以用。
    - 換位時網頁模式跟著移動；「更換網址」、移除時結束網頁模式。
    - 重開程式時，網頁模式的格子以播放器開啟：播放「網頁上目前的影片」，停在網頁上的時間（第十版 R55 觀看進度）。
    - 在網頁模式時，快轉倒轉、進度條、播放／暫停依網頁來源的規則（第九版 R51、第四版 R26）。
- 驗收條件：
  - AC1：YouTube 格子播放到 2:00，按「YouTube ▾」→「看這部影片的網頁（留言、推薦）」→ 這一格顯示這部影片的 YouTube 網頁，從 2:00 附近接著播，可以往下捲動看到留言區；廣告阻擋關閉。
  - AC2：AC1 的狀態下按「YouTube ▾」→「回到播放器」→ 換回嵌入播放，從網頁上的時間附近接著播；畫質、字幕維持原本的選擇。
  - AC3：AC1 的狀態下在網頁裡點一部推薦影片 → 網頁換成那部影片；「回到播放器」→ 播放器播放那部影片；歷史多一筆。
  - AC4：播放器暫停在 3:00 時切到網頁 → 網頁停在 3:00 附近，不自動播放。
  - AC5：從清單或貼上網址開啟的 YouTube 影片 → 選單只有「看這部影片的網頁（留言、推薦）」；從 YouTube 網站開啟的影片 → 選單另有「回到剛才的 YouTube 頁面」，在網頁模式時也有，按下回到原本的搜尋結果與捲動位置。
  - AC6：網頁模式下關閉再開啟程式 → 這一格是播放器，停在關閉時網頁上的影片和時間附近。
  - AC7：網頁模式時歷史沒有新增；音量、亮度和播放器時相同。
  - AC8：操作區沒有獨立的「← 回到 YouTube」按鈕；Backspace、滑鼠上一頁鍵仍然回到剛才的 YouTube 頁面（R63 AC3、AC4）。

### R67：工具列「全螢幕」按鈕的文字和實際狀態一致
- 描述：
  - 工具列的全螢幕按鈕在以下情況顯示「離開全螢幕」，其他時候顯示「全螢幕」：
    - 視窗是全螢幕。
    - 正在單格全螢幕（第三版 R20：單格全螢幕一定會讓視窗進入全螢幕）。
  - 單格全螢幕時按工具列的「離開全螢幕」→ 離開單格全螢幕，視窗回到進入前的狀態（和 F11 相同，第三版 R20）。
  - 每次切換全螢幕（工具列、格子、F11、Esc）後，畫面重新向主程序確認視窗狀態，即使錯過狀態通知，文字也會在 1 秒內更正。
- 驗收條件：
  - AC1：一般視窗按格子的「全螢幕」→ 格子顯示「離開全螢幕」，工具列也顯示「離開全螢幕」。
  - AC2：AC1 的狀態下按工具列的「離開全螢幕」→ 離開單格全螢幕、視窗回到一般大小；格子和工具列都顯示「全螢幕」。
  - AC3：工具列按「全螢幕」→ 工具列顯示「離開全螢幕」；再按格子的「全螢幕」→ 格子顯示「離開全螢幕」；按格子的「離開全螢幕」→ 回到分割畫面，視窗維持全螢幕，工具列仍顯示「離開全螢幕」。
  - AC4：用 F11、Esc 切換 → 工具列的文字都和視窗狀態一致。

## 8. 非功能需求

- **實作結果：**
  - 網頁模式是新的網頁來源，網址是 `watch?v=<代碼>&t=<秒>s`，格子的網址（☆、歷史判斷）仍是切換前的影片；背景的來源頁面（R63）一起帶過去。
  - 回到播放器時用網頁目前的網址（`getURL`）判斷網頁上目前的影片、用網頁回報的進度接續時間。
  - 暫停時切到網頁：網頁剛載入、YouTube 自動開始播放時程式送出一次暫停；實測網頁停在 3:01、5 秒後仍然暫停。
  - 保存：網頁模式的格子保存網頁上目前的影片與時間，重開時以播放器開啟。
- **技術風險：** YouTube 網頁從指定時間開始（`&t=` 參數）、網頁暫停狀態的取得、網頁剛載入時暫停一次，實作時驗證。
- **R67 的驗收：** 需要實際切換視窗全螢幕，會短暫蓋住使用者的螢幕；先徵求使用者同意再測。
- **測試：** 網址與時間的轉換寫成單元測試；切換以手動驗收。
