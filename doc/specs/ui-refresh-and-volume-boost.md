# 設定視窗、工具列改版、音量放大、讀取動畫 規格

- 功能代號：`ui-refresh-and-volume-boost`
- Jira：無
- 狀態：已確認、已複查
- 最後更新：2026-11-06
- 前置規格：[ytdlp-playback](ytdlp-playback.md)（R88–R95）。本規格的需求編號從 R96 開始（R34–R39 保留給本機播放與下載）。

## 1. 背景與目標

2026-11-06 使用者試用 0.7.0 後回報：

1. 設定變多了，希望設定畫面更精美，參考 Claude 桌面版的設定（置中的視窗、左側分類、右側標題＋說明＋開關）。
2. 工具列左邊的版型、全部播放等按鈕不夠好用、好看。
3. 用 yt-dlp 播放時聲音比較小，希望音量可以超過 100%。
4. 播放 `fg1H4WCdkNI` 到 4:07 時沒聲音、畫面停住，過一下跳到 4:16 繼續（使用者當時有切換過內嵌與 yt-dlp）。
5. 讀取影片時希望有讀取動畫，加入一隻活潑的小生物。

第 4 項的調查（2026-11-06）：
- 從 3:55 播到 4:22、切換內嵌與 yt-dlp、畫質跨聲音群組切換（240p ↔ 480p），時間都連續，沒有重現。
- 發現播放器會一次預先緩衝將近 10 分鐘（例如播放到 247 秒時已緩衝到 825 秒）。高畫質時超過瀏覽器給影片緩衝的容量，播放器要清掉部分緩衝，可能留下空洞，播到空洞時停住再跳過去，症狀相符。以限制預先緩衝的長度處理（R100）。

第 3 項的可能原因：內嵌播放器的音量刻度和一般播放器不同，同樣的數值內嵌播放器聽起來較大聲。

使用者選擇（2026-11-06）：置中的設定視窗＋左側分類；工具列改成圖示化的分段按鈕；音量最高 200%；讀取動畫是格子中央一隻活潑的小生物＋文字，短暫的緩衝不顯示。

## 2. 範圍

**包含：**
- 設定視窗（R96）
- 工具列改版（R97）
- 音量最高 200%（R98）
- 讀取動畫（R99）
- 限制預先緩衝的長度（R100）
- 版本號（R101）

**不包含：**
- 格子操作區的按鈕改版（只改工具列）
- YouTube 小視窗、清單面板的外觀
- 內嵌播放器、網頁來源、一般的 mp4 網址的音量超過 100%（技術上無法，見 R98）
- 新的設定項目（設定視窗只重新整理現有的設定）

## 3. 共用定義

- **設定視窗：** R96 的置中視窗，取代 R49 的「⚙ 設定」下拉選單。
- **可放大音量的來源：** 由程式自己的播放器播放、而且可以取得聲音資料的來源：yt-dlp 播放（R89）、m3u8 網址。不包含內嵌播放器、網頁來源、一般的 mp4 網址（伺服器沒有開放跨網站存取時，程式拿不到聲音資料，強行處理會整個沒有聲音）。

## 4. 需求清單

### R96：設定視窗
- 描述：
  - 按工具列的「設定」（R97 的齒輪圖示）→ 開啟置中的設定視窗，背景變暗。影片照常播放。
  - 視窗上方是標題「設定」與右上角的關閉（✕）。左側是分類，右側是目前分類的內容。
  - 分類與內容（現有的設定，不新增項目）：
    - **YouTube 播放：**
      - 「直播的播放方式」：說明「內嵌播放器是 YouTube 官方的播放器；yt-dlp 由程式直接播放，沒有廣告和 YouTube 的按鈕。」右側是兩段的選擇按鈕「內嵌播放器｜yt-dlp」（R88）。
      - 「一般影片的播放方式」：同上（R88）。
      - 「無法嵌入時自動改用網頁播放」：說明「影片不允許在其他網站播放時，直接改用 YouTube 網頁播放。」右側是開關（R49）。
    - **yt-dlp：**
      - 「版本」：顯示目前版本與狀態（已是最新版／有新版／正在檢查／無法檢查／正在更新／找不到 yt-dlp，R93 的狀態），右側是「檢查更新」或「更新到 <新版本>」按鈕（R93：可以點擊的狀態才能按；正在更新時按鈕停用並顯示「正在更新…」）。
      - 說明「程式會在開啟時自動更新（一天一次），YouTube 改版造成無法播放時也會自動更新。」
    - **關於：** 「MultiView 版本」（R76）。
  - 每一個設定是一列：左邊標題、下方較淡的說明，右邊是控制項；列與列之間用細線分隔。
  - 第一次開啟時顯示「YouTube 播放」；之後開啟顯示上次的分類（不保存到設定檔，重開程式回到「YouTube 播放」）。
  - 關閉：按 ✕、按 Esc、點視窗外的暗色背景。
  - 設定視窗開著時：工具列不自動隱藏；所有快捷鍵（第一版 R9、R51、F11 等）都不作用，按鍵只給設定視窗（Esc 關閉、Tab 在控制項之間移動）；格子的操作區不顯示；工具列上開著的總亮度滑桿先關閉。
  - 改了設定立即生效（和 R49、R88 相同），不需要「儲存」。
  - 檢查更新：打開「yt-dlp」分類時查詢最新版（1 小時內查過就不查，R93）；手動更新的結果仍用工具列的提示顯示（R93），同時這一列的狀態跟著更新。
  - 視窗縮小時，設定視窗跟著縮小，內容可以捲動；寬度不夠時左側分類收成較窄的樣式（只有文字，不換行）。
- 驗收條件：
  - AC1：按工具列的設定 → 出現置中的設定視窗，左側有「YouTube 播放」「yt-dlp」「關於」，預設是「YouTube 播放」；影片繼續播放。
  - AC2：把「直播的播放方式」切到 yt-dlp → 立刻生效（R88 AC2）；關閉再打開設定 → 仍是 yt-dlp。
  - AC3：「無法嵌入時自動改用網頁播放」的開關切換 → 立刻生效（R49）。
  - AC4：「yt-dlp」分類在有新版時顯示「更新到 <版本>」，按下後顯示「正在更新…」，完成後狀態變成已是最新版，工具列提示結果。
  - AC5：「關於」顯示「MultiView 版本 0.7.1」。
  - AC6：按 Esc、✕、點暗色背景都會關閉；設定視窗開著時按 Space 不會播放／暫停格子。
  - AC7：切到「yt-dlp」後關閉再打開 → 顯示「yt-dlp」；重開程式 → 顯示「YouTube 播放」。
  - AC8：視窗縮到最小尺寸（第一版 R1）→ 設定視窗完整顯示在視窗內，內容可以捲動，所有控制項按得到。

### R97：工具列改版
- 描述：
  - 功能不變，只改外觀與排列。所有按鈕統一高度、圓角、滑過與按下的效果；有作用中狀態的按鈕（目前的版型、置頂、清單打開、全螢幕）以強調色顯示。
  - 由左到右：
    1. **版型：** 一組分段按鈕，每個用小圖示畫出格子排列（`1`、`2`、`2×2`、`3×3`、`1+3`），目前的版型反白。滑鼠移上去顯示「版型：2×2」等名稱。
    2. **全部播放、全部暫停、全部靜音：** 一組三個圖示按鈕（▶、❚❚、靜音喇叭），滑鼠移上去顯示名稱；不能操作時（第一版的規則）停用。
    3. 中間：拖曳視窗的區域與提示文字（不變）。
    4. **右側功能：** 總亮度（圖示＋百分比，R41）、清單、YouTube 小視窗、置頂、全螢幕、設定，都是圖示按鈕，滑鼠移上去顯示名稱（和原本的文字相同，例如「最愛與歷史清單」「視窗置頂」「全螢幕 (F11)」）。
    5. 最右邊：最小化（─）、關閉（✕），和 Windows 的視窗按鈕相同的樣式（關閉滑過時是紅色），與功能按鈕之間有分隔線。
  - 圖示用程式內建的向量圖（不從網路載入），線條風格一致。
  - 視窗很窄時，中間的提示文字先縮短（省略號），按鈕不換行、不被切掉：寬度 760 像素以下按鈕與間距變小；560 像素以下總亮度只顯示圖示，數值放在滑鼠提示裡（實作時發現：最小寬度 480 像素放不下全部按鈕）。
  - 單格全螢幕或全螢幕時，全螢幕按鈕顯示「離開全螢幕」的圖示（R67）。
- 驗收條件：
  - AC1：工具列左邊是版型的分段按鈕（五個圖示），目前的版型反白；滑鼠移上去顯示名稱；按下切換版型（第一版 R4）。
  - AC2：全部播放／暫停／靜音是三個圖示按鈕，滑鼠移上去顯示名稱，功能和原本相同。
  - AC3：右側的清單、小視窗、置頂、全螢幕、設定是圖示按鈕並有名稱提示；置頂、清單打開、全螢幕時按鈕是強調色。
  - AC4：視窗縮到最小寬度 → 工具列按鈕都看得到、按得到，沒有換行。
  - AC5：總亮度按鈕仍顯示百分比（寬度 560 像素以下只有圖示，滑鼠提示有百分比），按下出現滑桿（R41）。

### R98：音量最高 200%
- 描述：
  - 可放大音量的來源（第 3 節）：音量滑桿（R42）的範圍改成 0–200；超過 100 的那一段在滑桿上用不同顏色顯示。「重設」仍然回到 100。按鈕顯示目前數值（例如「🔉 150」）。
  - 超過 100% 時加上防爆音：聲音太大時自動壓低，避免破音。100% 以下聲音處理和現在完全相同。
  - 其他來源（內嵌播放器、網頁、一般的 mp4 網址）：滑桿範圍仍是 0–100。
  - 音量跟著格子保存（第一版 R7、R10），保存的範圍改成 0–200。
  - 同一格的音量是 150、但改用不能放大的方式播放（例如設定改成內嵌播放器、yt-dlp 失敗退回內嵌、更換成一般的 mp4 網址）：實際用 100%，滑桿顯示 100、最大 100；保存的 150 不變，之後換回可放大的來源時恢復 150。在不能放大的來源上拖動滑桿時，保存的值改成拖動的值。
  - 靜音、獨占聲音（第一版 R7）、全部靜音的規則不變。
- 驗收條件：
  - AC1：yt-dlp 播放的格子按音量按鈕 → 滑桿範圍 0–200；拖到 200 → 聲音明顯變大，按鈕顯示「🔉 200」，大聲的片段沒有破音。
  - AC2：m3u8 網址的格子 → 同 AC1。
  - AC3：內嵌播放器、網頁、一般的 mp4 網址的格子 → 滑桿範圍 0–100。
  - AC4：AC1 的格子把設定改成內嵌播放器 → 滑桿顯示 100、最大 100；再改回 yt-dlp → 恢復 200。
  - AC5：音量 150 時關閉再開啟程式 → 仍是 150。
  - AC6：音量 150 時按靜音 → 沒有聲音；取消靜音 → 回到 150。
  - AC7：用 0.7.0 的設定檔開啟 → 音量照舊（0–100 的值不變）。

### R99：讀取動畫
- 描述：
  - 格子在解析中（R89）、載入中、緩衝中時，中央顯示一隻原創的小生物動畫，下方小字「解析中…」（解析時）或「載入中…」（其他）。取代 R89 的「解析中…」文字框。
  - 小生物的設計（原創，不模仿任何既有角色）：圓滾滾的麻糬形小身體，淺薄荷綠，兩個黑色小圓眼、臉頰淡粉紅，肚子上有一個小小的播放符號（▶）；動畫是原地彈跳：落地時身體壓扁、彈起時拉長，地上的影子跟著縮放，偶爾眨眼。以程式內建的向量圖與動畫製作，不載入外部檔案。
  - 大小隨格子調整：大格子最大 52 像素，小格子（`3×3`）縮小，最小 24 像素；格子太小時不顯示文字。
  - 載入中或緩衝中不到 0.5 秒就恢復時不顯示，避免閃爍；解析中立即顯示。
  - 半透明、不擋操作按鈕，也不攔截點擊（點到動畫的位置和點到影片相同）。
  - 不顯示的情況：錯誤訊息、輸入網址、暫停中、網頁來源（網頁本身會逐步顯示內容，第二版 R12–R18，包括 YouTube 網頁播放與整頁模式）。
  - 不依 Windows 的「減少動畫」改變，一直彈跳（使用者要求，2026-11-06）。
- 驗收條件：
  - AC1：yt-dlp 播放貼上 YouTube 網址 → 中央出現彈跳的小生物與「解析中…」，開始播放後消失。
  - AC2：內嵌播放器、mp4、m3u8 載入時 → 小生物與「載入中…」。
  - AC3：播放中斷線（緩衝超過 0.5 秒）→ 出現小生物；網路恢復、繼續播放後消失。
  - AC4：讀取中仍然可以按格子的操作按鈕（例如移除、更換網址）。
  - AC5：`3×3` → 小生物縮小，不超出格子。
  - AC6：Windows 開啟「減少動畫」→ 小生物仍然彈跳。

### R100：限制預先緩衝的長度
- 描述：
  - 程式自己播放的串流（yt-dlp 播放、m3u8 網址）最多預先緩衝目前位置之後 60 秒；目前位置之前保留 30 秒（往回倒轉 5 秒，R51，不用重新下載），更早的釋放。
  - 原本一般影片會預先緩衝將近 10 分鐘，高畫質時可能超過容量，造成停住後跳過一段（第 1 節第 4 項）；多格播放時也佔用大量記憶體與網路。
  - 直播的行為不變（直播本來就只能緩衝到最新的位置）。
- 驗收條件：
  - AC1：yt-dlp 播放一般影片 1080p 兩分鐘 → 緩衝範圍不超過目前位置之後約 60 秒（加一個片段的長度）。
  - AC2：播放 `fg1H4WCdkNI`（1080p）從 3:50 播到 4:30 → 時間連續，沒有停住後跳過。
  - AC3：往回倒轉 5 秒（R51）→ 立即播放，不需要重新緩衝。
  - AC4：拖曳到還沒緩衝的位置 → 重新緩衝後播放（和現在相同）。
