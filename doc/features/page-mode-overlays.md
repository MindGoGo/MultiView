# 整頁模式時工具列和操作列不再擋住網頁

> 上線版本：0.8.3　｜　更新日期：2026-11-08

## 這個功能做什麼

以前在「顯示整個網頁」時，滑鼠一移到視窗頂端，工具列就跳出來蓋住網站的搜尋欄和按鈕；移到格子上，底部的操作列也會蓋住網頁底部。現在這兩個都收起來了，網頁可以直接點。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

只有格子在「顯示整個網頁」時才這樣，影片模式和原本一樣：

1. **叫出工具列：** 把滑鼠移到視窗最上緣，停一下（約 0.3 秒）。出現後可以往下移到按鈕上。
2. **叫出操作列：** 滑鼠移到格子上，右下角會出現「⋯」，移到「⋯」上就會展開音量、更換網址、「只顯示影片」等按鈕；離開後自動收回。
3. 左上角的播放方式標示，也只在操作列展開時顯示。

## 範例

在格子裡打開購物網站要搜尋：直接把滑鼠移到網站的搜尋欄上點一下輸入，工具列不會跳出來。想切版型時，再把滑鼠推到視窗最上緣停一下。

## 限制與注意事項

- 視窗沒有放大時，要把滑鼠移得比較準才碰得到最上緣。
- 網站的按鈕如果貼在網頁最上面 6 像素內，滑鼠停在那裡夠久仍然會叫出工具列。
- 「⋯」本身會蓋住格子右下角一小塊。
- 工具列在顯示提示文字、清單或設定視窗開著時會維持顯示，和原本一樣。
