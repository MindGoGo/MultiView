# YouTube 可選用 yt-dlp 播放

> 上線版本：0.7.0　｜　更新日期：2026-11-06

## 這個功能做什麼

以前 YouTube 一律用 YouTube 官方的播放器，畫面上會出現 YouTube 的廣告、標誌和片尾推薦。現在可以在設定裡改用「yt-dlp」播放：程式先向 YouTube 取得影片本身，再用程式自己的播放器播放，畫面上只有影片，沒有廣告和 YouTube 的按鈕。直播和一般影片可以分開選擇。

yt-dlp 是程式內附的小工具，負責向 YouTube 取得影片。YouTube 改版時它需要更新，程式會自動幫你更新，也可以在設定裡手動更新。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

1. 按工具列右邊的齒輪（設定），選「YouTube 播放」（0.7.1 起是設定視窗）。
2. 選擇播放方式（目前的選擇會打勾）：
   - 「直播的播放方式」：內嵌播放器或 yt-dlp
   - 「一般影片的播放方式」：內嵌播放器或 yt-dlp
   - 預設都是「內嵌播放器」，也就是原本的方式。
3. 改了之後，畫面上的 YouTube 格子會立刻換成新的方式：一般影片從原本的時間繼續，原本暫停的仍然暫停。
4. 用 yt-dlp 時，剛放進去的影片會先顯示「解析中…」，幾秒後開始播放。
5. **yt-dlp 播不了時**（例如影片需要登入、直播還沒開始），這一格會自動改用原本的內嵌播放器，工具列會提示「yt-dlp 無法播放，已改用內嵌播放器」。這只影響這一次，下次開啟程式還是會先試 yt-dlp。
6. **語音（0.7.0 起）：** 有些影片除了原本的聲音，還有 YouTube 自動產生的其他語言配音。用 yt-dlp 播放時，程式會先選和 Windows 語言相同的聲音（中文介面就是中文），沒有的話用原本的聲音。這種影片的格子會多一個「語音」按鈕，可以換成其他語言；換了之後這一格會記住，之後放進這一格的影片有這種語言就直接用。想恢復預設，選「自動」。
7. **更新 yt-dlp：** 設定視窗的「yt-dlp」分類顯示目前版本與狀態：
   - 「已是最新版」：不用做什麼。
   - 「有新版 …」：按「更新到 …」，完成後工具列會提示結果。
   - 「無法檢查更新」：通常是沒有網路，也可以按「檢查更新」直接試著更新。

## 範例

同時看四場直播，不想看到廣告：在設定視窗把「直播的播放方式」選成 yt-dlp，四格直播會換成 yt-dlp 播放，畫面上只剩影片。其中一場還沒開播時，那一格會自動改用原本的播放器，顯示 YouTube 的倒數畫面。

## 限制與注意事項

- 用 yt-dlp 播放時，直播和一般影片都可以照常選畫質（一般影片最高到 4K）。少數一般影片 YouTube 沒有提供可選畫質的版本，這時固定 360p、畫質按鈕不能用；想看高畫質的話，把「一般影片」改回「內嵌播放器」。
- 用 yt-dlp 播放時沒有字幕，字幕按鈕不能用；也沒有「直接操作」按鈕（因為沒有 YouTube 的按鈕可以按）。
- 剛放進去的影片要等幾秒才會開始播放（大約 3–10 秒）。
- 1440p、4K 比較吃電腦，很多格同時用這種畫質可能會卡；畫質選「自動」時會依格子大小選擇，不會用到這麼高。
- 只有直播選 yt-dlp 時，程式要先查一下影片是不是直播，所以一般影片也會先顯示「解析中…」幾秒，再用原本的播放器播放。
- 需要登入的影片（會員限定、年齡限制）用 yt-dlp 播不了，會自動改用原本的播放器。
- 用 yt-dlp 播放會略過 YouTube 的廣告和嵌入限制，不符合 YouTube 的使用條款，只供個人使用。
- YouTube 改版後，偶爾會有一兩天 yt-dlp 都不能播（要等 yt-dlp 出新版），這段時間會自動改用原本的播放器，等 yt-dlp 有新版後會自動恢復。
- 換語音時影片不會重新開始，但新的聲音要重新緩衝，可能會停頓幾秒。內嵌播放器的格子沒有「語音」按鈕。
- 程式開啟時會在背景檢查 yt-dlp 有沒有新版（一天一次），不會影響開啟速度。

## 常見問題

**Q：改了設定，為什麼某一格還是有 YouTube 的按鈕？**
A：可能是那部影片 yt-dlp 播不了，自動改用原本的播放器了（改的時候工具列會有提示）。也可能你只改了「直播」，而那一格是一般影片。

**Q：設定裡一直顯示「無法檢查更新」？**
A：程式連不到 GitHub（yt-dlp 發布新版的地方），通常是沒有網路。這不影響播放，有網路後再打開設定就會重新檢查。

**Q：需要另外安裝 yt-dlp 或其他程式嗎？**
A：不需要，yt-dlp 已經包含在安裝檔裡。
