# 浮在影片上的操作按鈕

> 上線版本：0.9.1（0.9.2、0.9.4 調整）　｜　更新日期：2026-11-24

## 這個功能做什麼

格子下方原本一整條的操作列拿掉了，改成像 YouTube 一樣，圓形按鈕分散浮在影片的四個角落，影片幾乎不會被擋住。用 yt-dlp 播放的格子在左上角有一個綠色小圓點。另外可以設定開啟程式時自動打開 YouTube 小視窗。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

把滑鼠移到格子上：

1. **左上：** 聲音按鈕（按一下靜音／開聲音；滑鼠移上去旁邊出現音量滑桿，也可以用滾輪或方向鍵調）。滑鼠停在上面會說明這一格是用 yt-dlp、內嵌播放器還是網頁播放。
2. **中間：** 播放／暫停。
3. **右上：** YouTube ▾（回到網頁、推薦、留言、聊天室等）和齒輪。齒輪裡有亮度、畫質、語音、字幕、直接操作、顯示整個網頁、廣告阻擋、最愛、更換網址、移除。
4. **左下：** 目前時間與長度；直播顯示「直播」，往回看時顯示落後多久，按一下回到最新位置。
5. **右下：** 移動（拖到別的格子交換位置；也可以直接在影片上按住拖曳）、全螢幕。
6. **最下面：** 細細的進度條，滑鼠移上去會變粗並顯示預覽畫面，可以點或拖曳跳轉；SponsorBlock 的業配色塊也畫在上面。

快轉、倒轉用鍵盤的 ← →。

在影片上按右鍵也會在游標位置打開齒輪選單；設定 → 滑鼠操作 可以改左鍵、右鍵的效果（開啟選單、只聽這一格、播放／暫停）。

沒有把滑鼠移上去時，有聲音的格子左上角會有一個跳動的小音波。

開啟程式時打開小視窗：設定 → YouTube 小視窗 → 開啟 App 時打開小視窗。只有畫面上只有一格時才會打開。

## 範例

一格在看直播、想看聊天室：滑鼠移上去按右上的 YouTube ▾ → 聊天室。小視窗上方只會顯示影片名稱。

## 限制與注意事項

- 格子很窄時按鈕會變小，也不顯示時間。
- 最上排格子的上方按鈕會比較低一點，避開視窗頂端的工具列。
- 「顯示整個網頁」的格子平常只有右下角的「⋯」，移上去才出現按鈕。
