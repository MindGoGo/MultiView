# 進度條、單格全螢幕、最愛與歷史、畫質

> 上線版本：0.2.0　｜　更新日期：2026-10-09

## 這個功能做什麼

這一版讓 MultiView 更像一般的播放器：可以拖曳進度條跳到想看的地方、直播可以倒回去看剛才錯過的片段；想專心看某一格時，一鍵把它放大到整個螢幕；常看的頻道可以存成「最愛」，看過的影片會自動記在「歷史」，下次直接拖進格子就能播放；覺得 YouTube 畫面模糊時，可以把那一格調成高畫質。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

1. **進度條：** 滑鼠移到格子上，下方會出現進度條。
   - 一般影片：旁邊顯示「目前時間／總長度」。點一下或拖曳後放開，就跳到那個位置；原本在播放的繼續播放，暫停的維持暫停。
   - 可以倒轉的直播：往回拖可以看剛才的內容，旁邊會顯示「離直播還差多久」（例如 -1:23）。按「回到直播」就回到最新的畫面；已經在最新畫面時，按鈕顯示紅色的「● LIVE」。
   - 不能倒轉的直播：只顯示「● LIVE」。
2. **單格全螢幕：** 按格子右下角的「全螢幕」，這一格會放大到整個螢幕，其他格自動暫停。按 Esc、F11 或「離開全螢幕」就回到原本的分割畫面，原本在播放的格子會接著播放。放大時，空白鍵只控制這一格。
3. **加入最愛：** 按格子右下角的「☆」，星星變成「★」就是加入了；再按一次就移除。
4. **打開清單：** 把滑鼠移到視窗最上方，按工具列的「☰ 清單」，右邊會出現清單，有「最愛」和「歷史」兩個分頁。
   - **點一下**某一筆：放進第一個空白格。
   - **按住拖到**某一格：空白格就放入；有影片的格子就換成這一筆（聲音和音量設定不變）。
   - **編輯**：可以改名稱和網址。名稱留白會用網址當名稱。
   - **刪除**：刪掉這一筆。
   - 「最愛」可以按「＋ 新增」手動加入網址；「歷史」可以按「全部清除」（會再問一次）。
5. **歷史紀錄：** 每次放進格子的影片成功播放後，會自動記一筆，名稱是影片標題。同一個網址只留一筆，再看會移到最上面；最多記 200 筆。
6. **畫質：** YouTube 和 m3u8 的格子右下角有「畫質：自動」按鈕。0.3.0 版起改成選單，可以選擇影片提供的畫質（例如 1080p、720p），用法見「中央播放鈕、YouTube 字幕、畫質選單」的說明。

## 範例

想一邊看四台直播，一邊隨時切到某一台看清楚：

1. 打開「☰ 清單」，從「最愛」把四個常看的頻道依序拖進 2×2 的四格。
2. 某一台有重要新聞時，按那一格的「全螢幕」專心看，其他三台自動暫停。
3. 錯過了開頭，把進度條往回拖一分鐘重看；看完按「回到直播」。
4. 按 Esc 回到四格畫面，其他三台接著播放。
5. 覺得某一格的 YouTube 太模糊，把它的畫質選成 1080p，下次開啟程式也會記得。

## 限制與注意事項

- **切成高畫質後，畫面不會馬上變清楚。** YouTube 會先播完已經下載好的片段，一般影片大約要等 40 秒到 2 分鐘才換成高畫質。網路速度不夠時，YouTube 仍然會自動降低畫質。
- **高畫質比較耗網路和電腦資源。** 很多格同時開高畫質時，舊電腦或慢的網路可能會卡頓。
- 選了比格子大的畫質時，YouTube 畫面上的標誌和文字會跟著變小，這是正常的。
- mp4 和一般網頁（Twitch、新聞台官網等）沒有畫質按鈕：mp4 只有一種畫質，網頁的畫質由網站決定。
- 有些直播不開放倒轉，這時只會顯示「● LIVE」，不能拖曳。
- 清單裡同一部 YouTube 影片如果用不同寫法的網址（例如 youtu.be/… 和 youtube.com/watch?v=…）存了兩次，會被當成兩筆。
- 清單蓋住的格子部分不能拖放；清單佔滿整個視窗時（視窗很窄），只能用「點一下」放入。
- 開啟程式時自動還原的影片不會記到歷史。
- 單格全螢幕時，數字鍵 1～9 不作用；按工具列的版型會先回到分割畫面再切換。
- 格子很窄時，進度條會移到按鈕下方，而且不顯示時間。

## 常見問題

**Q：最愛和歷史會不會因為重灌程式而消失？**
A：不會。清單存在這台電腦的使用者資料裡，換新版的可攜版檔案也還在；但換一台電腦就要重新加入。

**Q：不小心按了「全部清除」怎麼辦？**
A：清除前會再確認一次；按下「清除」之後就無法復原。

**Q：為什麼有些直播拖不了進度條？**
A：那個直播沒有開放倒轉，只能看最新的畫面。
