# 播放一般影片網頁（Twitch、新聞台官網等）

> 上線版本：0.1.0　｜　更新日期：2026-10-08

## 這個功能做什麼

以前 MultiView 只能放 YouTube，或是結尾是 .mp4、.m3u8 的影片網址。很多直播只放在網站自己的頁面上，例如 Twitch、新聞台官網，沒辦法放進來。現在直接貼上那個網頁的網址就可以：程式會在格子裡打開整個網頁，自動找出頁面上最大的影片，放大填滿格子，網站的選單、聊天室、廣告欄都會被蓋掉，畫面上只看得到影片。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

1. **放入網頁：** 在空白格子貼上影片網頁的網址（例如 Twitch 頻道、新聞台的直播頁），按 Enter。網址要包含開頭的「https://」。
2. **等它找到影片：** 一般會在幾秒內只剩下影片。聲音、音量、全部播放／暫停、快捷鍵的用法都和 YouTube 格子一樣。
3. **影片沒有出現時：** 有些網站要先按「同意」、「播放」或登入，影片才會出現。程式找了 15 秒還找不到影片，會自動改成「顯示整個網頁」，格子上方會出現提示。這時直接在格子裡操作網頁（點按鈕、打字、捲動都可以），完成後把滑鼠移到格子上，按右下角的「只顯示影片」。
4. **隨時切換：** 滑鼠移到格子上，右下角有「顯示整個網頁」／「只顯示影片」按鈕，可以來回切換。
5. **廣告阻擋：** 網頁格子預設會擋掉常見的廣告。如果某個網站因此不能播放，按右下角的「廣告阻擋：開」把它關掉，那一格會重新載入。這個設定每一格各自記住。
6. **登入會被記住：** 在網頁裡登入過的網站，下次開啟程式還是登入狀態。同一個網站放在好幾格，也會共用同一個登入。

## 範例

想同時看兩個 Twitch 實況和一台國際新聞台：

1. 切到「2×2」版型。
2. 前兩格貼上兩個 Twitch 頻道網址，第三格貼上新聞台的直播頁網址。
3. Twitch 的兩格幾秒內就只剩實況畫面。
4. 新聞台那一格第一次開啟時跳出「是否同意 cookie」，影片沒出現。等提示出現後，在格子裡按掉同意視窗，再按「只顯示影片」。
5. 下次開啟程式，這三格都還在，新聞台也不會再問同意。

## 限制與注意事項

- **有版權保護的影片（例如 Netflix、Disney+）無法播放**，格子會顯示「這個影片有版權保護，無法播放」。
- **頁面上有好幾個影片時，一律顯示最大的那一個**，不能自己選。
- 不少台灣新聞台的官網直播其實是內嵌 YouTube，而且要先按播放才會載入影片。遇到這種情況，可以切到「顯示整個網頁」按播放後再切回來，或是直接貼該台的 YouTube 直播網址，通常更快。
- 網頁打不開、網址錯誤或網站沒有回應（30 秒）時，格子會顯示「無法載入網頁」和「重試」。程式不會自動重試。
- 「顯示整個網頁」時，按鍵會交給網頁（方便打字），空白鍵、M、數字鍵這些快捷鍵暫時不作用；點一下其他格子就會恢復。F11 全螢幕不受影響。
- 「顯示整個網頁」的狀態不會記住，重新開啟程式時都從「只顯示影片」開始。在網頁裡點連結換到別頁，下次開啟仍然是你當初貼上的網址。
- 網站要開新視窗（彈出視窗）都會被擋下。
- YouTube 格子不會擋廣告，這是 YouTube 的規定。
- 網頁格子比 YouTube 格子耗電腦資源，同時開很多格時，舊電腦可能會變慢。
- 格子很窄的時候，右下角的按鈕只顯示小圖示，把滑鼠停在圖示上可以看到名稱。

## 常見問題

**Q：明明看得到影片，格子卻一直是黑的，或跳成整頁？**
A：有些網站的影片要載入比較久，或要先按播放。切到「顯示整個網頁」，確認影片正在播放、而且在畫面上看得到，再按「只顯示影片」。

**Q：關掉廣告阻擋會影響其他格嗎？**
A：不會，只影響那一格。

**Q：怎麼登出網站？**
A：目前沒有清除登入的按鈕，請在「顯示整個網頁」裡用網站自己的登出功能。
