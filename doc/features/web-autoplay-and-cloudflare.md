# 網頁找不到影片時自動按播放

> 上線版本：0.8.2　｜　更新日期：2026-11-07

## 這個功能做什麼

有些網站要先按一下播放鈕，網頁上才會出現影片。以前遇到這種網站，「只顯示影片」會說找不到影片，要先切到整頁、自己按播放才行。現在程式會自動幫你按一次網站的播放鈕，找到影片後就只顯示影片。

另外，有些網站有 Cloudflare 的機器人驗證，以前 yt-dlp 會直接失敗；現在會自動換一種方式再試一次。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

不需要另外設定：

1. 用網頁播放的格子，網頁載入完成後幾秒內如果還找不到影片，程式會自動按一次網站的播放鈕。
2. 在「顯示整個網頁」時按「只顯示影片」，如果還沒有影片，會先顯示「正在找影片…」，自動按播放後切到只顯示影片；真的沒有影片才顯示「找不到影片」。

## 範例

開啟一個要先按播放才有影片的網站，以前會在 15 秒後自動切成整頁模式並提示找不到影片；現在幾秒內就會自己開始播放、只顯示影片。

## 限制與注意事項

- 程式認得常見播放器的播放鈕，以及寫著「play」「播放」的按鈕；網站自己做的特殊按鈕可能認不出來，這時仍然要手動按一次。
- 為了避免按到廣告，包在連結裡的按鈕不會按。
- 原本設成暫停的格子，自動按播放找到影片後會再暫停。
- 網站在維護或擋下程式時（例如顯示「under maintenance」），仍然看不到影片。
- Cloudflare 重試只能幫 yt-dlp 通過驗證；yt-dlp 不支援的網站仍然用網頁播放。
