# YouTube 選單：看影片的網頁、回到播放器、回到剛才的頁面

> 上線版本：0.5.5　｜　更新日期：2026-10-14

## 這個功能做什麼

- **看影片的留言和推薦：** 看 YouTube 影片時，可以把那一格切換到這部影片的 YouTube 網頁，往下捲動看留言、點其他推薦影片，看完再切回播放器，播放位置會接下去。
- **一個按鈕整合 YouTube 的操作：** 格子上只有一個「YouTube ▾」按鈕，裡面有「看這部影片的網頁」「回到播放器」「回到剛才的 YouTube 頁面」，不用找好幾個按鈕。
- **工具列的全螢幕按鈕文字修正：** 從格子按「全螢幕」時，工具列的按鈕也會顯示「離開全螢幕」，不會再和格子不一致。

## 誰可以使用

和 MultiView 其他功能一樣，給自己使用，不需要帳號。

## 怎麼使用

1. **看影片的網頁：** 滑鼠移到 YouTube 影片的格子上，按右下角的「YouTube ▾」→「回到網頁」。
   - 那一格會變成這部影片的 YouTube 網頁，從剛才的時間接著播（原本暫停就維持暫停，0.5.5 起不會先播出 1 秒）。
   - 往下捲動就能看留言；點推薦影片會在網頁裡換成那部影片。
2. **回到播放器：** 按「YouTube ▾」→「回到播放器」。會播放網頁上目前的影片（如果在網頁裡換過影片，就是換過的那部），從網頁上的時間接下去，畫質、字幕維持原本的設定。
3. **回到剛才的 YouTube 頁面：** 從格子裡的 YouTube 網站（例如搜尋結果）點開的影片，選單裡會多一項「回到剛才的 YouTube 頁面」，按下就回到原本的搜尋結果和捲動位置。滑鼠的「上一頁」側鍵和 Backspace 也一樣可以回去。

## 範例

看一場演講時想知道大家的評論：按「YouTube ▾」→「看這部影片的網頁」，往下捲看留言。看到推薦清單裡有同一位講者的另一場演講，點進去，再按「回到播放器」，就用一般的播放器（可以選畫質、開字幕）接著看那一場。

## 限制與注意事項

- 不能登入，所以在網頁裡只能看留言，不能留言、按讚或訂閱。
- 網頁模式的廣告阻擋預設開啟（0.5.3 起）；在格子上關掉後，這一格會記住你的選擇。0.5.3 以前 YouTube 網頁的廣告阻擋實際上沒有作用，0.5.4 起才會真的阻擋。部分廣告仍可能擋不掉，YouTube 也可能偵測到廣告阻擋而顯示警告或限制播放。
- 網頁模式時沒有畫質、字幕選單、預覽縮圖；回到播放器後就有。
- 網頁裡換到的影片如果不允許嵌入播放，回到播放器時會顯示「此影片無法在外部播放」，可以按「改用 YouTube 網頁播放」。
- 網頁模式時，格子上的 ☆ 加入的是切換前的那部影片；回到播放器後才換成網頁上目前的影片。
- 關閉程式再打開時，網頁模式的格子會變回播放器，停在網頁上當時的影片和時間。
- 「YouTube ▾」只出現在一般 YouTube 播放的格子；改用 YouTube 網頁播放的格子、在格子裡逛 YouTube 網站的格子本來就是網頁，沒有這個按鈕。

## 常見問題

**Q：原本的「← 回到 YouTube」按鈕不見了？**
A：已經放進「YouTube ▾」選單裡，叫做「回到剛才的 YouTube 頁面」。Backspace 和滑鼠的「上一頁」側鍵也照樣可以用。

**Q：切到網頁後影片從頭開始了？**
A：通常會從剛才的時間接著播；如果 YouTube 先播廣告，廣告結束後才會到那個時間。
