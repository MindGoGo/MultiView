# MultiView 多畫面直播播放器

> 上線版本：0.6.0　｜　更新日期：2026-11-01

## 這個功能做什麼

以前要同時看好幾個直播，得開好幾個瀏覽器視窗，畫面被網址列、推薦影片、留言佔掉一大半，也搞不清楚聲音是從哪一個視窗出來的。現在打開 MultiView，一個視窗就能把畫面切成 2、4 或 9 格，每格放一個直播，畫面上只有影片本身。哪一格要出聲音、要不要全部暫停，都能集中控制。

## 誰可以使用

目前是給自己使用的個人工具，不需要帳號，也不需要登入。只要是 Windows 10 或 11 的電腦都可以用。

## 在其他電腦上使用

0.3.2 版起改成安裝版（MultiView-Setup-版本號.exe），開啟比以前的單一檔案快很多：

1. 把安裝檔複製到要用的電腦。
2. 雙擊執行，會自動安裝並開啟程式，不需要系統管理員權限。之後從桌面或「開始」功能表的 MultiView 開啟。
3. 第一次執行時，Windows 可能會跳出「Windows 已保護您的電腦」。這是因為程式沒有向微軟購買的數位簽章，不是病毒。按「其他資訊」→「仍要執行」即可。

詳細說明見「安裝版、點 YouTube 裡的影片、暫停畫面的橫線」。

每台電腦會各自記住自己的版型和影片清單，換一台電腦需要重新設定。

## 怎麼使用

1. **放入影片：** 在空白格子的輸入框貼上網址，按 Enter 就會開始播放；也可以按輸入框下方的「開啟 YouTube」直接逛 YouTube。可以貼 YouTube 影片或直播網址、直接以 `.mp4` 或 `.m3u8` 結尾的影片網址，也可以貼 Twitch、新聞台官網這類影片網頁的網址（用法見「播放一般影片網頁」的說明）。
2. **換版型：** 把滑鼠移到視窗最上方，會出現工具列。點「1、2、2×2、3×3、1+3」切換分割方式。「1+3」是左邊一個大畫面，右邊三個小畫面。
3. **調整格子大小：** 拖曳格子之間的細線，可以讓某一格變大。在線上連點兩下，就會恢復平均分配。
4. **交換位置：** 滑鼠移到某一格，右下角會出現按鈕。按住「移動」，拖到另一格後放開，兩格的影片就會互換，而且不會中斷播放。
5. **聽哪一格：**
   - 點一下某一格的畫面，就只聽那一格，其他格自動靜音。
   - 想同時聽好幾格，就按各格右下角的喇叭按鈕，一格一格打開。
   - 每一格右下角的「🔉」按鈕可以各自調整大小聲（按下後出現音量條）。
   - 每一格右下角的「☀」可以各自調整亮度，工具列的「☀」可以一次調整全部格子（見「每格亮度、總亮度、音量按鈕」的說明）。
   - 有聲音的格子，左上角會一直顯示小喇叭。
6. **全部控制：** 工具列上有「全部播放」「全部暫停」「全部靜音」。
7. **其他按鈕：** 工具列右邊有「置頂」（讓視窗永遠在最上層）、「全螢幕」、「最小化」和「關閉」。要移動視窗，拖曳工具列中間的空白處就可以。工具列的「YouTube 小視窗」可以另外開一個視窗看推薦影片、留言、直播聊天室，或用手機版 YouTube 搜尋（見「YouTube 小視窗」的說明）。
8. **快捷鍵：**

   | 按鍵 | 作用 |
   |---|---|
   | 空白鍵 | 有任何一格在播放就全部暫停，否則全部播放 |
   | M | 全部靜音 |
   | 1～9 | 只聽第幾格（格子由左到右、由上到下編號） |
   | F11 | 切換全螢幕 |
   | Esc | 離開全螢幕（單格全螢幕時回到分割畫面）；正在輸入網址時則是取消輸入 |
   | ← / → | 滑鼠所在的格子（單格全螢幕時是放大的那一格）倒轉／快轉 5 秒，按住會一直跳 |
   | Backspace | 從 YouTube 網站開啟的影片回到原本的 YouTube 頁面 |

## 範例

想一邊看三台新聞直播、一邊看一場球賽：

1. 切到「1+3」版型。
2. 把球賽網址貼在左邊大格，三台新聞貼在右邊三個小格。
3. 新加入的格子預設靜音，所以只會聽到球賽。
4. 新聞出現重要消息時，點一下那一格就改聽新聞；看完再點回球賽。
5. 下次打開程式，四個畫面、版型和聲音設定都還在，按空白鍵就能全部開始播放。

## 限制與注意事項

- YouTube 首頁、搜尋結果、頻道頁、播放清單頁會以「顯示整個網頁」開啟，可以在裡面搜尋、點影片（見「在格子裡逛 YouTube、訂閱頻道、YouTube 清單分開」的說明）。
- YouTube 的標誌和廣告會照常出現，這是 YouTube 的規定，程式不會遮蓋。影片暫停或播完時，YouTube 可能會顯示同一個頻道的其他影片；按「直接操作」後點這些影片，就會在那一格播放。
- 有些 YouTube 影片的上傳者不允許在其他地方播放，這種影片會顯示「此影片無法在外部播放」。可以按下方的「改用 YouTube 網頁播放」，或在工具列「⚙ 設定」打開自動改用（見「YouTube 網頁播放、進度條預覽、快轉倒轉」的說明）。
- 為了讓「點畫面切換聲音」不會不小心暫停影片，平常點畫面不會操作到 YouTube 本身。如果需要略過廣告，請先按該格的「直接操作」，滑鼠移出那一格後就會恢復。
- 直播暫停後再播放，會從暫停的地方接著播；要回到最新畫面，請按進度條旁的「回到直播」（見「進度條、單格全螢幕、最愛與歷史、畫質」的說明）。
- 最多同時放 9 個影片。從九格切回四格時，第 5 格以後的影片會先暫停、藏起來，切回九格時就會再出現，不會被刪掉。
- 同時播放很多路高畫質直播會吃電腦效能。畫質預設依格子大小和網路狀況自動調整，也可以每格切成「畫質：高」。

## 常見問題

**Q：檔案為什麼這麼大（約 100MB）？**
A：程式裡面包含了一個完整的影片播放引擎，所以其他電腦不用另外安裝任何東西就能執行。

**Q：重新打開程式後，影片為什麼沒有自動播放？**
A：這是刻意的設計，避免一打開程式就突然好幾個聲音一起出來。按空白鍵或工具列的「全部播放」就會開始播放。

**Q：網址貼上去後顯示「不支援的網址」？**
A：請確認網址開頭有「https://」或「http://」。

**Q：某一格顯示「無法載入影片」？**
A：程式已經自動重試 3 次都失敗，通常是網址失效或網路中斷。可以按「重試」，或按「更換網址」改放別的影片。

**Q：工具列和按鈕跑去哪裡了？**
A：為了讓畫面只剩下影片，按鈕平常是隱藏的。把滑鼠移到視窗最上方會出現工具列，移到某一格上就會出現該格的按鈕。滑鼠不動 2 秒後，按鈕會再自動隱藏。
